# R15: الوصول واللغتان وRTL

| | |
|---|---|
| **الحالة** | 📝 مقترح، ينتظر قرار صاحب المشروع (القرار 3: «تابع عمودياً») |
| **المدة** | 5 أيام عمل |
| **المرحلة** | د. الإطلاق |
| **المنصة** | ويب، تطبيق |
| **يعتمد على** | R06، R10 |

## الهدف

أن تُلعب اللعبة بلوحة المفاتيح وقارئ الشاشة وبخط مكبّر، بالعربية والإنجليزية وبالليل والنهار، وأن يحرس ذلك فحص آلي.

## لماذا

W-A01، W-A02، W-A03، W-A04، W-A05، W-D21، M-A01، M-A02، M-A03، M-A04.

## المهام

### الويب

| الرمز | المهمة | الملفات |
|---|---|---|
| W1 | **axe على كل الشاشات:** `e2e/a11y.spec.ts` يمر على الـ 36 شاشة بالليل والنهار وبالعربية والإنجليزية، ويفشل على أي مخالفة «خطيرة» أو «حرجة» | `web/e2e/a11y.spec.ts` |
| W2 | **المعالم:** كل المحتوى داخل `header`، و`nav`، و`main`، و`footer` (32 شاشة فيها محتوى خارجها: الشريط العائم، والإشعارات، والمدرب المساعد). و`h1` لكل صفحة | `layouts/AppShell.vue`، `components/shell/` |
| W3 | **التباين:** كل زوج لون في `tokens.json` يُفحص آلياً (4.5:1 للنص، و3:1 للحدود والأيقونات) في سكربت الرموز، بالليل والنهار. القسم الحالي بالنهار من `gold-dark` | `web/scripts/tokens.mjs`، `docs/design/tokens.json` |
| W4 | **ARIA الصحيح:** 11 موضع `aria-prohibited-attr` (الملعب ولوحة النادي)، وأسماء أشرطة التقدم (المالية، وحسابي)، ومنطقة التمرير في الدوري تُبلغ بالمفاتيح | `pages/team/StadiumPage.vue`، `ClubBoard.vue`، `Finance.vue`، `Profile.vue`، `LeagueHome.vue` |
| W5 | **لوحة المفاتيح:** صفوف الجداول القابلة للنقر زر داخل خلية الاسم، وكل `<button>` بـ `type`، وترتيب التركيز يتبع الترتيب المرئي، والتركيز يعود لمكانه بعد إغلاق أي نافذة أو درج | `pages/team/squad/`، متفرقة |
| W6 | **التشكيلة بلا سحب:** اختيار لاعب ثم خانة بالمفاتيح أو اللمس (موجود باللمس: «اضغط لاعباً لتختار مكانه»)، مع إعلان النتيجة لقارئ الشاشة (`aria-live`) | `pages/team/Lineup.vue` |
| W7 | **المباراة:** الأحداث المهمة (هدف، وبطاقة، ونافذة المدرب) تُعلن في `aria-live`، وكل ما يُفعل في الدرجين يُفعل بالمفاتيح | `components/match/` |
| W8 | **«تابع عمودياً»** (إن اعتُمد): بطاقة التدوير فيها زر يُحفظ على الجهاز | `components/match/TurnPhone.vue` |
| W9 | **قائمة تحقق RTL** (من Sprint 30) تُعاد على الشاشات الجديدة: الأسهم، والأرقام والأكواد `dir="ltr"`، والأسماء الإنجليزية داخل النص العربي (`bdi`)، والتواريخ | ملف السبرنت |
