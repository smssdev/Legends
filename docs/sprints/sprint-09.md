## ملاحظات وقرارات
- **B1 (2026-10-20):** Sanctum (`HasApiTokens` وجدول التوكنات)، وReverb (`config/reverb.php` و`routes/channels.php`). `composer dev` يشغّل Reverb على 8080 مع الخمسة. والوقت UTC، والملفات الثلاثة والمعاملات `IMMEDIATE` كانت جاهزة. صورة Render التجريبية تبقى بلا بث (`BROADCAST_CONNECTION=log`).
- **B2 (2026-10-20):** `GameClock` يقرأ الإزاحة من ملف صغير (`storage/app/game-clock.json`) يكتبه `clock:travel` (`+8h` و`-30m` و`+2d` و`reset`)، فيرى الخادم والطابور والمجدول نفس الوقت. الإنتاج يتجاهل الملف ويرفض الأمر. واختبار `NoWallClockTest` يرفض `now()` و`time()` و`date()` و`Carbon::now()` وأخواتها في `app/` إلا داخل `GameClock`، وقد وجد `now()` في `data:import` فصار من `GameClock`.
- **B3 (2026-10-20):** `GET /api/v1/health` يعيد الإصدار وأدنى إصدار للتطبيق ونسخة المحرك ووقت اللعبة. و`POST /api/v1/health/ping` يبث حدث `ping` على القناة العامة `system`، وجُرّب حتى وصل لعميل WebSocket. وإن لم يكن Reverb شغالاً يرد 503 برسالة عربية. كل أخطاء الـ API بشكل واحد `{message, code, errors?}` بالعربية (`app/Http/Errors/ApiErrors.php`)، ورسائل `abort()` العربية تبقى كما هي، ورسائل التحقق في `lang/ar/validation.php`، واللغة الافتراضية `ar`. وعقد الـ API محدّث.
