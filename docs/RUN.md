# تشغيل Legends وتجربته

## الطريقة 1: GitHub Codespaces (لا تحتاج تثبيت أي شيء)

1. افتح المستودع على GitHub، واختر الفرع المطلوب (مثلاً `main`).
2. **Code ← Codespaces ← Create codespace on main**.
3. انتظر حتى ينتهي الإعداد (بضع دقائق أول مرة: تثبيت، قواعد بيانات، استيراد 588 نادياً، بناء الواجهة).
4. يُفتح المنفذ 8000 تلقائياً. أضف `/sim` إلى الرابط.

لو لم يعمل الخادم: افتح الطرفية واكتب `cd backend && php artisan serve --host=0.0.0.0`.
للعمل على الواجهة مع تحديث فوري: `cd backend && composer dev` ثم افتح المنفذ 5173.

## الطريقة 2: النسخة الجاهزة من GitHub Actions

1. في المستودع: **Actions ← Package**، وافتح آخر تشغيل ناجح.
2. نزّل الملف من قسم **Artifacts** (`legends-…`) وفك ضغطه.
3. تحتاج PHP 8.3 أو أحدث مع إضافة `pdo_sqlite` (على ويندوز: نزّل PHP من windows.php.net وفعّل `extension=pdo_sqlite` في `php.ini`).
4. شغّل `run.sh` (لينكس/ماك) أو `run.bat` (ويندوز)، ثم افتح http://127.0.0.1:8000/sim

النسخة تحتوي الـ API والواجهة المبنية وبيانات الأندية، ولا تحتاج Node أو Composer.

## ماذا تجرب في المحاكي

- اختر ناديين، وحدد من يدير كل فريق (أنا / الحاسوب)، والحكم، والملعب، والسرعة.
- أثناء المباراة: الأوامر السريعة، والتبديل، والتكتيك الكامل، وتغيير الطريقة. الأمر يُطبق في الدقيقة التالية.
- **لوحة المطور** تعرض الأرقام الداخلية (معدل الهجمات وحصة كل فريق).
- نفس البذرة + نفس الأوامر = نفس المباراة بالضبط.
- بعد صافرة النهاية: **تقرير المباراة** من وجهة نظر أي من الفريقين.
