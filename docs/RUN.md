# تشغيل Legends وتجربته

## الطريقة 1: GitHub Codespaces (لا تحتاج تثبيت أي شيء)

1. افتح المستودع على GitHub، واختر الفرع المطلوب (مثلاً `main`).
2. **Code ← Codespaces ← Create codespace on main**.
3. انتظر حتى ينتهي الإعداد (بضع دقائق أول مرة: تثبيت، قواعد بيانات، استيراد 588 نادياً، بناء الواجهة).
4. يُفتح المنفذ 8000 تلقائياً. أضف `/sim` إلى الرابط.

**التحديث تلقائي:** كل مرة تفتح الـ Codespace يسحب آخر نسخة من `main` ويعيد بناء الواجهة لو تغير الكود، ثم يشغّل اللعبة (لو عندك تعديلات محلية لا يسحب). Codespace قديم أُنشئ قبل هذه الميزة يحتاج مرة واحدة: `git checkout main && git pull && cd backend && composer build-web && php artisan serve --host=0.0.0.0`، أو احذفه وأنشئ واحداً جديداً على `main`.

لو لم يعمل الخادم: افتح الطرفية واكتب `cd backend && php artisan serve --host=0.0.0.0`.
للعمل على الواجهة مع تحديث فوري: `cd backend && composer dev` ثم افتح المنفذ 5173.

## رابط دائم مجاني على Render (للعرض)

1. افتح: https://render.com/deploy?repo=https://github.com/smssdev/Legends
2. سجّل الدخول بحساب GitHub، واسمح لـ Render بالوصول للمستودع لو طلب.
3. اضغط **Apply** وانتظر البناء (حوالي 5 إلى 10 دقائق أول مرة).
4. افتح الرابط الذي يظهر (`https://legends-xxxx.onrender.com`) وأضف `/sim`.

كل دمج في `main` يُنشر تلقائياً. حدود الخطة المجانية: ينام الموقع بعد 15 دقيقة بلا زوار (أول فتحة بعدها تأخذ حوالي دقيقة)، والبيانات تُمسح مع كل إعادة تشغيل. يكفي للمحاكي، ولا يصلح للدوريات (الخطة: جهاز منزلي [PLAN 2.19]).

## الطريقة 2: النسخة الجاهزة من GitHub Actions

1. في المستودع: **Actions ← Package**، وافتح آخر تشغيل ناجح.
2. نزّل الملف من قسم **Artifacts** (`legends-…`) وفك ضغطه.
3. تحتاج PHP 8.3 أو أحدث مع إضافة `pdo_sqlite` (على ويندوز: نزّل PHP من windows.php.net وفعّل `extension=pdo_sqlite` في `php.ini`).
4. شغّل `run.sh` (لينكس/ماك) أو `run.bat` (ويندوز)، ثم افتح http://127.0.0.1:8000/sim

النسخة تحتوي الـ API والواجهة المبنية وبيانات الأندية، ولا تحتاج Node أو Composer.

## مباراة بينك وبين صديق (جهازان)

1. في شاشة الإعداد اختر **طريقة اللعب: مع صديق**، واختر الناديين، ثم **ابدأ المباراة**.
2. تظهر لك بطاقة فيها **رابط الصديق**: أرسله له (زر "نسخ" أو المشاركة من الجوال). أنت تدير الفريق الأول، وهو يدير الثاني.
3. حين يفتح صديقك الرابط، يضغط أي منكما **ابدأ المباراة**، وتبدأ بعد 3 ثوانٍ على الجهازين معاً.
4. الخادم يدير الوقت (بسرعة ×1، والاستراحة 30 ثانية)، فلا إيقاف ولا تسريع. كل واحد يرسل أوامره لفريقه من جهازه.

**في Codespaces:** حتى يفتح صديقك الرابط من جواله، اجعل المنفذ 8000 عاماً: تبويب Ports ← اضغط مطولاً (أو بالزر الأيمن) على 8000 ← **Port Visibility ← Public**.

هذه نسخة تجريبية من المحاكي: لا حسابات، وكل واحد يستطيع رؤية تكتيك الآخر لو فتح لوحة المطور. المباراة الحقيقية بين الأصدقاء (بحسابات وتكتيك مخفي وبث لحظي) في السبرنت 13.

## ماذا تجرب في المحاكي

- اختر ناديين، وحدد من يدير كل فريق (أنا / الحاسوب)، والحكم، والملعب، والسرعة.
- أثناء المباراة: الأوامر السريعة، والتبديل، والتكتيك الكامل، وتغيير الطريقة. الأمر يُطبق في الدقيقة التالية.
- **لوحة المطور** تعرض الأرقام الداخلية (معدل الهجمات وحصة كل فريق).
- نفس البذرة + نفس الأوامر = نفس المباراة بالضبط.
- بعد صافرة النهاية: **تقرير المباراة** من وجهة نظر أي من الفريقين.
