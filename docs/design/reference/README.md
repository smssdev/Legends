# مراجع التصميم

**اللقطات الفعلية في `docs/reference/osm/`** (`mobile/` 95 لقطة و`web/` 74 لقطة). هذا الملف يبقى لتسمية اللقطات المختارة لو نُسخت هنا لاحقاً.

لقطات شاشة من لعبة OSM (المدرب الأفضل) للويب والموبايل، كمرجع للبنية والتنقل فقط.

| المجلد | المحتوى |
|---|---|
| `web/` | لقطات نسخة الويب |
| `mobile/` | لقطات نسخة الموبايل |

سمِّ كل لقطة باسم الشاشة: `dashboard.png`، `squad.png`، `lineup.png`، `tactics.png`، `training.png`، `transfers.png`، `scout.png`، `stadium.png`، `finances.png`، `league-table.png`، `fixtures.png`، `match-live.png`، `match-result.png`، `messages.png`، `specialists.png`، `shop.png`.

> مرجع للبنية فقط: لا تُنسخ الرسوم ولا الأيقونات ولا النصوص ولا الشخصيات. التصميم النهائي من عندنا بهوية Legends (`brand/`).
