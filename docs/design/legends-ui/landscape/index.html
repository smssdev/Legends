مسودات العرض · Sprint 55

الإطار وثماني شاشات بالعرض، للموقع والتطبيق معاً، كل واحدة بثلاثة مقاسات (667×375 و915×412 و1440×900)، بالليل والنهار، وبحالاتها (تحميل، وفراغ، وخطأ، وبلا اتصال). لا يُبنى منها شيء قبل اعتمادك (D12). والقرار الأول في «الإطار»: خيار الكمبيوتر.
