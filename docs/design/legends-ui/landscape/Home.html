كل المسودات الإطار المكتب الفريق التشكيلة التكتيك السوق المباراة القادمة المباراة الرئيسية

خارج النادي: الفتحات أولاً، وفي كل فتحة ناديها ومركزه ومباراته القادمة بعدّادها، وما ينتظرك فيها رقماً. والفتحة الفارغة «أنشئ أو انضم»، والمقفلة بعدّادها. وتحتها بطاقة التوثيق (بدل الشريط العلوي) والمكافأة.
