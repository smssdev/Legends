1. في نوع المخزن أضف remove: (id: number) => void، وفي المخزن remove: (id) => set((s) => { const { [id]: _, ...rest } = s.lines; return { lines: rest }; }). فالتفكيك مع كائن الباقي يبني كائناً جديداً بلا ذلك المفتاح. وفي CartSummary حدّد remove واستدعها من زر على كل سطر.
  2. const [language, setLanguage] = useState<"en" | "ar">("en"); useEffect(() => { document.documentElement.lang = language; document.documentElement.dir = language === "ar" ? "rtl" : "ltr"; }, [language]);، مع تقديم { language, setLanguage } عبر سياق وخطّاف useLanguage() يرمي خطأً خارج المزوّد.
  3. أنشئ المخزن بـ createStore<CartState>()((set) => ({ … })) بالدوال نفسها، ثم استدعِ store.getState().add(book) وadd(mug) وadd(mug) وclear()، واطبع selectCount(store.getState()) بعد كل منها: 1 ثم 2 ثم 3 ثم 0. وتعمل المحدِّدات دون تغيير، لأنها دوال عادية في الحالة.
  4. يُرسم كلاهما مرة في البداية. ثم يُرسم CartBadge مرة أخرى مع كل منتج يُضاف (تغيّر عدده)، ولا يُرسم ProductList من جديد: فهو يحدد add فقط، ولا تتغير أبداً. (وأثناء التطوير يضاعف الوضع الصارم كل رقم.)
  5. type Auth = { status: "signed-out" } | { status: "signing-in" } | { status: "signed-in"; user: User }، مع signIn وsignOut. تضبط signIn الحالة signing-in، وتنتظر الواجهة الوهمية، ثم تضبط signed-in مع المستخدم. وتستخدم الترويسة switch على status: زر دخول، أو زر «جارٍ الدخول…» معطّل، أو الاسم مع زر خروج.
