1. function Price({ value, currency }: { value: number; currency: string }) { return <p className="price">{value.toFixed(2)} {currency}</p>; }, then in ProductCard write <Price value={product.price} currency="EGP" />.
  2. Add discount?: number to Product and, in the card, {product.discount !== undefined && <span className="badge">-{product.discount * 100}%</span>}. Comparing with undefined keeps the left side a real boolean, so nothing is drawn for products without a discount.
  3. In App: const [count, setCount] = useState(0); pass onAdd={() => setCount(count + 1)} to every ProductCard, and render <p>{count} items in your cart</p> above the grid. The state lives in App because both the grid and the summary need it.
  4. Replace the if statements with switch (state.status) { case "loading": … case "error": … case "success": … default: return assertNever(state); }. After adding | { status: "offline" } to the type, the compiler reports the default line until you add case "offline": return <p className="muted">You are offline.</p>;.
  5. Move the number into the parent: const [visitors, setVisitors] = useState(0), render <Counter visitors={visitors} /> and a button with onClick={() => setVisitors(visitors + 1)}. Counter now only displays its prop, so rendering it twice gives the same result.
