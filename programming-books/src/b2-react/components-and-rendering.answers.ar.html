1. function Price({ value, currency }: { value: number; currency: string }) { return <p className="price">{value.toFixed(2)} {currency}</p>; }، ثم اكتب في ProductCard: <Price value={product.price} currency="جنيهاً" />.
  2. أضف discount?: number إلى Product، وفي البطاقة: {product.discount !== undefined && <span className="badge">-{product.discount * 100}%</span>}. والمقارنة بـ undefined تُبقي الجانب الأيسر قيمة منطقية حقيقية، فلا يُرسم شيء للمنتجات بلا خصم.
  3. في App: const [count, setCount] = useState(0)، ومرّر onAdd={() => setCount(count + 1)} إلى كل ProductCard، وارسم <p>{count} عناصر في سلتك</p> فوق الشبكة. وتعيش الحالة في App لأن الشبكة والملخص كليهما يحتاجانها.
  4. استبدل جمل if بـ switch (state.status) { case "loading": … case "error": … case "success": … default: return assertNever(state); }. وبعد إضافة | { status: "offline" } إلى النوع يبلّغ المترجم عن سطر default حتى تضيف case "offline": return <p className="muted">أنت غير متصل.</p>;.
  5. انقل الرقم إلى الأب: const [visitors, setVisitors] = useState(0)، وارسم <Counter visitors={visitors} /> وزراً بـ onClick={() => setVisitors(visitors + 1)}. صار Counter يعرض خاصيته فقط، فرسمه مرتين يعطي النتيجة نفسها.
