CLAUDE.md والمهارات والـ Hooks

في هذا الفصل ستتعلم أن

  • تكتب CLAUDE.md يعطي كل جلسة ما تحتاج معرفته عن مشروعك
  • تضع الصلاحيات في ملفات الإعدادات، وتفهم لماذا يجب أن يُوثق المجلد الجديد أولاً
  • تفرض قاعدة بـ hook، بدل أن تأمل أن يتبعها النموذج
  • تحزم مهمة متكررة في مهارة لا تُحمَّل إلا عند الحاجة
  • تختبر الـ hook وحده، دون أي نموذج

في الفصل 7 حمل كل تشغيل قواعده في سطر الأوامر: أي الأوامر مسموحة، وكيف تُشغّل الاختبارات، وما لا يُلمس. ولا يستطيع فريق أن يعمل هكذا. فـ Claude Code يقرأ إعداداته من ملفات في المستودع، فتُكتب القواعد مرة، وتُراجع كالكود، ويتشاركها الجميع. وأربعة ملفات تقوم بمعظم العمل: CLAUDE.md للمعرفة، وsettings.json للصلاحيات، والـ hooks للقواعد التي يجب أن تصمد، والمهارات للمهام التي تكررها.

كل ما فعله Claude Code في هذا الفصل حقيقي: أرسل CLAUDE.md إلى النموذج، وتجاهل صلاحيات المشروع حتى وُثق المجلد، وشغّل الـ hook الذي أوقف الدفع، وحمّل مهارة باسمها. ولعب خادم التدريب دور النموذج، وضُبط رده عن CLAUDE.md ألا يظهر إلا إن وصلت كلمات CLAUDE.md فعلاً.

أبقِ CLAUDE.md قصيراً ومحدداً. الأوامر، والأعراف، وتخطيط الكود، والأخطاء التي يقع فيها الناس هنا؛ لا درساً تعليمياً، ولا المعمارية كلها، ولا حقائق تتغير كل أسبوع. فكل سطر يُرسل مع كل طلب، فكل سطر يكلّف tokens وانتباهاً. و/init في الجلسة التفاعلية يكتب مسودة من قاعدة كودك؛ فاختصرها. وتستطيع أيضاً حفظ CLAUDE.md شخصي في ~/.claude/ لعاداتك عبر المشاريع، وإضافة ملفات في المجلدات الفرعية لأجزاء المستودع الكبير التي تحتاج ملاحظاتها.



نصيحة
حين يكرر Claude Code الخطأ نفسه مرتين، فالإصلاح عادة سطر في CLAUDE.md، لا أمر أطول. اكتبه قاعدة بسببها («المبالغ بالقروش، أعداداً صحيحة: الأعداد العشرية تقرّب خطأ»)، واحفظه، فتتحسن جلسات الفريق كله دفعة واحدة.

انتبه

{{n}}.3 الـ Hooks: قواعد تصمد



يقول CLAUDE.md «لا تدفع أبداً». هذه نصيحة: يقرؤها النموذج ويتبعها عادة. و«عادة» لا تكفي لبعض القواعد. والـ hook أمر يشغّله Claude Code بنفسه في لحظة من الحلقة (قبل أن تعمل أداة، وبعد أن تعمل، وحين يُرسل أمر، وحين تتوقف الجلسة)، مهما ظن النموذج. وhook المشروع يعمل قبل كل أمر طرفية:








حاول النموذج المكتوب أن يدفع، رغم CLAUDE.md، بالضبط نوع الزلة الذي وُجد الـ hook من أجله. فشغّل Claude Code الـ hook، ورأى الـ hook git push فخرج برمز 2، ولم يعمل الأمر أبداً؛ وعادت رسالة الـ hook إلى النموذج، فأبلغ عن المنع. النموذج يستطيع تجاهل النصيحة؛ ولا يستطيع تجاهل الـ hook.



والـ hooks برامج عادية، فتستطيع فعل أكثر بكثير من المنع: تنسيق ملف بعد كل تعديل، وتشغيل الاختبارات حين تنتهي الجلسة، وإضافة اسم المناوب اليوم إلى كل أمر، وكتابة سجل تدقيق. وأبقِها سريعة، لأنها تعمل مع كل حدث مطابق، وتذكّر أنها تعمل بصلاحياتك أنت.

{{n}}.4 المهارات



الـ مهارة (skill) مجلد فيه SKILL.md: اسم، ووصف من سطر واحد، وتعليمات، مع أي سكربتات أو قوالب تحتاجها المهمة. ولا يرى Claude Code إلا الأوصاف حتى تحتاج مهمةٌ مهارة؛ وعندها يحمّل التعليمات. وعلى خلاف CLAUDE.md الذي يُرسل مع كل طلب، لا تكلّف المهارة شيئاً حتى تُستخدم، فيستطيع الفريق أن يحفظ عشرات منها.






والمشروع {{n}}.2 يشغّلها. والوصف أهم مما يبدو: فهو ما يقرؤه Claude ليقرر هل تناسب المهارة المهمة، فاكتبه بالموقف الذي هي له («اكتب ملاحظات الإصدار لتطبيق المقهى»)، لا كعنوان («مساعد الإصدار»).



عادة المحترفين
راجع التغييرات على CLAUDE.md والإعدادات والـ hooks والمهارات كالكود، في طلبات دمج، مع شخص يفهم ما تسمح به. فهي تقرر ما يعرفه الوكيل، وما يُسمح له به، وما يجب ألا يفعله، لكل من في الفريق.

الخطأما يحدثالحل



CLAUDE.md طويلtokens وانتباه يُنفقان مع كل طلبما لا يستطيع Claude تخمينه فقط؛ والباقي إلى المهارات


قواعد يجب أن تصمد مكتوبة كنصيحةتُتبع عادة، وأحياناً لاافرضها بـ hooks أو صلاحيات


الثقة بمستودع دون قراءة .claude/إعداداته والـ hooks فيه تعمل على جهازكاقرأه أولاً، كأي سكربت بناء


إعدادات شخصية محفوظة للفريقيأخذ الجميع صلاحيات شخص واحدالقواعد الشخصية في settings.local.json


hooks بطيئة على أحداث متكررةكل استدعاء أداة ينتظرأبقِ الـ hooks سريعة؛ وطابق الأدوات التي تحتاجها فقط


أوصاف مهارات غامضةلا تُستخدم المهارة حين يجبصِف الموقف الذي المهارة له






الملخص



    

  • CLAUDE.md يُرسل مع كل طلب: أبقِه قصيراً ومحدداً ومحفوظاً.
    • 

  • الإعدادات تحفظ الصلاحيات على ثلاثة مستويات، وإعدادات المشروع لا تنطبق إلا بعد أن يوثق إنسان المجلد.
    • 

  • الـ hooks أوامر يشغّلها Claude Code بنفسه؛ ورمز الخروج 2 يوقف استدعاء الأداة، مهما قصد النموذج.
    • 

  • المهارات لا تحمّل تعليماتها إلا حين تحتاجها مهمة، فلا تكلّف شيئاً حتى تُستخدم.
    • 

  • كل ذلك كود: راجعه، واختبره، واعرف ما يسمح به.
    • 




إجابات «اختبر نفسك»: 1. ضُبط رد خادم التدريب ليطابق فقط إن كانت كلمات CLAUDE.md في الطلب؛ وقد طابق، فقد أرسلها Claude Code. 2. لأن المجلد لم يكن موثوقاً: فحتى يثق به إنسان، لا تستطيع إعدادات المشروع منح Claude Code صلاحيات، وإلا لاستطاع أي مستودع أن يسمح لنفسه بأي شيء. 3. السطر في CLAUDE.md نصيحة قد لا يتبعها النموذج، وهنا لم يتبعها؛ والـ hook برنامج يشغّله Claude Code قبل الأمر، فيوقف الدفع مهما فعل النموذج.
