Before you begin

How to Use This Book

Claude is one family of AI models that reaches you through several doors: a chat app on the web, desktop and phone; Claude Code, an agent that works in your terminal and your repository; and an API that puts the same models inside your own programs. This book teaches all three the way a professional uses them: what each is good at, how to give it the right context, how to check its work, and what it costs. It is written for developers and teams, and it builds on Book 7, AI for Developers, whose habits (give the model what it needs, check what it gives you, measure before you believe) apply here to one family of tools in depth.

What you need

  • Node.js 22 and a code editor, as in the earlier books.
  • For Part I, a Claude account; the free plan is enough for most of it, and the chapters say where a paid plan adds something.
  • For Part II, Claude Code, installed as Chapter 6 shows, with a Claude subscription or an API key.
  • For Part III, nothing more: every example runs against the book’s practice server, described below. A key from the Claude Console is needed only when you want real answers from Claude.

The practice server

Every program in this book calls Claude through the official SDK, @anthropic-ai/sdk, exactly as it would in production. To let you run all of them for free, offline and with no account, the book’s code repository includes a practice server: a small local program that speaks the API’s format (requests, responses, streaming events, tool calls, errors, token usage) and answers from a file in each chapter, practice.json.

Read this before any example

The practice server is not Claude. Its answers were written for this book, to show what each part of a response looks like and how a program should handle it. When a transcript in this book shows an answer, it is the practice server’s, and the chapter says so. The errors, the field names, the streaming events and the code are real; the words of the answers are not Claude’s, and the token counts are an approximation (about four characters per token). To see what Claude really answers, run the same code against the real API with your own key: Claude’s words will differ, and you should check them the way Book 7 taught.

Switching between the two is a matter of two environment variables, which the SDK reads by itself:

node practice/server.mjs &                       # the practice server, on port 4141
export ANTHROPIC_BASE_URL=http://127.0.0.1:4141    # talk to it
export ANTHROPIC_API_KEY=test-key                  # its only key

unset ANTHROPIC_BASE_URL                           # the real API instead
export ANTHROPIC_API_KEY=sk-ant-...                # your own key, never in code

How the book is organised

The seventeen chapters are grouped in three parts, one for each door. They can be read in any order, but the parts build on each other: the habits of Part I are assumed in Part II, and Part III assumes you have read Chapter 1.

  • Claude.ai: the models and their limits, conversations with files and images, projects that keep a team’s knowledge, artifacts, and research with connectors and tools.
  • Claude Code: the agent in your terminal, working on a real codebase, instructions in CLAUDE.md, skills and hooks, the path from issue to pull request, and Claude Code for teams and continuous integration.
  • Building with Claude: the API, tool use and structured output, MCP for connecting Claude to your systems, agents, cost and speed, safety and evaluation, and a capstone product.

Every chapter

Each chapter follows the pattern of the series: what you will learn; explanations built on real examples; a quick check; boxes with tips, traps and professional habits; common mistakes; a summary; three practice projects (easy, medium and challenge); and exercises with answers at the end of the book.

Versions and dates

Claude changes faster than any book: new models, new features, new prices. Everything in this book was checked in November 2026 against these versions:

ToolVersion
Node.js22.23
@anthropic-ai/sdk1.8.0 (API version 2026-10-21)
ModelsClaude Fable 5.2, Opus 5.5, Sonnet 5.5 and Haiku 5.5

When a model name, a price or a limit in this book disagrees with Anthropic’s documentation, the documentation is right. Chapter 1 shows how to ask the API itself which models exist and what their limits are, so your programs never depend on a number printed here.

Reading the examples

  • A dark tab above a listing gives the file’s path in the project.
  • A box with three coloured dots is a terminal: a line starting with $ is a command, the lines below are its answer.
  • Every example, project and exercise answer is in the book’s code repository, with the practice server, each chapter’s practice.json, and the script that produced each transcript.
