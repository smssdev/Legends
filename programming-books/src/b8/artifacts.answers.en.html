  3. Write the test first: a bill of 100 split between 3 gives 36.67 each (110 / 3 = 36.666…), and the shares then add up to 110.01, not 110.00. Tricky inputs: zero or negative people, fractions of a person, and the rounding that makes shares not add up to the total. Decide in the test what should happen (for example, the last person pays the difference), and only then write or ask for the code.
