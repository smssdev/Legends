الفصل {{n}}

Claude Code في الطرفية

في هذا الفصل ستتعلم أن

  • تثبّت Claude Code، وتسجّل الدخول، وتختار بين الوضع التفاعلي ووضع الطباعة
  • تراقب حلقة الوكيل: ما يقوله Claude، وأي الأدوات يستدعي، وما يعود
  • تتحكم فيما يُسمح لـ Claude Code بفعله، بالصلاحيات والأدوات المسموحة
  • تقرأ مخرجات Claude Code بصيغة JSON: النتيجة، والأدوار، والتكلفة
  • تضع حداً صارماً لما يُسمح لتشغيل أن ينفقه

استخدم الجزء الأول Claude في نافذة، وكنت تحمل الكود منها وإليها. أما Claude Code فيعمل حيث الكود: في طرفيتك، داخل مستودعك. يقرأ الملفات، ويبحث فيها، ويشغّل الأوامر، ويعدّل الكود ويفحص عمله، في حلقة، حتى تنتهي المهمة أو يحتاجك. وهذا يجعله أقوى طريقة لاستخدام Claude في البرمجيات، والطريقة التي تهم فيها الصلاحيات أكثر من غيرها.

Claude Code في هذا الفصل حقيقي، الإصدار 2.1.331، يعمل على جهاز الكتاب. ونموذجه وحده خادم التدريب: الردود مكتوبة مسبقاً، لكن الملف الذي يقرؤه، والاختبارات التي يشغّلها، والأمر الذي يُرفض، وحساب تكلفته، وحد إنفاقه كلها سلوك Claude Code نفسه.

{{n}}.1 التثبيت وتسجيل الدخول

Claude Code برنامج سطر أوامر. ويسرد توثيق Anthropic طرق تثبيته (مثبّت أصلي، أو حزمة لنظامك، أو npm)؛ ومع وجود Node.js على جهازك، npm أقصرها:

npm install -g @anthropic-ai/claude-code
claude --version



أول مرة تشغّل فيها claude، يطلب منك تسجيل الدخول، باشتراك Claude أو بحساب Claude Console يدفع لكل token عبر مفتاح API. ويعمل أيضاً في محررات مثل VS Code وJetBrains، وفي تطبيق الحاسوب وعلى الويب؛ وهو الوكيل نفسه في كل منها، ويستخدم هذا الجزء من الكتاب الطرفية لأن كل شيء فيها مرئي.



هل تعلم؟
يقرأ Claude Code المتغيرين نفسيهما اللذين تقرؤهما الحزمة، ANTHROPIC_BASE_URL وANTHROPIC_API_KEY. وهكذا يوجّهه هذا الفصل إلى خادم التدريب، وهكذا توجّهه الشركات عبر بوابتها أو عبر مزوّد سحابي.



{{n}}.2 طريقتان لتشغيله



شغّل claude في مجلد مشروع فتحصل على جلسة تفاعلية: تكتب، ويعمل Claude، وتستطيع توجيهه، والموافقة على أفعاله، وكتابة أوامر تبدأ بشرطة مائلة: /help للقائمة، و/model لتغيير النموذج، و/clear للبدء من جديد، و/compact لتلخيص جلسة طويلة والإكمال، و/permissions لرؤية المسموح. وهكذا ستستخدمه معظم الوقت.



وشغّل claude -p مع أمر فتحصل على وضع الطباعة: مهمة واحدة، بلا أسئلة، والجواب على المخرج القياسي. وهكذا تستخدم السكربتات ومهام التكامل المستمر وهذا الكتاب Claude Code:






قرأ Claude الملف price.mjs قبل أن يجيب؛ والأقسام التالية تُظهر تلك الخطوة. والجواب من خادم التدريب؛ والنموذج الحقيقي يشرح الملف بكلماته، ويجب أن يلاحظ المشكلة نفسها، التي يجعلها بقية الفصل مرئية.

{{n}}.4 الصلاحيات



أدوات Claude Code مجموعتان. القراءة (الملفات، والبحث، وقائمة الملفات) مسموحة افتراضياً. وكل ما يغيّر شيئاً أو يشغّل شيئاً (تعديل الملفات، وتشغيل الأوامر، والجلب من الويب) يحتاج صلاحية، تُعطى مرة، أو لجلسة، أو بقاعدة. والقاعدة تسمّي أداة، وللأوامر، الأمر:






--allowedTools "Bash(node --test)" يسمح بهذا الأمر بالضبط، ولا شيء غيره: لا node --test --watch، ولا rm. وهذه المرة شُغّلت الاختبارات، فعلاً، وعادت نتيجتها الحقيقية إلى النموذج: الفاتورة الصحيحة تنجح، والفاتورة بالقروش تفشل، خطأ parseInt نفسه من الفصل 4. والقواعد نفسها يمكن أن تعيش في ملف إعدادات، لك أو للفريق كله (الفصل 8).



وأوضاع الصلاحيات تغيّر الافتراضي لجلسة كاملة: default يسأل عن كل فعل؛ وacceptEdits يترك Claude يعدّل الملفات دون سؤال لكنه يسأل قبل الأوامر؛ وplan يتركه يقرأ ويخطط دون أن يغيّر شيئاً، وهي البداية الصحيحة لمهمة كبيرة. وهناك وضع يتخطى كل فحوص الصلاحيات: موجود لبيئات معزولة تُرمى بعد الاستخدام، ولا مكان له على جهاز فيه مفاتيحك وبريدك وكود شركتك.



انتبه
اسمح بالأوامر بأسمائها، لا بنمط لم تفكر فيه جيداً. Bash(npm test) قرار؛ وBash(*) تخلٍّ عن القرار. فقد يحوي المستودع تعليمات في ملف README أو في مهمة، مكتوبة لتجدها وكلاء الذكاء الاصطناعي، والأوامر التي سمحت بها هي ما تستطيع تلك التعليمات الوصول إليه.



اختبر نفسك
  1. لماذا رُفض node --test في التشغيل الأول ولم يُرفض في الثاني؟
  2. أي الأدوات يسمح بها Claude Code دون سؤال؟
  3. لماذا وضع plan طريقة جيدة لبدء مهمة كبيرة؟

{{n}}.5 كم يكلّف التشغيل



مع --output-format json، يعيد وضع الطباعة كائن JSON واحداً في النهاية: النتيجة، وعدد الأدوار، واستهلاك الـ tokens، والتكلفة. والسكربت يحتفظ بما يحتاجه:








دوران (قراءة الملف، ثم الإجابة)، ونحو سبعة سنتات. وانظر إلى الـ tokens: اثنا عشر ألفاً كُتبت في الذاكرة المؤقتة، واثنا عشر ألفاً قُرئت منها، ولا شيء تقريباً غير ذلك. فقبل أن يقول أمرك كلمة، يرسل Claude Code تعليماته وأوصاف أدواته، وهذا معظم كل طلب. والتخزين المؤقت يجعل الدور الثاني رخيصاً؛ والأول ما زال يدفع ثمن كتابة الذاكرة المؤقتة. وخادم التدريب يعدّ الـ tokens تقريبياً، فستختلف الأرقام الحقيقية، لكن الشكل لا يختلف: سياق الوكيل الثابت جزء كبير من تكلفته، والتكلفة لكل دور.



نصيحة
مع الاشتراك، يُحسب استخدام Claude Code من حدود خطتك لا فاتورة؛ ومع مفتاح API، يُحاسب كل دور. وفي الحالتين، /cost في الجلسة التفاعلية ومخرجات JSON في وضع الطباعة تخبرانك بما استخدمته المهمة. انظر بعد بضع مهام، فتعرف كم يكلّف عملك.

الملخص



    

  • Claude Code وكيل في طرفيتك: يقرأ، ويبحث، ويشغّل، ويعدّل، في حلقة، داخل مشروعك.
    • 

  • الجلسات التفاعلية للعمل معه؛ ووضع الطباعة (-p) للسكربتات، بنص أو JSON أو تدفق أحداث.
    • 

  • القراءة مسموحة افتراضياً؛ والتغيير والتشغيل يحتاجان صلاحية، تُعطى بدقة، بقاعدة أو بوضع.
    • 

  • كل تشغيل يبلّغ عن أدواره والـ tokens والتكلفة؛ وتعليمات الوكيل نفسه جزء كبير ومخزَّن من كل دور.
    • 

  • حد الإنفاق يوقف الحلقة الهاربة، بعد الدور الذي يتجاوزه.
    • 




إجابات «اختبر نفسك»: 1. تشغيل أمر يحتاج صلاحية. في التشغيل الأول لم يسمح به شيء، ووضع الطباعة لا يستطيع أن يسأل، فرُفض؛ وفي الثاني، سمح --allowedTools "Bash(node --test)" بهذا الأمر بالضبط. 2. أدوات القراءة: قراءة الملفات، والبحث في محتواها، وسردها. 3. لأن Claude يقرأ ويقترح دون أن يغيّر شيئاً، فتستطيع فحص الاتجاه قبل أن يُعدَّل أي ملف.

تشغيل لا يستطيع تجاوز الميزانية


أعطِ Claude Code مهمة لا يستطيع إنهاءها، ودع حد الإنفاق يوقفه.


ستتدرب على: --max-budget-usd، وقراءة كيف انتهى التشغيل.


    

  1. اطلب شيئاً بلا نهاية: شغّل الاختبارات حتى تنجح، دون إصلاح أي شيء.
    2. 

  2. اسمح بأمر الاختبار وحده، وضع حداً من ثلاثين سنتاً.
    3. 

  3. راقب الحلقة، واقرأ سطر الملخص.
    4. 





تلميح: انتهى التشغيل بـ error_max_budget_usd عند 0.3301 دولار، فوق الحد بقليل: فـ Claude Code يفحص الميزانية بين الأدوار، فيكتمل الدور الذي يتجاوزها. فاضبط الحد تحت ما تستطيع تحمّله، لا عنده. ولاحظ ما أخطأ فيه «النموذج» المكتوب: كرر أمراً لا يمكن أن تتغير نتيجته. والنماذج الحقيقية تفعل هذا أيضاً، والحد هو ما يوقفها.
