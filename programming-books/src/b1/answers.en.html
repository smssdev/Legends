Appendix

Answers to the Exercises

Try every exercise yourself before you look here. When your answer differs from this one, that is not necessarily wrong: most programming problems have several good solutions. If yours works for normal and unusual cases, and you can explain it, it is a good answer. The full code for every answer is in the book’s code repository.
