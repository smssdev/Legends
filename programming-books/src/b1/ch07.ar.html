الفصل 7

التخطيط بـ Flexbox وGrid

ستتعلم في هذا الفصل أن

  • تضع العناصر في صف أو عمود بـ Flexbox
  • تباعد العناصر وتحاذيها وتوسّطها في الاتجاهين
  • تبني تخطيطات ثنائية الأبعاد بـ CSS Grid
  • تجعل الصفحات تتكيف مع كل شاشة باستعلامات الوسائط
  • تعطي صفحتك التعريفية تخطيطاً حقيقياً متجاوباً

لسنوات طويلة كان وضع صندوقين جنباً إلى جنب في صفحة ويب صعباً على نحو مدهش، وكان المطورون يستخدمون حيلاً ذكية تنكسر بسهولة. أما اليوم ففي CSS أداتان صُممتا للتخطيط بالذات: Flexbox لترتيب الأشياء على خط واحد، وGrid للصفوف والأعمدة معاً. وبهما صارت التخطيطات التي كانت تستغرق يوماً تُكتب في أسطر قليلة.

معلومة طريفة: توسيط عنصر عمودياً كان أشهر نكتة بين مطوري الويب. وفي القسم 7.2 من هذا الفصل ستفعله في ثلاثة أسطر!

7.1 Flexbox: صف من الصناديق

عناصر الكتلة تتكدس عادة من الأعلى إلى الأسفل. أضف display: flex إلى العنصر الأب، فيصطف أبناؤه في صف. ويُسمى الأب حاوية مرنة (flex container)، وأبناؤه المباشرون عناصر مرنة (flex items).





ثلاث خصائص تقوم بمعظم العمل:





الخاصيةقيم شائعةماذا تفعل



gap8px و1remالمسافة بين العناصر، ولا مكان غيره


justify-contentflex-start وcenter وspace-between وflex-endأين تقف العناصر على امتداد الصف


align-itemsstretch وcenter وflex-start وflex-endكيف تصطف العناصر عرضياً (رأسياً في الصف)






ولاحظ أن «البداية» تعني حيث يبدأ اتجاه القراءة. ففي النسخة العربية من الصفحة تضع CSS نفسها القائمة على اليمين، بلا أي كود إضافي. فـ Flexbox وGrid مبنيتان على الاتجاهات المنطقية التي تعرفت عليها في الفصل 6.



الصفوف والأعمدة والالتفاف



flex-direction: column تحوّل الصف إلى عمود. وflex-wrap: wrap تسمح للعناصر بالانتقال إلى سطر جديد حين لا تكفي المساحة بدل أن تنضغط. وعلى العنصر نفسه، flex: 1 تعني «تمدد لتملأ المساحة الفارغة»، وهكذا تجعل خانة البحث تتمدد بجانب زر ثابت الحجم.





7.2 توسيط أي شيء



اجمع justify-content: center وalign-items: center، فيقف العنصر في منتصف حاويته تماماً، أفقياً ورأسياً:





body {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 260px;
}




ثلاثة أسطر! المطورون الذين تعلموا CSS قبل Flexbox ما زالوا يبتسمون حين يرون هذا. لكن الحاوية تحتاج ارتفاعاً: هنا أعطتها min-height واحداً. وبدونه يكون الصندوق بطول محتواه فقط، فلا يبقى مكان للتوسيط.



7.3 Grid: الصفوف والأعمدة معاً



Flexbox ترتب العناصر على خط واحد، أما CSS Grid فترتبها في بعدين معاً، مثل جدول أو جدول بيانات. ضع display: grid على الحاوية وصِف أعمدتها:







السطر السحري هو:


grid-template-columns: repeat(auto-fit, minmax(140px, 1fr));



اقرأه من الداخل إلى الخارج. 1fr تعني «جزءاً واحداً من المساحة الفارغة». وminmax(140px, 1fr) تعني «140 بكسل على الأقل، وإلا فتقاسموا المساحة بالتساوي». وrepeat(auto-fit, …) تعني «أعمدة كهذه بقدر ما يتسع». فتحصل على أربعة أعمدة في الشاشة العريضة، وعمودين في الهاتف، دون أن تكتب قاعدة واحدة لأي منهما. وهذا قلب التصميم المتجاوب.





تكتبتحصل على



grid-template-columns: 1fr 1frعمودين متساويين


grid-template-columns: 200px 1frشريط جانبي ثابت وعمود رئيسي مرن


grid-template-columns: repeat(3, 1fr)ثلاثة أعمدة متساوية


grid-column: 1 / -1 (على عنصر)يمتد العنصر على الأعمدة كلها، من أول خط إلى آخر خط






7.4 تخطيط الصفحة بالمناطق المسماة



وتستطيع Grid أن تخطط صفحة كاملة. تعطي كل جزء اسماً، ثم «ترسم» التخطيط بهذه الأسماء، كأنه رسم بالحروف:





.page {
  display: grid;
  grid-template-columns: 180px 1fr;
  grid-template-areas:
    "head head"
    "side main"
    "foot foot";
  gap: 10px;
}
header { grid-area: head; }
aside  { grid-area: side; }
main   { grid-area: main; }
footer { grid-area: foot; }





كل سطر بين علامتي تنصيص صف، وكل كلمة خلية. و"head head" تعني أن الترويسة تمتد على العمودين. وصار تغيير التخطيط كله مسألة إعادة رسم الصورة، وهذا بالضبط ما نفعله للشاشات الصغيرة.



7.5 التصميم المتجاوب باستعلامات الوسائط



أكثر من نصف زيارات الويب تأتي من الهواتف. واستعلام الوسائط (media query) يطبق CSS فقط حين يصح شرط ما، وغالباً عرض الشاشة:



@media (max-width: 600px) {
  .page {
    grid-template-columns: 1fr;
    grid-template-areas: "head" "main" "side" "foot";
  }
}



في الشاشات التي عرضها 600 بكسل أو أقل تصير الصفحة عموداً واحداً، وينتقل المحتوى الرئيسي فوق الشريط الجانبي، لأن المحتوى على الهاتف هو ما جاء الناس من أجله:





عادة المحترفين: الهاتف أولاً
معظم المحترفين يكتبون تخطيط الهاتف أولاً قاعدةً افتراضية، ثم يضيفون قواعد @media (min-width: …) للشاشات الأكبر. فتخطيطات الهاتف أبسط غالباً، فتبقى CSS أبسط. واختبر دائماً بشريط الأجهزة في أدوات المطورين، وعلى هاتف حقيقي حين تستطيع.



Flexbox أم Grid؟
قاعدة بسيطة: استخدم Flexbox لصف من الأشياء (قائمة، أو صف أزرار، أو وسوم، أو رأس بطاقة)، وGrid لتخطيط من الأشياء (صفحة، أو معرض، أو لوحة تحكم). وهما تعملان معاً بانسجام: صفحة بـ Grid يمكن أن تحوي قوائم بـ Flexbox، والعكس.



اختبر نفسك
  1. أي خاصية تجعل أبناء العنصر يصطفون في صف؟
  2. ما معنى 1fr في الشبكة؟
  3. ماذا يفعل @media (min-width: 700px) { … }؟
الإجابات في آخر الفصل، بعد الخلاصة.



7.6 مشروع: صفحة تعريفية متجاوبة



صفحتك التعريفية جميلة، لكنها ما زالت عموداً واحداً طويلاً. فلنضف جزءاً سادساً إلى style.css فيه تخطيط حقيقي، دون أن يتغير شيء في HTML.










انظر ماذا يفعل كل جزء:


    

  • صار header حاوية مرنة تلتف. ففي الشاشة العريضة تقف الصورة والاسم جنباً إلى جنب، وflex-basis: 100% تُجبر القائمة على سطر خاص بها.
    • 

  • وmain شبكة لها gap، فتتباعد البطاقات بالشبكة لا بهوامشها.
    • 

  • وقائمة المهارات حاوية مرنة تلتف: تنتقل الوسوم إلى سطر جديد في الشاشات الضيقة.
    • 

  • وداخل استعلام الوسائط يأخذ main عمودين، وتمتد بطاقة «عني» عليهما بـ grid-column: 1 / -1.
    • 

  • وpadding-inline خاصية منطقية: في الصفحة العربية تنتقل الحشوة الإضافية إلى الجهات الصحيحة وحدها.
    • 




أخطاء شائعة





الخطأماذا يحدثالعلاج



وضع display: flex على العناصر بدل الأبلا يصطف شيءflex وgrid توضعان على الحاوية


استخدام الهوامش للمباعدة بين عناصر flex أو gridمسافات غير متساوية عند الأطرافاستخدم gap


التوسيط الرأسي في حاوية بلا ارتفاعلا يتحرك العنصرأعط الحاوية height أو min-height


نسيان وسم viewportتعرض الهواتف صفحة حاسوب صغيرة، وتبدو استعلامات الوسائط معطلةأبقِ <meta name="viewport"> في head


عروض ثابتة مثل width: 900pxتمرير أفقي على الهواتفاستخدم max-width و% وfr






الخلاصة



    

  • display: flex تصف الأبناء في صف (أو عمود). واستخدم gap وjustify-content وalign-items.
    • 

  • لـ Flexbox محور رئيسي ومحور عرضي، وflex-wrap: wrap تنقل العناصر إلى أسطر جديدة.
    • 

  • justify-content: center مع align-items: center توسّط أي شيء.
    • 

  • display: grid تصنع صفوفاً وأعمدة. وfr تقسم المساحة الفارغة، وrepeat(auto-fit, minmax(…, 1fr)) تصنع معارض متجاوبة.
    • 

  • grid-template-areas ترسم تخطيط الصفحة بالأسماء.
    • 

  • استعلامات الوسائط تطبق CSS عند عروض معينة للشاشة. وصمّم للهاتف أولاً.
    • 

  • Flexbox لصف من الأشياء، وGrid لتخطيط من الأشياء.
    • 




إجابات «اختبر نفسك»: 1. display: flex على الأب. 2. جزء واحد من المساحة الفارغة: عمودان بـ 1fr يتقاسمانها بالتساوي. 3. يطبق CSS التي بداخله فقط حين يكون عرض الشاشة 700 بكسل على الأقل.



تمارين



    

  1. سهل اصنع صفاً من ثلاثة أزرار بـ Flexbox، بينها 12 بكسل، في منتصف الصفحة.
    2. 

  2. سهل غيّر المعرض ليكون عرض كل عمود 200 بكسل على الأقل. كم عموداً تحصل عليه مع عروض مختلفة للنافذة؟
    3. 

  3. متوسط ابنِ بطاقة منتج فيها صورة في جهة ونص في الجهة الأخرى بـ Flexbox. وفي الشاشات الأضيق من 500 بكسل ضع الصورة فوق النص.
    4. 

  4. متوسط أضف منطقة رابعة، ads، إلى layout.html، تظهر في نهاية المحتوى الرئيسي على الشاشات العريضة، وفي أسفل الصفحة تماماً على الهواتف.
    5. 

  5. تحدٍّ أعد بناء تخطيط الصفحة الرئيسية لموقع أخبار تحبه بمناطق Grid وصناديق ملونة بدل المحتوى الحقيقي، واجعله يعمل على عروض 360 و768 و1280 بكسل.
    6. 




حلول التمارين في آخر الكتاب، وفي مستودع الكود الخاص بالكتاب.
