Before you begin

How to Use This Book

This book is for anyone who has never written a line of code. You do not need to be good at maths, you do not need an expensive computer, and you do not need to know anything about programming. You need curiosity, a little patience, and about an hour a few times a week.

What you need

  • A computer with Windows, macOS or Linux. A phone or tablet is not enough for writing code, but it is perfect for testing your pages.
  • A modern web browser, such as Chrome, Edge or Firefox.
  • Free tools that you will install in Chapter 3: Visual Studio Code and Node.js. Later, in Chapter 15, Git.

How the book is organised

The eighteen chapters are grouped in four parts. Read them in order: each chapter builds on the ones before. Part 1 teaches you to think like a programmer, Part 2 builds web pages with HTML and CSS, Part 3 brings them to life with JavaScript, and Part 4 teaches you to work like a professional and to publish a real app.

Every chapter follows the same pattern: a list of what you will learn, explanations with real examples, a project that uses the new ideas, a table of common mistakes, a summary, and exercises at three levels. Answers to the exercises are at the end of the book.

Reading the examples

Every example in this book is a real file that was run while the book was being made, and every output you see is exactly what it printed. A dark tab above a listing gives the file’s name; create that file in your project folder, type the code yourself, and run it.

  • A grey box with three coloured dots shows what appears in the terminal.
  • In terminal sessions, a line starting with $ is a command for you to type (without the $); the lines below it are the computer’s answer.
  • A picture in a browser frame shows how a page looks in the browser. The width in the corner tells you how wide the window was.

Meet Bit

Bit is a small purple robot who loves computers and will walk with you through the whole book. You will find Bit in speech bubbles, welcoming you to new chapters, sharing tricks, and cheering you on before the projects. Bit’s advice is always worth reading.

The code repository

Every example, every project and every exercise answer is also available in the book’s code repository, so you can compare your work or start from a working version when you are stuck. But type the examples yourself first: your fingers learn faster than your eyes.
