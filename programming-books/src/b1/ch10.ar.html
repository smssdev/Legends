الفصل 10

الدوال

ستتعلم في هذا الفصل أن

  • تحزم قطعة من الكود في دالة لها اسم وتُعاد استخدامها
  • تُدخل المعلومات بالمعاملات وتُخرج النتائج بـ return
  • تفهم أين تعيش المتغيرات: النطاق
  • تكتب دوال سهمية قصيرة وتستخدمها مع map وfilter وreduce
  • تعيد بناء شبّاك التذاكر من دوال صغيرة واضحة

لقد استخدمت دوال كثيرة دون أن تكتب واحدة: console.log وpush وjoin. كتبها أحدهم مرة، وأعطاها أسماء، والآن يستخدمها ملايين المبرمجين كل يوم. وفي هذا الفصل ستكتب دوالك أنت. فالدوال هي الطريقة التي يحوّل بها المبرمجون برنامجاً طويلاً متشابكاً إلى قطع صغيرة، كل واحدة تتقن وظيفة واحدة.

تخيّل الدالة آلة صغيرة: تضع فيها شيئاً (عمراً مثلاً)، فتعمل، فيخرج منها شيء (سعر مثلاً). تبني الآلة مرة واحدة، وتستخدمها كلما شئت دون أن تفكر في أحشائها مرة أخرى.

10.1 دالتك الأولى






للدالة ثلاثة أجزاء:


    

  • الاسم، greet، وبه تستدعيها. وأسماء الدوال أفعال غالباً، لأن الدوال تفعل أشياء.
    • 

  • المعاملات (parameters) بين القوسين، وهنا name: المدخلات. وداخل الدالة يعمل المعامل كأنه متغير.
    • 

  • الجسم بين القوسين المعقوصين: الكود الذي يُنفَّذ كلما استُدعيت الدالة.
    • 




تعريف الدالة وحده لا يفعل شيئاً. فالكود لا يُنفَّذ إلا حين تستدعي الدالة بكتابة اسمها ثم القوسين: greet("سارة"). والقيمة التي تمررها، "سارة"، تُسمى وسيطاً (argument)، وداخل الدالة يصير name مساوياً لـ "سارة".



إرجاع قيمة



الكلمة return ترسل قيمة إلى من استدعى الدالة، وتنهي الدالة فوراً. ولهذا تعمل const message = greet("سارة"): يُستبدل الاستدعاء بالقيمة المُرجعة. والدالة التي ليس فيها return تعيد undefined.

عادة المحترفين: وظيفة واحدة لكل دالة
الدالة الجيدة تفعل شيئاً واحداً، واسمها يقول ما هو. فإن احتجت حرف «و» لتصفها («تحسب السعر وتطبع الإيصال») فقسّمها إلى دالتين. والدوال الصغيرة أسهل في القراءة والاختبار وإعادة الاستخدام والإصلاح.

10.4 النطاق: أين تعيش المتغيرات



المتغير الذي يُنشأ داخل دالة لا يوجد إلا داخلها، ويُسمى هذا النطاق (scope):








total يعيش داخل withTax، وخارجها لا وجود له، فتكون typeof total مساوية لـ "undefined". أما tax الذي أُنشئ خارجها فيمكن قراءته داخل الدالة. والقاعدة: الكود يرى المتغيرات في كتلته وفي الكتل المحيطة بها، ولا يرى أبداً ما في الكتل التي بداخله.



والنطاق نعمة. فمعناه أن دالتين تستطيع كل منهما أن تملك متغيراً اسمه total دون أن تزعج إحداهما الأخرى، تماماً كما يمكن لعائلتين أن يكون في كل منهما طفل اسمه عمر.



نصيحة
أبقِ المتغيرات في أضيق نطاق ممكن. فالمتغير الذي لا يُستخدم إلا داخل دالة يجب أن يُنشأ داخلها. وكلما قلّت الأماكن التي تستطيع تغيير متغير، قلّت الأماكن التي يختبئ فيها الخطأ.



10.5 الدوال السهمية ودوال المصفوفات



في JavaScript طريقة أقصر لكتابة الدوال الصغيرة، تُسمى الدوال السهمية (arrow functions):



function double(n) { return n * 2; }   // a normal function
const double = (n) => n * 2;           // the same, as an arrow function



حين يكون الجسم تعبيراً واحداً، تُرجعه الدالة السهمية تلقائياً بلا return ولا أقواس معقوصة. وتتألق الدوال السهمية حين تعطي دالةً لدالة أخرى. وللمصفوفات ثلاث دوال مشهورة تفعل ذلك بالضبط:










الدالةماذا تفعلالنتيجة



map(f)تستدعي f على كل عنصر وتجمع النتائجمصفوفة جديدة بالطول نفسه


filter(f)تُبقي العناصر التي تُرجع لها f القيمة trueمصفوفة جديدة أقصر (أو مساوية)


reduce(f, start)تجمع كل العناصر في قيمة واحدة، مثل المجمِّعقيمة واحدة






الدالة التي تُمرَّر إلى دالة أخرى تُسمى دالة رد النداء (callback). فـ map تستدعي دالتك مرة لكل سعر، والسعر وسيطاً. وهذه الدوال الثلاث كثيراً ما تستبدل حلقة كاملة بسطر واحد مقروء، وستراها في كل مكان في الكود الاحترافي.



انتبه: 13.200000000000001؟
انظر إلى أول نتيجة لـ map: 12 × 1.1 أعطت 13.200000000000001 لا 13.2. هذه ليست علّة في JavaScript. فالحاسوب يحفظ الكسور بالنظام الثنائي (الفصل 1)، وكما أن 1/3 لا يُكتب بالضبط بالعشري، فإن 1.1 لا يُكتب بالضبط بالثنائي، وكل اللغات فيها هذا الأثر. وللعرض قرّب النتيجة بـ price.toFixed(2)، أما في المال فيحفظ المحترفون أعداداً صحيحة من أصغر وحدة، مثل القروش أو الهللات.



اختبر نفسك
  1. ما الفرق بين المعامل والوسيط؟
  2. ماذا تُرجع الدالة إن لم يكن فيها return؟
  3. ماذا تعطي [1, 2, 3].map((n) => n * 10)؟
الإجابات في آخر الفصل، بعد الخلاصة.



10.6 مشروع: شبّاك من الدوال



لنعد بناء الشبّاك كما يفعل المحترف: من دوال صغيرة، لكل واحدة وظيفة واحدة. دالة تعرف السعر الأساسي، ودالة تطبق يوم الأعضاء، ودالة تبني سطر الإيصال من بيانات الزائر:








كل زائر مكتوب بالشكل { name: "سارة", age: 34, member: true }، وهو كائن (object) يجمع عدة قيم تحت أسماء، وتقرؤها بنقطة: visitor.age. والكائنات موضوع الفصل القادم.



قارن هذا بالشبّاك الطويل في الفصل 8. صار لكل قطعة اسم يشرحها، وصار تغيير أي قطعة ممكناً دون لمس غيرها. فإن غيّرت السينما أسعارها غيّرت ticketPrice ولا شيء غيرها. وهذه قوة الدوال الحقيقية: ليست أسطراً أقل، بل أسطراً أوضح.



لاحظ كيف تُقرأ الدالة الأخيرة كأنها جملة: «السعر الأساسي هو سعر التذكرة لهذا العمر، والسعر هو الأساسي بعد يوم الأعضاء». الأسماء الجيدة تجعل الكود يشرح نفسه. وأنا أقول دائماً: الكود يُقرأ أكثر بكثير مما يُكتب.

الخلاصة



    

  • الدالة كود له اسم ويُعاد استخدامه. عرّفها بـ function name(params) { … } واستدعها بـ name(args).
    • 

  • المعاملات هي المدخلات، والوسائط القيم الممررة، ويمكن أن يكون للمعاملات قيم افتراضية.
    • 

  • return ترسل قيمة إلى المستدعي وتنهي الدالة.
    • 

  • المتغيرات تعيش في نطاقها: ما داخل الدالة لا يُرى خارجها.
    • 

  • الدوال السهمية ((n) => n * 2) صيغة قصيرة، ومثالية دوالَّ رد نداء.
    • 

  • map وfilter وreduce تحوّل المصفوفات وتختار منها وتجمعها.
    • 

  • اكتب دوالاً صغيرة لكل منها وظيفة واحدة واسم واضح.
    • 




إجابات «اختبر نفسك»: 1. المعامل هو الاسم في تعريف الدالة، والوسيط القيمة الفعلية الممررة عند استدعائها. 2. undefined. 3. [10, 20, 30].

قيّم كلمات المرور ضعيفة أو مقبولة أو قوية، بدوال مساعدة صغيرة تفحص كل منها شيئاً واحداً.


ستتدرب على: دوال تُرجع boolean، والإرجاع المبكر، والمرور على حروف النص، وجمع الدوال الصغيرة.


    

  1. اكتب hasDigit(text): مرّ على الحروف بـ for…of، وأرجع true بمجرد أن تجد رقماً، وبعد الحلقة أرجع false.
    2. 

  2. اكتب hasUpper(text): في النص حرف كبير إن تغيّر حين تحوّله إلى حروف صغيرة.
    3.
