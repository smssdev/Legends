1. Nowhere, and that is the lesson: the catalogue lists the spaces by hand, [('xs', Space.xs), …], so a new token is invisible until someone remembers to add it. Give Space one list of every value, static const all = {'xs': xs, 's': s, 'm': m, 'l': l, 'xl': xl, 'xxl': xxl}, and let the catalogue loop over it; from then on every new token appears by itself, in every theme.
  2. Everything that comes from Material’s ColorScheme turns blue: the filled Order buttons, the selected navigation item, the switch, and the tints of surfaces and cards. The prices and the tags stay as they were, because they come from the Brand extension, which the seed does not touch. That split is deliberate: Material’s roles follow the seed, and the brand’s own colours are chosen and tested by hand.
  3. brand.dart gets info and onInfo, with values in light and dark and a line in lerp; components.dart gets a case in the StatusTag switch, which the compiler demands as soon as the enum grows; the catalogue shows the new tag. The contrast test must check the new pair in both themes. No screen changes until one decides to use the new tag.
  4. The first to break is the card’s header row: a long drink name in large text and a tag share one line, and the name wraps into a narrow column or overflows. Buttons keep working because their height is a minimum, not a fixed size. The tokens help because the fix is made once, in the component: the header becomes a Wrap (or the tag moves under the name when space is short), and every screen that uses MenuCard is fixed together. Test it with MediaQuery(data: MediaQuery.of(context).copyWith(textScaler: TextScaler.linear(2))) in a widget test.
  5. Add 'a hand-made text style': RegExp(r'TextStyle\(') to the rules; the screens already use context.text.titleLarge and friends. A copyWith on a theme style is acceptable for a role colour from the theme, as the price does with context.brand.accent, because the size, weight and line height still come from the design system. When the same copyWith appears in two places, it has become a style of its own: give it a name in the design system (priceStyle).
