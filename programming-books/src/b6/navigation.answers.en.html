1. “No order number 9” and “No order number ?”, both inside the normal layout, with the Orders tab selected and a back arrow. Both addresses match the route /orders/:id, so the router builds OrderPage; only the page knows that order 9 does not exist, and int.tryParse('abc') gives null instead of crashing. The not-found page is only for addresses that match no route at all.
  2. The back arrow disappears. A top-level route has no parent in the tree, so opening it builds a stack of one page: there is nothing to go back to. (Outside the shell it also loses the tabs.) Nesting is not decoration: it is what tells the router which pages belong under a deep link.
  3. onDestinationSelected: (i) => shell.goBranch(i, initialLocation: i == shell.currentIndex). goBranch normally restores the branch’s last location, which is what keeps the cake open; with initialLocation: true it goes to the branch’s first route instead. Passing it only for the tab that is already selected gives the behaviour people know from most apps: tap another tab to return to where you were, tap the current tab again to return to its start.
  4. Give the child route its own redirect: GoRoute(path: ':id', redirect: (context, state) => drinks.containsKey(state.pathParameters['id']) ? null : Routes.menu, …). It is usually worse: the person followed a link, landed on the menu, and does not know why. A message that says “no drink called coffee” explains it. Redirects are better for addresses that moved, such as an old id renamed, where the destination really is the same thing.
  5. Make the sign-in state a Notifier<bool> provider, and create the router in a provider: final routerProvider = Provider((ref) { final refresh = ValueNotifier(0); ref.listen(authProvider, (previous, next) => refresh.value++); ref.onDispose(refresh.dispose); return GoRouter(refreshListenable: refresh, redirect: (context, state) { final signedIn = ref.read(authProvider); … }, routes: […]); });. The app watches routerProvider for routerConfig, and a test overrides authProvider in its ProviderScope, as in Chapter {{n-1}}. The router is created once per container, never in build.
