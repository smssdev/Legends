The p95 is the time under which 950 of the 1,000 requests finish. 940 finished within 100 ms and 990 within 500 ms, so the 950th falls between 100 and 500 ms; Prometheus interpolates inside the bucket and would report about 180 ms. The p99 (the 990th request) is about 500 ms. With buckets this wide, add one at 250 ms if the exact value matters.
  3. Every customer creates a new series for every route and status, so the number of series grows with the customer base: after a month, hundreds of thousands of series, memory and storage in the metrics system explode, and queries become slow or fail. The question (“which customers get errors?” or “how many requests does this customer make?”) belongs to the logs or traces, which carry the customer id on each event and can be searched and counted when needed; or to a dedicated business table if it is asked often.
  4. Without a timeout, a database that hangs (rather than refusing connections) makes every readiness check hang; the platform’s check times out, but the server piles up open checks and connections, and recovery is slower. Checking a slow partner API is worse: when the partner is slow, every server reports “not ready”, the load balancer removes all of them, and the whole shop goes down because one optional feature is degraded. Readiness should check only what this server cannot work without, with short timeouts; partners are watched with metrics and alerts instead.
  5. SLO: over 30 days, 99.5% of checkout requests succeed (any status below 500) and 95% complete within 800 ms. Paging alert: the error budget is burning fast, for example more than 5% of checkouts failing over the last 5 minutes and over the last hour (both, so a single blip does not wake anyone); this means customers are losing orders now. Ticket alert: the budget is burning slowly, for example the p95 above 800 ms for three hours, or 1% of checkouts failing over a day; this needs attention during working hours, not at night. The difference is urgency for users: page only when people are affected now and someone must act at once.
