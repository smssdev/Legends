Compare the count with four, and read each line: the risk in a decisions-only request is the opposite one, actions and proposals turned into “decisions”, such as the cold brew that was rejected.
  4. Ask for “each task reported as done, with the hash of the commit that did it”, then check each hash with log.includes(hash). A task with no hash, or a hash not in the log, is an unsupported claim. In the Arabic edition’s report, T5 and T6 would have had no hash to give; the request itself makes inventing progress harder.

Run it on both editions. The Arabic merge’s “9 May” passes a number check, because 9 is in the meeting, as an hour; a check of month names catches it, since May was never said.
