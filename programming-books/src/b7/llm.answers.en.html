1. The book’s run gave " " at 98.5%, then " noon" at 0.6% and " $" at 0.3%. If you wrote “8”, “9” and “noon”, you thought in words; the model thinks in tokens, and this tokenizer writes a space and the digits separately, so after “opens at” the next token is almost certainly a lone space, with the hour coming one step later. Prediction is per token, and that is exactly why it can surprise you.
  2. More expensive. A small function, export function total(items) { return items.reduce((sum, item) => sum + item.price * item.count, 0); }, was 15 “words” and 28 tokens, 1.87 per word against 1.18 for English prose: brackets, dots, operators and names like item.price are cut into separate tokens. Long files of code fill a context window faster than their length in lines suggests.
  3. In English, temperature 0.3 still gave “Brew & Co.” for all three seeds; at 0.7 each seed gave something different, one of them “Mug & Co.” and one an explanation instead of a name. The Arabic prompt already differed at 0.3, because its probabilities were flatter to begin with (Section {{n}}.3): when no token clearly wins, even a little randomness changes the answer. There is no universal threshold; it depends on how sure the model is.
  4. For PostgreSQL the model answered 5432, which is right. For the made-up “Brewlytics Server” it explained that it knows no such software, and then, because the question asked for a number only, ended with “Answer: 0”. A program that read only the last line would have stored a port of 0. Nothing in the format of an answer tells you whether it is true; what tells you is a source: the tool’s documentation, its configuration file, or running it and seeing what it listens on. And never force a model to answer in a form that leaves no room for “I don’t know”.

More context removed the inventions, but also the variety: with so little text, each pair of words has only one or two possible followers, so the model can only copy. Real models look at thousands of tokens and were trained on trillions, which is what lets them be both coherent and new, and also why their inventions are so convincing.
