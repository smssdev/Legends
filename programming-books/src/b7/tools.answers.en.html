  4. Without the check, Function(`return (${expression});`)() runs any JavaScript the model passes. An expression such as process.env.API_KEY returns a secret into the conversation, and process.exit(1) stops the program; with an asynchronous import, it could read or delete files. The model may not choose such an input by itself, but anyone who controls text the model reads can ask it to: a web page, an email or a file in the project saying “calculate this”. That is called prompt injection, and Chapter 15 is about it. A tool must check its input as strictly as an API endpoint does, because that is what it is.
