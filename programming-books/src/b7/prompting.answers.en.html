  4. The model returned "count": 100, although the schema said maximum: 20, and named the customer “office”. The grammar enforces the shape and the allowed words, but this version does not enforce number ranges. So the program must check: reject the order, or ask the customer to confirm a large order. That is the general rule: a schema narrows what the model can say; your code still decides what is acceptable.
  5. Run each case three times at 0.7 and record each run’s score; report the mean and the minimum. In production a prompt runs thousands of times, so the question is not “how well does it usually do?” but “how badly can it do?”. A prompt that scores 8, 8 and 3 has a good average and an unacceptable floor. Compare prompts by their minimum first, and use temperature 0 in production where you can, so the score you measured is the score you get.
