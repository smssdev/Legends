1. Price.vue: defineProps<{ value: number; currency: string }>() and the template <p class="price">{{ value.toFixed(2) }} {{ currency }}</p>. In ProductCard: <Price :value="product.price" currency="EGP" />. Notice the colon on :value but not on currency, which is a fixed string.
  2. Add discount?: number to Product, and in the card <span v-if="product.discount !== undefined" class="badge">-{{ product.discount * 100 }}%</span>.
  3. In Shop.vue: const count = ref(0); on each card @add="count++"; and above the grid <p>{{ count }} items in your cart</p>. The state lives in Shop because the cards only report the click; the shop owns the cart.
  4. Add | { status: "offline" } to the type, and a branch <p v-else-if="state.status === 'offline'" class="muted">You are offline.</p> before the last one. vue-tsc helps: until you add the branch, state.orders in the last branch is an error, because state might be offline there. It cannot tell you that the new state needs a nice message; that is still your job.
  5. In ShopSection.vue: <header><h2>{{ title }}</h2><slot name="actions" /></header>. An empty named slot draws nothing, so the slot is optional already. In Shop.vue: <template #actions><a href="/products">See all</a></template>. To avoid an empty wrapper when it is missing, use v-if="$slots.actions".
