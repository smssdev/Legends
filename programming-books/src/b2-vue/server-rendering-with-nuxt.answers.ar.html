  2. يحذّر Vue من عدم تطابق الإحياء: فالنص الذي رسمه الخادم (وقته) يختلف عما رسمه المتصفح بعد لحظة. ومع useState يقرأ المتصفح قيمة الخادم من الحمولة، فيتفقان.
  3. في الصفحة: const route = useRoute(); const sort = computed(() => route.query.sort === "price" ? "price" : undefined); const { data } = await useFetch("/api/products", { query: { sort } });. ولأن query تحمل قيمة محسوبة، يعيد تغيير العنوان الجلب. وفي المسار: const { sort } = getQuery(event)، وproducts.toSorted((a, b) => a.price - b.price) حين تكون "price".
  4. runtimeConfig: { shopEmail: "" } في nuxt.config.ts، وفي المسار const { shopEmail } = useRuntimeConfig(event)، وشغّل بـ NUXT_SHOP_EMAIL=shop@example.com node .output/server/index.mjs. ولا يجد curl -s localhost:3000/contact | grep shop@ شيئاً، لأن القيم الخاصة لا تدخل الحمولة أبداً.
