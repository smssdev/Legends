1. app/pages/about.vue calls useSeoMeta({ title: "About" }) and shows some text; the layout gets <NuxtLink to="/about">. It reads no data and nothing per request, so it should be prerendered: add "/about": { prerender: true }, and the build lists /about and its _payload.json.
  2. Vue warns about a hydration mismatch: the text the server rendered (its time) differs from what the browser rendered a moment later. With useState, the browser reads the server’s value from the payload, so both agree.
  3. In the page: const route = useRoute(); const sort = computed(() => route.query.sort === "price" ? "price" : undefined); const { data } = await useFetch("/api/products", { query: { sort } });. Because query holds a computed, changing the address refetches. In the route: const { sort } = getQuery(event), and products.toSorted((a, b) => a.price - b.price) when it is "price".
