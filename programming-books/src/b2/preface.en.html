Before you begin

How to Use This Book

This book is for developers who can already build something in the browser and want to build it the way senior engineers do: typed, tested, accessible, fast, secure, ready for two languages, and easy for a team to change. If you finished Code from Zero, the first book of this series, you are ready. If you learned elsewhere, you need about a year of JavaScript: functions, arrays and objects, the DOM, fetch, and Git.

Two editions, one book

The book exists in two editions, one for React and one for Vue, the two most widely used ways to build user interfaces. The chapters that do not depend on the framework, such as JavaScript in depth, TypeScript, testing, accessibility, performance, security and architecture, are the same in both, and their examples use the framework of your edition where one is needed. You are reading the React edition.You are reading the Vue edition. If your team uses the other framework, everything outside the framework chapters still applies, word for word.

Read the first two parts in order. After that, the chapters of the last two parts can be read in the order your work needs them, though each one assumes the parts before it.

Every chapter

Each chapter follows the same pattern, so you always know where you are: what you will learn; explanations built on real, running examples; a quick check in the middle; boxes with professional habits and common traps; a table of common mistakes; a summary; three practice projects (easy, medium and challenge) with steps and hints; and exercises at three levels. Answers to the quick checks follow each summary, and answers to the exercises are at the end of the book.

The projects matter more than anything else in the book. Reading about a skill is not having it. Do at least one project per chapter, preferably the medium one, before moving on.

  • A dark tab above a listing gives the file’s name and path in the project.
  • A box with three coloured dots shows what appeared in the terminal. A line starting with $ is a command; the lines below it are the answer.
  • A picture in a browser frame is a screenshot of the running example, with the window’s width in the corner.

What you need

  • A computer with Windows, macOS or Linux, and a modern browser.
  • Node.js 22 or later, Git, and an editor such as Visual Studio Code. Every library in the book is free and open source.
  • An account on GitHub or GitLab, for the chapters about pull requests and continuous integration.

The code repository

Every example, every project and every exercise answer is in the book’s code repository, in a folder per chapter. Type the examples yourself first, then use the repository to compare, or to recover when you are stuck.

A word from the author
