1. مع innerHTML يعمل <svg onload="window.hacked=true">، ويعمل <iframe src="javascript:…"> في متصفحات كثيرة: فكل عنصر بخاصية معالج حدث باب. ومع textContent لا يعمل أي منها. والدرس: الحيل أكثر بكثير من أن تُمنع واحدة واحدة.
  2. ملفات جلسات المواقع جيدة الإدارة تكون عادة HttpOnly وSecure وSameSite=Lax أو Strict. أما ملفات التحليلات والتفضيلات فكثيراً ما تقرؤها JavaScript، ولا بأس بذلك ما دامت لا تحمل أسراراً.
  3. في وضع التبليغ فقط ما زال Console يبلّغ عن المخالفة، لكن السكربت المضمّن يعمل: فتصير «عمل السكربت؟» نعم. ولهذا وُجد هذا الوضع: ترى كل ما كانت السياسة ستمنعه في موقع حي، فتصلحه، ثم تفرضها.
  4. function safeUrl(input: string): string { try { const url = new URL(input); return url.protocol === "https:" || url.protocol === "http:" ? url.href : "#"; } catch { return "#"; } }. واختبر رابط https عادياً، ورابط http، وjavascript:alert(1)، وJavaScript:alert(1) (بحروف كبيرة)، ونصاً ليس رابطاً أصلاً.
  5. يسمّي التنبيه الحزمة، والإصدارات المصابة والمصلحة، ودرجة الخطورة، وكيف تُستغل العلّة. وكثيراً ما تكون الدالة المصابة في أداة بناء لا تصل إلى المستخدمين، أو في كود لا تستدعيه أبداً، فيكون الرد الصحيح ترقية، أو ملاحظة تشرح لماذا لا ينطبق.
