Before you begin

How to Use This Book

This book takes you from your first line of Dart to your first app in Google Play and the App Store. It is written for people who already know the basics of programming: values and variables, decisions, loops and functions. If you read Parts I and III of Code from Zero, the first book of this series, you are ready. If you learned somewhere else, in any language, you are ready too: the book explains everything that is new in Dart and in Flutter from the beginning, and points out where they differ from JavaScript.

What you need

  • A computer with Windows, macOS or Linux, with at least 8 GB of memory: the Android emulator needs room. To build apps for the iPhone you need a Mac, because Apple’s tools only run there; everything else in the book works on any of the three.
  • An Android phone or an iPhone is welcome but not required: an emulator on your computer does the same job.
  • Free tools that you will install in Chapter 1: Flutter (which includes Dart), Visual Studio Code, and Android Studio.

How the book is organised

The fifteen chapters are grouped in three parts. Read them in order: each one builds on the ones before.

  • Dart installs Flutter and teaches the language every Flutter app is written in: its basics, classes and null safety, collections, and code that waits for things with futures and streams.
  • Building Screens is about what the user sees: widgets, layouts that fit every screen, lists, images and themes, moving between screens, and forms.
  • Real Apps adds what real apps need: state that changes, data from the internet, data saved on the phone, Arabic and English with right-to-left layouts, a complete notes app that uses everything, and publishing to the two stores.

Every chapter

Each chapter follows the same pattern, so you always know where you are: what you will learn; explanations built on real, running examples; a quick check in the middle; boxes with tips, traps and professional habits; a table of common mistakes; a summary; three practice projects (easy, medium and challenge) with steps and hints; and exercises at three levels. Answers to the quick checks follow each summary, and answers to the exercises are at the end of the book.

The projects matter more than anything else. Reading about a skill is not having it. Build at least one project per chapter before moving on.

Real code, real output

Every listing in this book is a real file, every terminal session was recorded while the book was being made, and every screenshot is the real app. When Chapter 1 shows a test failing and then passing, that is what Flutter printed. You will see the same results with the same versions:

ToolVersion
Flutter3.50.1 (stable)
Dart3.14.0 (it comes with Flutter)
material_ui1.1

The screenshots were taken from the app running in a browser at the size of a phone screen, which is exactly how Flutter draws it on a phone: Flutter paints every pixel itself, so the same code looks the same everywhere. Tools change quickly. If a newer version prints something slightly different, read the difference: it usually teaches you what changed and why.

Reading the examples

  • A dark tab above a listing gives the file’s name and its path in the project. Type the code yourself, then run it.
  • A box with three coloured dots shows what appeared in the terminal. A line starting with $ is a command for you to type (without the $); the lines below it are the answer. A line starting with # says what the next command is for.
  • A picture in a phone outline is a screenshot of the app.

Bit is back

Bit, the small purple robot from the earlier books, walks with you through this one too. This time Bit wants to live on your phone. You will find Bit in speech bubbles, sharing tricks it learned the hard way and cheering you on before the projects.

The code repository

Every example, every project and every exercise answer is in the book’s code repository, so you can compare your work or start from a working version when you are stuck. For apps, the repository keeps the files you write (lib/, test/ and pubspec.yaml); flutter create makes the rest, exactly as Chapter 1 shows. But type the examples yourself first: your fingers learn faster than your eyes.

A word from the author

A phone is the computer most people in the world carry every day. Building for it, in your own language, for the people around you, is one of the most rewarding things a developer can do. This book exists in English and in Arabic, written for each language rather than translated word for word, and its apps speak both. Welcome, and enjoy the journey.
