1. Compute the name in build: final typed = name.text.trim(); then final who = typed.isEmpty ? 'stranger' : typed.toUpperCase();. trim() removes the spaces at both ends, so a name of only spaces counts as empty. Change what you show, never what people typed: the field still holds their text exactly.
  2. A name: TextInputType.name (capital letters at the start of words on many phones), next. A phone number: phone, next. An email: emailAddress, next, with autocorrect: false. A note: multiline with maxLines above 1, and the default action, which makes Enter a new line. The last field: done, and onSubmitted can send the form, so people never have to look for the button.
  3. Remove the spaces in the validator: (value) => RegExp(r'^[0-9]{11}$').hasMatch((value ?? '').replaceAll(' ', '')) ? null : '...'. Do the same when you read the value to send it, so that the server receives 01001234567. Accepting what people naturally type, then cleaning it, is kinder than refusing it.
  4. Add a listener, or call setState in the name field’s onChanged, and give the button onPressed: name.text.trim().isEmpty ? null : place. A disabled button is clear for one obvious missing field; but when several fields are wrong, a greyed-out button does not say what is wrong, and people are left guessing. Long forms are usually better with an enabled button and clear messages after the tap.
  5. Keep a TimeOfDay? pickup in the state, and a button that calls final t = await showTimePicker(context: context, initialTime: TimeOfDay.now());. If t is not null, check t.hour >= 8 && t.hour < 22; store it with setState if it passes, or show a snack bar explaining the opening hours if it does not. To make it part of the form’s validation, put it in a FormField<TimeOfDay>, as the terms checkbox of Project {{n}}.2 does.
