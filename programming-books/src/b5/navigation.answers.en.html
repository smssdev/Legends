  2. showDialog(context: context, barrierDismissible: false, builder: ...). The barrier is the dark area around the dialog; making it not dismissible means the only ways out are the buttons. Keep this for decisions that must be made; for most dialogs, tapping outside to cancel is what people expect.
  3. Wrap each tab’s icon: Tab(icon: Badge(label: Text('3'), child: Icon(Icons.local_cafe)), text: 'Drinks'). Badge draws a small coloured label on the corner of its child, positioned for you, the same idea as Chapter 6’s cart badge, ready-made. Count the items from the same lists the pages show, so the numbers can never disagree.
  4. Coming back, the long list starts at the top again. Without IndexedStack, the page you leave is removed from the tree, and its state, including the scroll position, is thrown away; coming back builds a new one. IndexedStack keeps all the pages in the tree and only shows one, so each keeps its state.
  5. Declare GoRoute(path: '/orders/:id', ...) at the top level, next to /. context.go('/orders/7') replaces the whole stack with the one that matches the address: the order page alone, with no back arrow, because /orders/7 is not below the drink in the route tree. context.push('/orders/7') puts the order page on top of the current stack, so the back arrow returns to the drink. Use go to move to a place in the app, and push for a detour that the user will come back from.
