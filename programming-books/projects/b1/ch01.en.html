Project 1.1 · Easy

Your life in numbers

Write a program that tells you how many months, days, hours and minutes you have been alive (roughly).

You will practise: running JavaScript, numbers and the * operator, and printing several values.

  1. Create a file called my-numbers.js in your code-from-zero folder, or open the browser console.
  2. Write const age = 20; on the first line, with your own age instead of 20.
  3. Print the number of months: console.log("Months:", age * 12);. Notice that console.log can print a label and a number together, separated by a comma.
  4. Add three more lines for days (age * 365), hours and minutes. Each one multiplies the line before by a little more.
  5. Run the program and check one answer with a calculator.

Hint: hours are days × 24, and minutes are hours × 60, so the minutes line is age * 365 * 24 * 60.

Project 1.3 · Medium


Your birthday in binary


Show the day, month and year of a birthday in binary, and check the result by turning it back.


You will practise: toString(2), parseInt and checking your own work.


    

  1. Create three constants: day, month and year, with a birthday you like.
    2. 

  2. Print each one in binary with .toString(2), with a label.
    3. 

  3. Before running the program, work out the day in binary on paper, using the table in Section 1.3. Did you get the same answer as the computer?
    4. 

  4. Prove that the conversion is correct: turn the year’s binary back into a normal number with parseInt(year.toString(2), 2). It must print the year again.
    5.
