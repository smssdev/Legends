Practice projects

Layout is learned by building layouts. Each project below is a pattern you will meet on real websites again and again. Test every one at phone width and desktop width with the DevTools device toolbar.

Project 7.1 · Easy

The café, side by side

Give the café website from Project 6.2 a real layout: on wide screens, its sections sit next to each other as cards.

You will practise: Grid with auto-fit and minmax, gap, and a wrapping Flexbox menu.

  1. Open cafe.css from Chapter 6 and add a new part at the end, with a comment: /* Chapter 7 */.
  2. Make main a grid with grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)) and a gap, and widen its max-width to 900 pixels.
  3. Remove the bottom margin of the sections: the gap now does the spacing.
  4. Make the nav a wrapping flex container, centred, with a gap between the pills.
  5. Resize the window slowly from wide to narrow, and watch the cards go from three columns to two to one.

Hint: you did not write a single media query, yet the layout adapts. That is the power of auto-fit with minmax.

Project 7.2 · Medium

A “Meet the team” page

Build a grid of team member cards, each with a round avatar, a name and a role, perfectly centred inside the card.

You will practise: Grid for the page, Flexbox inside each card, and centring in both directions.

  1. In team.html, write a <main class="team"> containing six <article class="person">, each with a <div class="avatar"> (the first letter of the name), an <h2> and a <p>.
  2. Make .team a responsive grid of cards at least 150 pixels wide.
  3. Make each .person a flex column with align-items: center, so everything inside is centred.
  4. Make .avatar a 64-pixel circle (border-radius: 50%) and centre its letter with Flexbox: justify-content and align-items both set to center.
  5. Check the page at 360 pixels: how many cards per row?

Hint: this is the “Flexbox inside Grid” pattern from the Tip in Section 7.5: Grid places the cards; Flexbox arranges what is inside each card.

Project 7.3 · Challenge

A product landing page

Build the classic landing page that almost every product has: a top bar, a “hero” with text and a picture, and three feature cards. It must look right on phones too.

You will practise: space-between, flex: 1, fixed grid columns, and a media query that changes direction.

  1. Sketch the page first: a bar with the brand on one side and links on the other; a hero with text beside a picture; a row of three cards; a footer.
  2. Make the bar a flex container with justify-content: space-between, so the brand and the links are pushed to opposite sides.
  3. Make the hero a flex container. Give its text block flex: 1, so it takes all the space the picture does not need.
  4. Lay out the three features with grid-template-columns: repeat(3, 1fr).
  5. Add a media query for screens up to 600 pixels: the hero becomes a centred column (flex-direction: column) and the grid becomes one column.

Hint: the picture is decorative, so its alt is empty (alt=""). The heading already says everything that matters.
