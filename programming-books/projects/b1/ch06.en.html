Project 6.1 · Easy

A warm recipe page

Give the recipe page the warm look of a cookbook: a cream background, a serif font, and orange accents.

You will practise: linking a stylesheet, type selectors, colours, fonts, line-height and borders.

  1. Create recipe.css and link it in the <head> of recipe.html.
  2. On body, set a cream background (#fdf6ec), a dark brown text colour, a serif font such as Georgia, and line-height: 1.6.
  3. Make the h1 bigger and orange. Turn the h2s into small capitals with text-transform: uppercase, some letter-spacing, and a coloured border-bottom.
  4. Round the corners of the picture and give it a white frame with padding and background-color.
  5. Colour the strong text so the cooking time stands out.

Hint: padding on an image shows its background colour around it, like a photo frame. Try border-radius: 16px and see the frame’s corners round.

Project 6.2 · Medium

A café brand with custom properties

Give the café website a brand: three colours defined once as custom properties, used everywhere.

You will practise: custom properties, the box model, inline-block pills, cards and centring with max-width.

  1. In cafe.css, define --brown, --cream and --gold in :root.
  2. Make the header a brown band with centred white text, and turn the menu links into cream pills with display: inline-block, padding and border-radius: 999px.
  3. Keep main narrow and centred with max-width: 560px and margin: 24px auto.
  4. Turn each section into a white card with rounded corners and a gold top border.
  5. Finally, change only the three custom properties to a completely different palette, and watch the whole site change.

Hint: if a pill looks squashed, check that it has display: inline-block; plain inline links ignore vertical padding in the layout.

Project 6.3 · Challenge

A professional sign-up form

Turn the plain sign-up form into a clean card that is pleasant to fill in, with clear focus states.

You will practise: box-sizing, styling form fields, attribute selectors, :focus and box-shadow.

  1. Start signup.css with the box-sizing: border-box rule from Section 6.6, so that fields with padding never overflow.
  2. Turn the form into a white card with a soft shadow and a max-width, on a light background.
  3. Style input, select and textarea together, with one selector list: full width, padding, a border and rounded corners. Use font: inherit so they use the page’s font.
  4. The checkbox should not be full width: select it with the attribute selector input[type="checkbox"] and set width: auto.
  5. Add a clear focus style: a coloured border and a soft “glow” made with box-shadow: 0 0 0 3px. Click into each field to test it.

Hint: never remove the focus outline without replacing it with something just as visible; keyboard users need to see where they are. Chapter 16 explains why.
