Project 9.1 · Easy

Class statistics

A teacher has the scores of a whole class. In one pass through the list, find the average, the highest and lowest score, and how many students passed.

You will practise: for…of, several accumulators at once, and += and ++.

  1. Create an array of eight scores.
  2. Before the loop, create four accumulators: total starting at 0, highest and lowest starting at the first score, and passed starting at 0.
  3. In one for…of loop, update all four. total += score is short for total = total + score.
  4. After the loop, print the number of students, the average (total / scores.length), the highest, the lowest, and “passed out of total”.
  5. Add a score of 100 and one of 0 to the array, and check that the results change as you expect.

Hint: start highest and lowest at the first score, not at 0. If you start lowest at 0, it never changes, because no score is below 0.

Project 9.3 · Challenge


The counting game and a triangle of stars


Two classic loop puzzles. First, count from 1 to 15, but say “Bit” for multiples of 3, “Bot” for multiples of 5, and “Bit Bot” for multiples of both. Second, draw a triangle of stars.


You will practise: % inside a loop, the order of conditions, and nested loops.


    

  1. Write a for loop from 1 to 15.
    2. 

  2. Inside, check for “both” first: n % 3 === 0 && n % 5 === 0. Then 3 alone, then 5 alone, else the number itself.
    3. 

  3. For the triangle, write an outer loop for the rows, 1 to 4. Inside it, start an empty string line.
    4. 

  4. An inner loop adds "* " to the line once for each row number: row 1 gets one star, row 4 gets four.
    5. 

  5. Print the line after the inner loop. Then change the program to draw 10 rows, or an upside-down triangle.
    6. 



Hint: this counting game (usually called FizzBuzz) is a very common question in programming interviews. The trap is the order: if “3” is checked before “both”, 15 prints only “Bit”.
