Each project builds a small toolbox of functions that work together. Give every function one job and a name that says what it does.

Project 10.1 · Easy

A unit converter

Write a set of small conversion functions, plus one helper for rounding, and use them together.

You will practise: parameters, return, default values, and calling functions inside other calls.

  1. Write kmToMiles(km) (× 0.621371), kgToPounds(kg) (× 2.20462) and celsiusToFahrenheit(c).
  2. Write a helper round(value, digits = 1) that returns Number(value.toFixed(digits)). The default means you usually do not have to pass digits.
  3. Print four conversions, passing the result of one function straight into another: round(kmToMiles(10)).
  4. Convert the length of a marathon, 42.195 km, with two decimal places.
  5. Add one more converter of your own, for example litres to cups.

Hint: toFixed returns a string; Number(…) turns it back into a number, so you can keep calculating with it.

Project 10.2 · Medium


Password strength checker


Rate passwords as weak, okay or strong, using small helper functions that each check one thing.


You will practise: functions that return booleans, early returns, looping over the letters of a string, and combining small functions.


    

  1. Write hasDigit(text): loop over the characters with for…of, and return true as soon as one is a digit. After the loop, return false.
    2. 

  2. Write hasUpper(text): a text has a capital letter if it changes when you make it lower case.
    3. 

  3. Write strength(password): give one point each for 8 or more characters, 12 or more characters, a digit, and a capital letter.
    4. 

  4. Turn the points into a word with early returns: 0–1 weak, 2–3 okay, 4 strong.
    5. 

  5. Test four passwords, from the weakest to the strongest.
    6. 



Hint: length matters more than anything else for a password’s strength. A long, unusual sentence beats a short word with symbols.

Project 10.3 · Challenge


Sales report with map, filter and reduce


A small shop has a list of orders. Answer three business questions, each in one or two lines, without writing a single for loop.


You will practise: arrow functions, map, filter, reduce, and chaining them.


    

  1. Create an array of five orders, each an object with a product, a quantity and a price.
    2. 

  2. Write an arrow function lineTotal(order) that returns quantity × price.
    3. 

  3. Total revenue: map each order to its line total, then reduce to one sum.
    4. 

  4. Big orders: filter the orders whose line total is 25 or more, and print how many.
    5. 

  5. Stickers sold: filter the sticker orders, then reduce their quantities. Writing .filter(…) and .reduce(…) on separate lines makes the chain easy to read.
    6. 



Hint: read a chain from top to bottom as a sentence: “orders, only the stickers, add up the quantities”. Professional code is full of chains like this.
