مشاريع تطبيقية

الكائنات هي طريقة البرامج في وصف العالم الحقيقي: كتاب، أو طالب، أو إعدادات مستخدم. تنتقل هذه المشاريع من كائن واحد، إلى قائمة منها، إلى حفظها نصاً.

مشروع 11.1 · سهل

بطاقة مكتبة لكتابك المفضل

صِف كتاباً واحداً بكائن، ثم غيّره، وأضف إليه، واطبع كل خصائصه.

ستتدرب على: إنشاء الكائنات، وتغيير الخصائص وإضافتها، وObject.entries وObject.keys.

  1. أنشئ كائن book فيه title وauthor وpages وread: false.
  2. انتهيت من قراءته للتو: اجعل book.read تساوي true.
  3. أضف خاصية لم تكن موجودة: book.rating = 5.
  4. مرّ على Object.entries(book) بـ for (const [key, value] of …) واطبع كل زوج.
  5. اطبع عدد خصائص الكائن الآن بـ Object.keys(book).length.

تلميح: Object.entries تحوّل الكائن إلى مصفوفة أزواج [key, value]، والأقواس المربعة في الحلقة تفك كل زوج إلى متغيرين.

تقرير الفصل


احتفظ بقائمة طلاب ودرجاتهم، واطبع متوسط كل طالب، واعرف الأول على الفصل.


ستتدرب على: مصفوفات الكائنات، والتفكيك داخل الحلقة، ودالة مساعدة، وتتبّع أفضل قيمة حتى الآن.


    

  1. أنشئ مصفوفة students: كل عنصر فيها { name, marks }، وmarks مصفوفة من ثلاثة أرقام.
    2. 

  2. اكتب average(marks) بـ reduce وMath.round.
    3. 

  3. مرّ بـ for (const { name, marks } of students) واطبع كل اسم مع متوسطه.
    4. 

  4. احتفظ بمتغير best يبدأ بـ null، واستبدله بـ { name, avg } كلما تفوّق عليه طالب.
    5. 

  5. بعد الحلقة اطبع الفائز. ثم غيّر الدرجات ليفوز طالب آخر، وتأكد أن التقرير يتبعها.
    6. 



تلميح: { name, avg } اختصار لـ { name: name, avg: avg }. فحين يحمل المتغير اسم الخاصية نفسه تكتبه مرة واحدة.

مشروع 11.3 · تحدٍّ


إعدادات التطبيق محفوظة بصيغة JSON


التطبيقات الحقيقية تبدأ بإعدادات افتراضية، ثم تحمّل ما حفظه المستخدم في المرة الماضية، وتطبّق تغييراً، ثم تحفظ النتيجة من جديد. ابنِ هذه الدورة.


ستتدرب على: JSON.parse، وJSON.stringify بمسافات، ودمج الكائنات بالنشر دون تغيير الأصل.


    

  1. أنشئ defaults فيه theme وfontSize وlanguage.
    2. 

  2. افترض أن التطبيق حفظ هذا النص في المرة الماضية: '{"theme":"dark","fontSize":18}'. ولاحظ أنه بلا language.
    3. 

  3. ادمجهما: { ...defaults, ...JSON.parse(saved) }. الخصائص اللاحقة تغلب، فالقيم المحفوظة تحل محل الافتراضية، والناقصة تبقى على افتراضيتها.
    4. 

  4. المستخدم يكبّر الخط: أنشئ updated بالنشر وfontSize + 2، واطبع الحجمين لتثبت أن settings لم تتغير.
    5. 

  5. أعد updated نصاً بـ JSON.stringify(updated, null, 2)، جاهزاً للحفظ.
    6. 



تلميح: الترتيب داخل الأقواس مهم. فلو بدّلت النشرين لمسحت الإعدادات الافتراضية ما حفظه المستخدم، وهذا خطأ شائع جداً.
