Practice projects

Three real pages, each a little bigger than the last. Use HTML only: no CSS yet. Keep these files, because you will style them in Chapters 6 and 7.

Project 5.1 · Easy

A recipe page

Write the page for a recipe you love, with a picture, a list of ingredients and numbered steps.

You will practise: the page skeleton, headings, paragraphs, strong, images with alt, and both kinds of list.

  1. Create a folder projects-05, and in it recipe.html with the full skeleton from Section 5.2.
  2. Add an <h1> with the recipe’s name, and a short paragraph that says how long it takes and how many people it serves. Mark the time with <strong>.
  3. Add a picture of the dish with <img>. Write an alt that describes it in one sentence, and give it a width and height.
  4. Add an <h2> “Ingredients” with an unordered list, and an <h2> “Steps” with an ordered list.
  5. Open the page in the browser, and then in the DevTools Elements panel. Is the tree what you expected?

Hint: the order of ingredients does not matter, so use <ul>; the order of steps does, so use <ol>. If you have no photo, use any picture, or soup.svg from the code repository.

Project 5.2 · Medium

A website for a small café

Build the one-page website of a neighbourhood café, with a proper semantic structure and a menu that jumps to each section.

You will practise: header, nav, main, section, footer, links to #id, and tel: links.

  1. Plan the page on paper first: draw boxes for the header, the three sections (menu, opening hours, address) and the footer.
  2. Write the <header> with the café’s name, a one-line description, and a <nav> with three links: #menu, #hours and #find.
  3. Inside <main>, write three <section>s, each with the matching id, an <h2>, and a list or a paragraph.
  4. In the address section, add a phone link: <a href="tel:+201000000000">. On a phone, tapping it starts a call.
  5. Finish with a <footer>. Then make the window small and click the menu links: the page jumps to each section.

Hint: the & sign has a special meaning in HTML, so write it as &amp;, for example Bean &amp; Book.

Project 5.3 · Challenge

A course sign-up form

Build a complete sign-up form with six kinds of field, each with a proper label.

You will practise: forms, label with for, input types, select, textarea, checkboxes and required.

  1. Create signup.html with a heading and a <form>.
  2. Add text, email and phone fields (type="text", "email" and "tel"), each with a <label> whose for matches the field’s id.
  3. Add a <select> for the student’s level, with three <option>s.
  4. Add a <textarea> for “Why do you want to learn?”, and a checkbox for agreeing to emails, with its label after it.
  5. Make the name and email required, and test: press the button with empty fields, then with an email that has no @.

Hint: on a phone, type="email" shows a keyboard with @, and type="tel" shows a number pad. Try it with the DevTools device toolbar, or on your own phone.
