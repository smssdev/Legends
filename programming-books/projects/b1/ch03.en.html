Practice projects

These projects make your new tools feel natural. Do them with the keyboard as much as you can: speed with the terminal and the editor comes from practice, not from reading.

Project 3.1 · Easy

A folder for your notes, terminal only

Create a folder structure for your notes on this book, moving around it using only the terminal.

You will practise: cd, mkdir, ls, pwd, the Up arrow and Tab.

  1. Open the terminal and go into code-from-zero.
  2. Create a folder called book-notes and go into it.
  3. Create four folders, part-1 to part-4, with one command: mkdir accepts several names separated by spaces.
  4. Go into part-1, check where you are with pwd, and come back up two levels with cd .. twice.
  5. Use the Up arrow to repeat a command, and Tab to complete a folder name, at least once each.

Hint: if you get lost, pwd always tells you where you are. Your folder paths will start differently, depending on your computer and your user name.

Project 3.2 · Easy


Quote of the day


Write a small program that prints an encouraging programming quote, and run it from VS Code’s own terminal.


You will practise: creating and running files, the VS Code terminal, Prettier, and a first look at lists.


    

  1. In VS Code, create quote.js in your code-from-zero folder.
    2. 

  2. Write a list of four quotes between square brackets, separated by commas, as in the solution below. You will learn lists properly in Chapter 9.
    3. 

  3. Print a title, then quotes[today], where today is a number from 0 to 3.
    4. 

  4. Mess up the spacing on purpose, then save: watch Prettier tidy it up.
    5. 

  5. Open the terminal with Ctrl + ` and run node quote.js. Change today and run it again with the Up arrow.
    6. 



const quotes = [
  "First, solve the problem. Then, write the code.",
  "Every expert was once a beginner.",
  "Small steps every day beat big steps once a month.",
  "Read the error message. All of it.",
];
const today = 2;
console.log("Quote of the day:");
console.log(quotes[today]);
console.log("Quotes in the list:", quotes.length);


Hint: the first quote is number 0, not 1. That surprises everybody at first; Chapter 9 explains why.

Project 3.3 · Medium


DevTools detective


Investigate a real website with the browser’s developer tools, and write a short report of what you find.


You will practise: the Elements, Console and Network panels, and looking things up on MDN.


    

  1. Choose a website you use often, open it, and press F12.
    2. 

  2. In Elements, find the main heading. Which element is it (h1, h2, a div…)? Look up that element on MDN.
    3. 

  3. In Network, reload the page. Write down: how many requests, how much data was transferred, and the type of the largest file.
    4. 

  4. In Console, type document.title and press Enter. What do you get?
    5. 

  5. Write your findings in a file called detective.txt in your book-notes folder, as a short table: question, answer.
    6. 



Hint: the Network panel shows the totals at the bottom: number of requests, data transferred and the time the page took to load. Tick Disable cache to see a “first visit” load.


Your result: a short report. There is no single right answer; every website is different, and that is what makes the detective work interesting.
