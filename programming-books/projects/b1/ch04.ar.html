مشروع 4.1 · سهل

فاحص العناوين

فكّك قائمة من عناوين الويب، واطبع المضيف والمسار والاستعلام والجزء لكل واحد منها.

ستتدرب على: أجزاء عنوان URL، وكائن URL.

  1. قبل كتابة الكود، انسخ العناوين الثلاثة من الحل على ورقة، وضع خطاً تحت كل جزء بلون مختلف كما في الشكل 4.1.
  2. أنشئ inspect-urls.js فيه مصفوفة بالعناوين الثلاثة.
  3. لكل عنوان أنشئ new URL(text)، واطبع hostname وpathname وsearch وhash تفصلها "|".
  4. بعض العناوين ليس فيها استعلام أو جزء، فتكون هذه الخصائص فارغة. اطبع "-" بدلاً منها بـ url.search || "-".
  5. قارن المخرجات بورقتك. هل وجدت كل جزء صحيحاً؟
for (const text of addresses) {
  const url = new URL(text);
  console.log(url.hostname, "|", url.pathname, "|", url.search || "-", "|", url.hash || "-");
}

تلميح: for (const text of addresses) تكرر الكود لكل عنوان (الفصل 9)، و|| تختار الطرف الأيمن حين يكون الأيسر فارغاً (الفصل 8).

موقع من ثلاث صفحات وصفحة 404


وسّع خادمك ليقدم صفحة رئيسية وصفحة «من نحن» وصفحة «تواصل معنا»، ويجيب بـ 404 Not Found لكل ما سواها.


ستتدرب على: المسارات، ورموز الحالة، وكيف يقرر الخادم ما يرسله.


    

  1. انسخ server.js من القسم 4.7 إلى site.js.
    2. 

  2. فوق الخادم أنشئ كائناً يربط كل مسار بصفحته: "/" و"/about" و"/contact".
    3. 

  3. داخل الخادم ابحث عن pages[request.url]. إن وُجدت الصفحة فأرسلها برمز 200، وإلا فأرسل عنوان «الصفحة غير موجودة» برمز 404.
    4. 

  4. اختبر أربعة مسارات، أحدها غير موجود، واطبع المسار والرمز والصفحة.
    5. 

  5. احذف server.close()، وافتح http://localhost:3002/about في متصفحك، وانظر إلى الرمز في تبويب Network.
    6. 



const page = pages[request.url];
if (page) {
  response.writeHead(200, { "Content-Type": "text/html; charset=utf-8" });
  response.end(page);
} else {
  response.writeHead(404, { "Content-Type": "text/html; charset=utf-8" });
  response.end("<h1>الصفحة غير موجودة</h1>");
}


تلميح: الكائن المستخدم هكذا «قاموس» صغير من المسارات إلى الصفحات. والخوادم الحقيقية تفعل الشيء نفسه بصفحات أكثر بكثير، ويُسمى ذلك التوجيه (routing).
