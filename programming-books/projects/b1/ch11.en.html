Practice projects

Objects are how programs describe the real world: a book, a student, a user’s settings. These projects move from one object, to a list of them, to saving them as text.

Project 11.1 · Easy

A library card for your favourite book

Describe one book as an object, change it, add to it, and print every property it has.

You will practise: object literals, changing and adding properties, Object.entries and Object.keys.

  1. Create a book object with title, author, pages and read: false.
  2. You have just finished it: set book.read to true.
  3. Add a property that did not exist before: book.rating = 5.
  4. Loop over Object.entries(book) with for (const [key, value] of …) and print each pair.
  5. Print how many properties the object has now with Object.keys(book).length.

Hint: Object.entries turns an object into an array of [key, value] pairs, and the square brackets in the loop unpack each pair into two variables.

Project 11.3 · Challenge


App settings saved as JSON


Real apps start from default settings, load what the user saved last time, apply a change, and save the result again. Build that cycle.


You will practise: JSON.parse, JSON.stringify with indentation, and merging objects with spread without changing the originals.


    

  1. Create defaults with theme, fontSize and language.
    2. 

  2. Pretend the app saved this text last time: '{"theme":"dark","fontSize":18}'. Notice that it has no language.
    3. 

  3. Merge them: { ...defaults, ...JSON.parse(saved) }. Later properties win, so the saved values replace the defaults, and the missing ones keep their defaults.
    4. 

  4. The user makes the text bigger: create updated with spread and fontSize + 2. Print both sizes to prove settings did not change.
    5. 

  5. Turn updated back into text with JSON.stringify(updated, null, 2), ready to be saved.
    6. 



Hint: the order inside the braces matters. Swap the two spreads and the defaults would wipe out what the user saved, a very common bug.
