Project 2.2 · Medium


Guess my number


A friend thinks of a number from 1 to 100 and answers only “too high” or “too low”. Write the strategy that always wins in at most seven guesses, and let the computer play it.


You will practise: binary search, keeping track of a range, and repetition.


    

  1. Play the game with a friend, on paper. Always guess the middle of the numbers that are still possible. Write down each guess.
    2. 

  2. Write the strategy as pseudocode with two values, LOW and HIGH. What happens to them after “too low”? After “too high”?
    3. 

  3. Type the solution below into guess.js. It uses a while loop and break, which you will learn properly in Chapter 9; for now, follow the shape: repeat: guess the middle; if right, stop; otherwise move LOW or HIGH.
    4. 

  4. Change secret to other numbers, such as 1, 100 and 64. Does it ever need more than seven guesses?
    5. 



const secret = 73;
let low = 1;
let high = 100;
let tries = 0;

while (true) {
  const guess = Math.floor((low + high) / 2);
  tries++;
  if (guess === secret) {
    console.log(`Guess ${tries}: ${guess}. Got it!`);
    break;
  }
  if (guess < secret) {
    console.log(`Guess ${tries}: ${guess}, too low`);
    low = guess + 1;
  } else {
    console.log(`Guess ${tries}: ${guess}, too high`);
    high = guess - 1;
  }
}


Hint: Math.floor rounds down, so the middle of 1 and 100 is 50, not 50.5. Seven guesses are always enough because 27 = 128, which is more than 100.

Sort three cards

You will practise: designing an algorithm, testing every case, and thinking about correctness.

    3. 

  3. Test your algorithm by hand on all six possible orders of 1, 2 and 3. A correct algorithm must sort every one of them.
    4. 

  4. Write it in JavaScript. A neat way to swap two variables is [a, b] = [b, a];.
