مدونة صغيرة بعناوين جميلة

قائمة تدوينات وصفحة لكل تدوينة، على عناوين مثل /posts/rules-for-state، مع رسالة لطيفة للتدوينات غير الموجودة.

ستتدرب على: المسارات المتداخلة، ومسار الفهرس، ومعامل المسار، وLink وNavLink، ومعالجة غير الموجود.

  1. أعطِ كل تدوينة معرّفاً نصياً (slug): معرّفاً قصيراً مقروءاً مصنوعاً من العنوان، مثل keys-explained. والعناوين المقروءة أفضل للمستخدمين ولمحركات البحث.
  2. اكتب Layout فيه اسم المدونة، وNavLink إلى القائمة، وOutlet.
  3. مسار الفهرس يعرض القائمة، وposts/:slug يعرض تدوينة واحدة.
  4. في PostPage جِد التدوينة بـ useParams().slug. فإن لم توجد قل ذلك واربط إلى الرئيسية.
  5. جرّب عنواناً خاطئاً بيدك، مثل /posts/nothing، وتحقق من الرسالة.

تلميح: البيانات هنا ثابتة، فلا حاجة إلى استعلام. فليست كل صفحة بحاجة إلى TanStack Query، واستخدمها حين تأتي البيانات من خادم.

قائمة منتجات تُشارَك


وسّع متجر هذا الفصل لتعيش الفئة ونص البحث في العنوان، فيُشارك كل اختيار رابطاً.


ستتدرب على: useSearchParams للقراءة والكتابة، ومفاتيح الاستعلام متعددة الأجزاء، وإبقاء العنوان متوافقاً مع حقل إدخال.


    

  1. اقرأ category وq من معاملات البحث، وكلاهما قد يغيب.
    2. 

  2. ضع الاثنين في مفتاح الاستعلام: ["products", category, q]، ومرّرهما إلى دالة الواجهة البرمجية.
    3. 

  3. اجعل حقل البحث محكوماً بالعنوان: قيمته q ?? ""، وonChange تستدعي setParams بالنص الجديد مع إبقاء الفئة.
    4. 

  4. مرّر { replace: true } إلى setParams أثناء الكتابة، كي لا يصير كل حرف مدخلاً جديداً في تاريخ زر الرجوع.
    5. 

  5. افتح العنوان نفسه في تبويب جديد، وتحقق أنك ترى القائمة نفسها بالضبط.
    6. 



تلميح: لتغيّر معاملاً واحداً وتبقي الباقي انسخها أولاً: const next = new URLSearchParams(params); next.set("q", text); setParams(next, { replace: true });.

زر مفضلة متفائل


قلب يمتلئ لحظة الضغط، ويحفظ في الخلفية، ويعيد الأمور بهدوء إن رفض الخادم.


ستتدرب على: useMutation، وقراءة ذاكرة الاستعلامات والكتابة فيها، والتراجع بقيمة سياق، والإبطال.


    

  1. حمّل المنتج بـ useQuery بالمفتاح ["product", id].
    2. 

  2. أنشئ تعديلاً (mutation) تستدعي mutationFn فيه setFavourite(id, value).
    3. 

  3. في onMutate ألغِ استعلامات المفتاح (كي لا يكتب رد قديم فوقك)، واحفظ القيمة الحالية بـ getQueryData، واكتب الجديدة بـ setQueryData، وأرجع { previous }.
    4. 

  4. في onError أعد كتابة context.previous. وفي onSettled أبطل المفتاح، لتنتهي الشاشة بحقيقة الخادم.
    5. 

  5. اختبر الفشل: في الواجهة الوهمية مفتاح server.failNextSave. وراقب القلب يمتلئ ثم يفرغ، مع رسالة.
    6. 



تلميح: استخدم التحديثات المتفائلة للأفعال الصغيرة المتكررة القابلة للتراجع، كالإعجاب وعلامات الصح وإعادة الترتيب. أما المدفوعات وكل ما يصعب التراجع عنه، فاعرض حالة «جارٍ الحفظ…» واضحة وانتظر الخادم.
