# أداة الصور (W14)

أمر واحد يحوّل `art/raw/` إلى صور اللعبة في `web/public/match-art/`:

```bash
pip install pillow numpy scipy   # مرة واحدة
python3 tools/art/build.py
```

## ماذا تفعل

1. **تزيل الخلفية:** الخضراء (أو الوردية للمؤثرات، أو السوداء لمؤثرات الضوء) بحواف ناعمة، وتنزع اللون الأخضر المنعكس على الأطراف.
2. **تقص الإطارات:** كل لوحة تُقص إلى عدد الإطارات المكتوب لها في `README.md` مجلدها («الإطارات a إلى b من N»). القطع الصغيرة الشاردة تُضم لأقرب شخص. والشخصان المتلامسان يُفصلان، فلا تدخل قدم شخص في إطار غيره.
3. **طبقة القميص:** صورة ثانية لكل أطلس (`-kit.png`) تحدد القميص والشورت والجوارب البيضاء، مع ظلالها الزرقاء وإضاءة حوافها. فتلوّنها اللعبة بألوان أي نادٍ، وتبقى البشرة والشعر والحذاء كما هي.
4. **الحجم وخط الأرض:** كل شخصية تُقاس على بطاقتها المرجعية (`ref.png`)، فيكون اللاعب الواقف بنفس الطول في كل حركاته. ولكل حركة خط أرض واحد، فالإطار الذي يطير فيه اللاعب يبقى مرتفعاً.
5. **الأطلس بدقتين:**
   - `hd` للكمبيوتر: اللاعب 384 بكسل، والملعب بعرض 1376.
   - `sd` للجوال: النصف.
6. **الملاعب:** كل صورة ملعب تصير `webp` بالدقتين.

## الناتج

- `web/public/match-art/manifest.json`: كل حركة وإطاراتها:
  - مكان الإطار في الأطلس (`page`، `x`، `y`، `w`، `h`).
  - نقطة الارتكاز: `ax` منتصف القميص، فلا يهتز الجسم بين الإطارات. و`ay` خط الأرض.
  - الإطارات الناقصة (`missing`).
  - ومقاسات صور الملاعب.
- `web/public/match-art/{hd,sd}/sprites-N.png` وطبقة القميص `sprites-N-kit.png`.
- `web/public/match-art/{hd,sd}/plates/<الملعب>/<الحالة>/<الزاوية>.webp`.

الناتج لا يُرفع إلى git (`.gitignore`)، بل يُبنى من `art/raw/` في أي وقت. ونفس الصور تعطي نفس الملفات دائماً.

## حدود النسخة الأولى

- طبقة القميص واحدة للقميص والشورت والجوارب معاً. وفصل كل جزء بلونه يأتي في محرك المشهد (W15).
- أجزاء صغيرة من الذراع في الظل قد تدخل طبقة القميص.

## المعاينة (W14b)

بعد البناء شغّل `npm run dev` من `web/` وافتح `http://localhost:5173/dev/art`. الصفحة في التطوير فقط.

- **التشغيل:** كل حركة تتحرك بإيقاعها (12 إطاراً في الثانية)، أو بربعه أو نصفه، أو إطاراً إطاراً.
- **أدوات الفحص:**
  - لون القميص من الألوان الجاهزة أو أي لون.
  - الخلفية: عشب، أو مربعات لرؤية حواف القص، أو أي صورة ملعب.
  - خطوط الأرض والارتكاز، والإطار السابق شفافاً، والدقتان.
- **التنبيهات:** الإطارات الناقصة، والقفزات بين إطارين في الطول (أكثر من 6%) أو في خط الأرض (أكثر من 4%، وهذا طبيعي في القفز والارتماء فقط).
- **الرابط:** رابط كل حركة يحفظ اسمها، مثل `/dev/art#striker%2Frun-side`.

**فحص كل مجموعة:** حمزة يرفع الصور، ثم `python3 tools/art/build.py`، ثم تشغيل المجموعة في الصفحة والتأكد أنها بلا تنبيهات ولا قفزات.
