# 02. كتالوج المزايا

كل ميزة برمزها، والسبرنت الذي تُبنى فيه. الرموز تُستعمل في ملفات السبرنتات.

## أ. المصحف

| الرمز | الميزة | السبرنت |
|---|---|---|
| A1 | مصحف المدينة صفحة بصفحة (604) بالرسم العثماني وخط المصحف، مطابق للمطبوع سطراً بسطر | M03 |
| A2 | عرض بديل: آية آية، وبخط كبير | M03 |
| A3 | تلاوات لعدة قراء مع تظليل الكلمة أثناء التلاوة | M03 |
| A4 | تكرار آية أو مقطع بعدد، وسرعة تشغيل، وفاصل للترديد | M06 |
| A5 | مصحف التجويد الملون (اختياري) | M16 |
| A6 | بحث في النص والمعاني، وانتقال بالسورة والجزء والصفحة | M03 |
| A7 | علامات وملاحظات على الآيات | M15 |
