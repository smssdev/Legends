# 08. Unity

Unity هنا ليس لعبة ملصقة بالمنصة، بل ثلاث تجارب لا تصلح لها الواجهة العادية: **رؤية الحفظ مكاناً**، و**رؤية النطق جسماً**، و**اللعب تثبيتاً**.

## 1. عالم الرحلة (K1)

بستان واسع فيه 114 موضعاً، لكل سورة موضع بحجم يناسب طولها، مرتبة على طريق واحد من الفاتحة إلى الناس.

| حالة الحفظ | ما يُرى |
|---|---|
| لم تُحفظ | أرض ممهدة فارغة |
| حفظ جديد | غرس صغير |
| مراجعة قريبة | شجرة تنمو |
| متقنة | شجرة مثمرة مضيئة |
| تضعف (تستحق مراجعة) | أوراق تصفرّ |
| ضعيفة | شجرة ذابلة تنتظر السقيا (المراجعة) |
| ختم جزء | نهر يجري في ذلك الجزء |
| ختم القرآن | البستان كله مضيء، ويبدأ طور «الرعاية» (التعاهد) |

- **السقيا هي المراجعة:** الضغط على شجرة ذابلة يفتح جلسة ترميمها. فالعالم مرآة لخريطة الإتقان، لا نظام نقاط مستقل.
- **لا شخصيات ولا تصوير لذوات الأرواح** في العالم: طبيعة، وماء، وضوء، وعمارة إسلامية هندسية.
- **لا آيات مكتوبة على الأرض أو في مواضع تُداس،** واسم السورة على لوحة مرتفعة.
- يتجول المستخدم بالسحب، ويرى من الأعلى «خريطة عمره مع القرآن».
- **بستان الحلقة والأسرة:** عرض مشترك اختياري يرى فيه الأعضاء تقدم المجموعة.

**العقد مع الواجهة الحاضنة:**

```json
{
  "surahs": [
    { "id": 67, "state": "mastered", "strength": 92, "pages": 3, "weak_pages": 0 },
    { "id": 2,  "state": "learning", "strength": 61, "pages": 48, "mastered_pages": 22, "weak_pages": 3 }
  ],
  "juz_complete": [30, 29],
  "khatma": false,
  "season": "ramadan"
}
```

وUnity يرسل: `{ "event": "open_surah", "id": 2 }` أو `{ "event": "water", "surah": 2, "page": 21 }`.

## 2. مجسم المخارج (K2)

مقطع جانبي ثلاثي الأبعاد للفم والحلق والأنف (مجسم تعليمي تشريحي، لا وجه إنسان):

- اختيار حرف يحرك اللسان والشفتين إلى مخرجه ويضيء موضعه، مع صوت النطق الصحيح.
- المخارج السبعة عشر، والصفات (الهمس والجهر، والشدة والرخاوة، والاستعلاء، والإطباق، والقلقلة) بمؤثر بصري لكل صفة (مثل جريان النفَس في الهمس).
- مقارنة حرفين متقاربين (س/ص، ت/ط، ذ/ظ) جنباً إلى جنب.
- مربوط بدروس التجويد: الدرس يفتح المجسم على الحرف المطلوب، وتنبيه التجويد في التسميع يحيل إليه.
- يُراجَع علمياً من متخصص في التجويد قبل النشر.

## 3. ألعاب التثبيت (K3)

كلها تسحب أسئلتها من الخادم (من محفوظ اللاعب وأضعف مواضعه)، وتعيد النتائج أحداث مراجعة خفيفة.

| اللعبة | الفكرة | تخدم |
|---|---|---|
| **جسر الآيات** | تُبنى ألواح الجسر بترتيب كلمات الآية أو ترتيب الآيات | الترتيب |
| **مفترق المتشابهات** | طريق يتفرع عند موضع التشابه، واختر التكملة الصحيحة لهذه السورة | المتشابهات |
| **قافلة السور** | رتّب السور، وما قبلها وما بعدها | المواضع |
| **صدى** (للصغار) | استمع وردد، وكل ترديد صحيح يضيء فانوساً | التلقين |
| **أين الآية؟** | صفحة مصحف مجسمة، وضع الآية في موضعها من الصفحة | الذاكرة البصرية |

**ضوابط:** لا خسارة مهينة ولا مؤثرات صاخبة، والآيات تُعرض بخط المصحف كاملة التشكيل، ولا تُقطَّع الكلمة الواحدة، ولا يُتلاعب بصوت التلاوة.

## 4. التقنية

- Unity LTS وURP، ومشروع واحد بهدفين: WebGL (يُحمَّل عند الطلب) ومكتبة داخل Flutter.
- أسلوب بصري خفيف (low-poly مع إضاءة جميلة) حتى يعمل على الجوالات المتوسطة، بثلاث درجات جودة.
- الخط العربي: نص المصحف يُرسم صوراً (textures) مولّدة من خط المصحف نفسه، لضمان صحة الرسم، لا بمحرك نصوص Unity.
- لا حالة محفوظة في Unity: كل فتح يبدأ من `journey_state`.
- الحجم المستهدف لـ WebGL: أقل من 25MB مضغوطاً.
