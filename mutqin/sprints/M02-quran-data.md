# M02 بيانات القرآن

- **المرحلة:** 0 التأسيس
- **المدة:** أسبوعان
- **يعتمد على:** M00 (التراخيص)، M01
- **الحالة:** لم يبدأ

## الهدف

قاعدة القرآن الموثقة: النص، والصفحات سطراً بسطر، والكلمات، والتلاوات بتوقيتها، مبنية بسكربت واحد ومحمية ببصمة. هي أساس كل ما بعدها.

## المهام

### خط البناء (`data/`، Python)
- [ ] سكربت استيراد لكل مصدر معتمد في M00، يكتب إلى مخطط `docs/04-data-model.md` القسم 2.
- [ ] الجداول: `surahs` و`ayahs` (عثماني، وإملائي، وبلا تشكيل) و`words` و`pages` و`page_lines` وحدود الأجزاء والأحزاب والأرباع ومواضع السجدات.
- [ ] `ayah_segments`: تقسيم الآيات الطويلة على علامات الوقف.
- [ ] `reciters` و`recitation_timings` (توقيت الآية والكلمة) للقراء المختارين.
- [ ] الصيغة الصوتية لكل كلمة (`phonemes`) للتسميع لاحقاً.
- [ ] ناتجان: تفريغ PostgreSQL للخادم، وملف SQLite مضغوط للتطبيق.

### السلامة
- [ ] فحص الأعداد المرجعية: 114 سورة، و6236 آية، و604 صفحات، و30 جزءاً، و60 حزباً، و15 سطراً في الصفحة (عدا الصفحتين الأوليين).
- [ ] مقارنة النص بين مصدرين مستقلين حرفاً بحرف، وتقرير بأي فرق.
- [ ] ملف البصمات (SHA-256 لكل سورة وللقاعدة)، وفحصه في CI وعند إقلاع الخادم.
- [ ] اختبار: مجموع كلمات السطور = كلمات الآيات، ولا كلمة بلا سطر.

### الخادم (Laravel)
- [ ] وحدة `Quran` للقراءة فقط (لا نموذج يكتب)، واختبار يمنع الكتابة.
- [ ] `GET /quran/surahs` و`/quran/pages/{n}` و`/quran/ayahs/{id}` و`/quran/reciters`، مع كاش طويل.
- [ ] تخزين الصوت في MinIO وروابط موقّعة، أو CDN حسب الترخيص.

### المحتوى
- [ ] جدول «المصادر» بنسبة كل مصدر وترخيصه (يظهر في التطبيق لاحقاً).

## تعريف الانتهاء

- [ ] `make quran-db` يبني القاعدة من الصفر ويطبع «البصمة مطابقة».
- [ ] الفحوص المرجعية كلها تمر، وتقرير المقارنة بين المصدرين بلا فروق غير مفسرة.
- [ ] المسارات تعيد صفحة كاملة بسطورها وكلماتها في أقل من 50 مللي ثانية (مع الكاش).
- [ ] المراجع الشرعي اطلع على تقرير السلامة.

## كيف يُختبر

1. تغيير حرف واحد في ملف المصدر والتأكد أن البناء يفشل بالبصمة.
2. طلب الصفحة 1 و2 و604 وصفحة فيها بداية سورة ومطابقتها بالمصحف المطبوع.
3. تشغيل توقيت كلمة والتأكد أنه يوافق الصوت.

## المخاطر

- **اختلاف المصادر في الرسم أو عدّ الكلمات:** يُعتمد مصدر واحد مرجعاً للنص والآخر للتحقق فقط.
- **توقيت الكلمات غير متاح لكل قارئ:** يُولَّد بالمحاذاة الآلية في M08 ويُراجع بعينة.
