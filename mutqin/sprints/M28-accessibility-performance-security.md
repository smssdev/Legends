# M28 الوصول والأداء والأمان

- **المرحلة:** 5 مدى الحياة والإطلاق
- **المدة:** 3 أسابيع
- **يعتمد على:** كل ما سبق
- **المزايا:** N2، N5
- **الحالة:** لم يبدأ

## الهدف

المنصة تصلح للكفيف وكبير السن وصاحب الجوال الضعيف والشبكة البطيئة، وتصمد أمام الحمل والاختراق قبل فتحها للعامة.

## المهام

### الوصول
- [ ] **الوضع الصوتي الكامل للمكفوفين:** كل المسار بلا نظر: الورد يُقرأ، والجلسة بأوامر صوتية وإيماءات بسيطة، والتسميع بتنبيه صوتي عند الخطأ يذكر الصواب، والتقرير مسموع. يُصمم ويُجرب مع حفاظ مكفوفين (وهم كثر).
- [ ] قارئ الشاشة (TalkBack وVoiceOver وNVDA): تسميات لكل عنصر، وقراءة الآية بتلاوة القارئ لا بصوت النظام الآلي.
- [ ] كبار السن: وضع مبسط (خط أكبر، وأزرار أقل، وتباين أعلى)، وتكبير حتى 200% بلا انكسار.
- [ ] ضعاف السمع: كل تنبيه صوتي له نظير بصري واهتزازي.
- [ ] عمى الألوان: الخطأ بالرمز مع اللون، وفحص التباين (WCAG AA).
- [ ] لوحة المفاتيح كاملة على الويب، وتقليل الحركة.
- [ ] فحص آلي (axe) في اختبارات المتصفح، ومراجعة يدوية.

### الأداء
- [ ] الويب: حزمة أولى صغيرة، وتحميل متأخر للأقسام وUnity، وأهداف Core Web Vitals على جوال متوسط وشبكة 3G.
- [ ] الجوال: زمن الفتح أقل من ثانيتين، و60 إطاراً في المصحف، وقياس البطارية في جلسة تسميع 30 دقيقة.
- [ ] الخادم: فهارس القاعدة، والاستعلامات البطيئة، وكاش قراءات القرآن، وتقسيم `review_events` (أكبر جدول).
- [ ] خدمة التسميع: دفعات، وحد التزامن، وقياس الكلفة لكل ساعة تسميع.
- [ ] **اختبار حمل:** محاكاة العدد المستهدف للإطلاق (مستخدمون، وجلسات تسميع متزامنة، وغرف مباشرة، وطابور فيديو)، وخطة توسع مكتوبة.
- [ ] وضع الشبكة الضعيفة: كل شيء يعمل، والصوت يُرفع لاحقاً.

### الأمان والخصوصية
- [ ] مراجعة أمنية كاملة: الصلاحيات (خصوصاً مسارات التسجيلات والحلقات والصغار)، وOWASP، وترويسات الأمان وCSP، وحدود المعدل، والرفع.
- [ ] الروابط الموقّعة قصيرة العمر لكل صوت وفيديو، والتشفير في التخزين.
- [ ] اختبار اختراق لمسارات الخصوصية: محاولة الوصول إلى تسجيل غيرك بكل طريقة.
- [ ] حماية الرفيق الذكي من حقن التعليمات (إعادة تشغيل مجموعة M15 موسعة).
- [ ] **تصدير البيانات وحذف الحساب** نهائياً (مع التسجيلات والنسخ بعد مدة الاحتفاظ)، والتحقق بالاختبار.
- [ ] الدخول بخطوتين للمعلمين والمشرفين والإدارة.
- [ ] النسخ الاحتياطي: يومي ومشفر وخارج الخادم، وتجربة استعادة كاملة موثقة.
- [ ] سجل تدقيق لأفعال الإدارة والمعلمين على بيانات الطلاب.
- [ ] مراجعة سياسة الخصوصية والشروط على ما بُني فعلاً، ومتطلبات المتاجر وبيانات الصغار.

### لوحة الإدارة
- [ ] المستخدمون والحلقات وتوثيق المعلمين، والبلاغات، ومحتوى المراجعة (بطاقات، وأسئلة، ودروس)، وصحة الخدمات، وأرقام المقاييس (README القسم 7).

## تعريف الانتهاء

- [ ] حافظ كفيف يتم ورد يوم كامل (مراجعة وتسميع وتقرير) دون مساعدة.
- [ ] لا مخالفة حرجة في axe، والتباين AA.
- [ ] اختبار الحمل يمر عند العدد المستهدف بزمن تسميع أقل من 1.5 ثانية.
- [ ] لا ثغرة عالية أو حرجة مفتوحة من المراجعة الأمنية.
- [ ] استعادة النسخة الاحتياطية جُربت ونجحت.
- [ ] حذف الحساب يزيل كل شيء (اختبار يبحث في القاعدة والتخزين).

## كيف يُختبر

1. إتمام ورد بالوضع الصوتي والشاشة مغطاة.
2. فتح الموقع بمحاكاة 3G وجوال ضعيف.
3. محاولة فتح تسجيل مستخدم آخر برابطه بعد انتهاء توقيعه وبحساب آخر.
4. تصدير ثم حذف حساب والتأكد من الزوال.

## المخاطر

- **الوضع الصوتي أكبر من سبرنت:** يبدأ بالمسار الأساسي (الورد والتسميع والتقرير)، والباقي يكمل بعد الإطلاق بملاحظات المكفوفين.
- **اختبار الحمل يكشف حاجة لعتاد أكبر:** قرار لصاحب المشروع قبل M29.
