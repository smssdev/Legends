## الهدف

مستودع يعمل من أول يوم: خادم، وويب، وتطبيق، وخدمة Python، كلها تتصل ببعضها بأمر واحد، مع فحوص آلية تمنع الانحراف.

## المهام

### المستودع
- [ ] إنشاء المستودع بالهيكل في `docs/03-architecture.md` القسم 11، ونقل هذه الخطة إليه.
- [ ] `CLAUDE.md` للمشروع: المبادئ العشرة، والقواعد الثابتة، وطريقة العمل.
- [ ] `docs/api/openapi.yaml` (فارغ بمسار الصحة) و`docs/design/tokens.json`.

### الخادم (Laravel)
- [ ] Laravel 12 وPHP 8.4، وPostgreSQL للخادم وSQLite للاختبار.
- [ ] Sanctum (كوكيز للويب وتوكن للجوال)، وشكل الخطأ الموحد `{message, code, errors?}` بالعربية والإنجليزية.
- [ ] ساعة التطبيق (`AppClock`) بدل `now()`، مع أمر لتحريك الوقت في التطوير، واختبار يمنع `now()` المباشر.
- [ ] Redis للكاش والطابور، وReverb.
- [ ] `GET /api/v1/health` يفحص القاعدة وRedis وخدمة Python.
- [ ] Pint وPHPUnit أو Pest، واختبار أمان الترحيلات (تضيف ولا تحذف).

### الذكاء (Python)
- [ ] مشروع FastAPI بـ `uv`، ومسار صحة، وتوقيع الطلبات بينه وبين Laravel (HMAC).
- [ ] هيكل الوحدات: `asr` و`tajweed` و`similarity` و`companion`، و`ruff` و`pytest`.

### الويب (Vue)
- [ ] Vue 3 وTypeScript وVite وPinia وVue Router وTailwind، وRTL من الأساس.
- [ ] توليد الألوان من `tokens.json`، وتوليد أنواع الـ API من `openapi.yaml`.
- [ ] i18n (عربي وإنجليزي) وفحص يمنع نصاً مكتوباً في الشاشة مباشرة.
- [ ] الإطار الفارغ (شريط جانبي وسفلي) وصفحة دخول تجريبية.
- [ ] Playwright واختبار واحد يمر.

### الجوال (Flutter)
- [ ] مشروع Flutter (أندرويد وiOS)، وRiverpod وgo_router وDrift.
- [ ] الألوان من `tokens.json`، والترجمة، والإطار الفارغ بالشريط السفلي.
- [ ] عميل API مولَّد من `openapi.yaml`.

### التشغيل
- [ ] `docker compose` للتطوير: الخدمات كلها بأمر واحد.
- [ ] CI: اختبارات الخادم، وبناء الويب، وتحليل Flutter، واختبارات Python، وفحص تحديث `openapi`.
- [ ] بيئة تجريبية (staging) على الخادم المختار في M00.

## تعريف الانتهاء
