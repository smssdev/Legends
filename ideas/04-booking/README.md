# نظام الحجوزات (صالونات، ملاعب، قاعات)

## الفكرة

محرك حجز واحد بثلاثة قوالب جاهزة: صالون (خدمة مع موظف)، وملعب (مورد بالساعة)، وقاعة (مورد باليوم مع باقات). صفحة حجز عامة بالدفع، ولوحة تقويم، وتذكيرات، وتطبيق.

**هو المشروع المقترح للبدء:** الأصغر، وفيه يُبنى الأساس المشترك (`kit/`) ومحرك التوفر الذي يعيد استعماله مشروع العيادات.

## المشتري

- صالونات الحلاقة والتجميل ومراكز السبا.
- ملاعب الخماسي والبادل وصالات الألعاب.
- قاعات الأفراح والمناسبات والاستراحات والشاليهات.
- استوديوهات التصوير ومراكز التدريب ومساحات العمل.

## ما يميزنا

- قالب جاهز لكل نشاط: المشتري يختار نشاطه فتُضبط الشاشات والمصطلحات.
- عربون أونلاين يوقف الحجوزات الوهمية.
- تذكير واتساب وتأكيد بزر.
- نسخة يملكها، لا عمولة على كل حجز.

## النطاق

**v1:** الخدمات والموارد والموظفون، محرك التوفر، الحجز والعربون، الصفحة العامة، التقويم، التذكيرات، سياسات الإلغاء، العملاء، الباقات والاشتراكات، التطبيق، التقارير.

**بعد v1:** سوق يجمع أنشطة كثيرة (Marketplace)، نقطة بيع للمنتجات، الرواتب والعمولات المتقدمة.

## الأدوار

| الدور | ما يفعله |
|---|---|
| المالك | الإعدادات والأسعار والتقارير |
| الاستقبال | الحجوزات والتحصيل والعملاء |
| الموظف (مقدم الخدمة) | تقويمه وحجوزاته |
| العميل | يحجز ويدفع ويعدّل ويلغي |

## نموذج البيانات (مختصر)

`branches`، `resources` (موظف، ملعب، قاعة، غرفة)، `services`، `service_resources`، `schedules`، `time_off`، `price_rules`، `bookings`، `booking_items`، `payments`، `customers`، `packages`، `memberships`، `policies`، `reminders`، `reviews`.

## التقنية

الأساس المشترك كاملاً (يُبنى هنا أول مرة)، ومحرك توفر نقي بأرقام صحيحة (دقائق منذ بداية الأسبوع) مع اختبارات كثيرة.

## التسعير والبيع (تقديري)

| الباقة | السعر | تشمل |
|---|---|---|
| أساسية | 250$ | فرع واحد، الويب وصفحة الحجز |
| كاملة | 500$ | فروع بلا حد، والتطبيق بعلامته، والباقات والاشتراكات |
| سكربت في الأسواق | 59 إلى 79$ | نسخة بلا تطبيق وبلا دعم تركيب (إن قرر صاحب المشروع) |
| تجديد الدعم | 25% سنوياً | |

## التسويق

- لكل نشاط صفحة هبوط خاصة به (صالون، ملعب، قاعة) بلقطاته ومصطلحاته.
- إنستغرام وتيك توك (جمهور الصالونات والملاعب هناك).
- زيارات مباشرة للملاعب والصالونات، وشهر تجربة.
- موردو مستلزمات الصالونات كمسوّقين.

## المخاطر

| الخطر | التعامل معه |
|---|---|
| منافسة عالمية ومجانية (Fresha وغيره) | العربية، والعربون المحلي، وواتساب، والملاعب والقاعات التي لا يخدمها المنافس |
| ثلاثة أنشطة قد تشتت المنتج | محرك واحد، والفرق في القالب والمصطلحات فقط |
| تعارض الحجوزات | حجز بتحديث شرطي واختبارات تزامن |
