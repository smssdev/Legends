# Sprint 01: الأساس المشترك والخدمات والموارد

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل (أطول لأنه يبني `kit/` لكل المشاريع) |

**الهدف:** الأساس المشترك يعمل ومعزول في حزمة، ومالك يعرّف خدماته وموارده وأوقات عمله.

| الرمز | المهمة | الملفات |
|---|---|---|
| K1 | الهيكل: Laravel وVue وDocker Compose (app، queue، scheduler، PostgreSQL، Redis)، وحزمة `kit/` مستقلة تُنسخ | `backend/`، `web/`، `kit/` |
| K2 | الحسابات: بريد وكلمة مرور، وجوال وOTP، وأدوار وصلاحيات، وسجل دخول | `kit/Auth` |
| K3 | الهوية: الاسم والشعار والألوان من الإعدادات، تُحقن متغيرات CSS بلا بناء | `kit/Brand` |
| K4 | اللغتان وRTL، والعملة والمنطقة الزمنية والضريبة | `kit/Locale` |
| K5 | الدفع: واجهة `PaymentGateway`، ومزوّد أول (حسب البلد الأول) ونقدي، وWebhook موقّع | `kit/Payments` |
| K6 | الإشعارات: بريد وواتساب وSMS وFCM خلف واجهة واحدة، وقوالب تُعدَّل | `kit/Notify` |
| K7 | الترخيص والمثبّت وسجل التدقيق والنسخ الاحتياطي | `kit/License`، `kit/Install`، `kit/Audit`، `kit/Backup` |
| K8 | الأخطاء `{message, code, errors?}` بالعربية، وساعة قابلة للتحريك للاختبارات | `kit/Errors`، `kit/Clock` |
| B1 | الموارد: نوع (موظف، مكان، غرفة)، وسعة، وجدول أسبوعي وإجازات | `App\Resources` |
| B2 | الخدمات: المدة، السعر، وقت فاصل قبل وبعد، والموارد التي تقدمها | `App\Services` |
| B3 | قواعد السعر: بحسب اليوم والساعة (ذروة)، ومدة أقل وأكثر | `PriceRule` |
| W1 | الإطار ومكونات `components/ui` (زر، حقل، نافذة، جدول، Toast) ونظام `tokens.json` | `web/src` |
| W2 | شاشات الإعدادات: الهوية، الفروع، الموارد، الخدمات، الأسعار | `pages/settings` |
| D1 | مسودات: صفحة الحجز العامة، التقويم، التطبيق | `docs/design` |

**تعريف الانتهاء:**
- [ ] `kit/` بلا أي اعتماد على كود الحجز (فحص آلي للاستيراد)، وله اختباراته.
- [ ] التركيب على جهاز نظيف بالمعالج، والترخيص يُفحص.
- [ ] دفع تجريبي في بيئة اختبار البوابة ينجح، وWebhook مكرر لا يُسجَّل مرتين.
- [ ] ملعب بسعر ذروة مساءً وسعر عادي نهاراً يُحفظ ويُسعَّر صحيحاً (Unit).

**كيف يُختبر:** ركّب، غيّر الهوية، عرّف صالوناً (3 موظفين و5 خدمات) وملعباً بسعرين.
