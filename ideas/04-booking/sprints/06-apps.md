# Sprint 06: التطبيق

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** تطبيق واحد باسم النشاط: العميل يحجز منه، والموظف يرى يومه.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | API التطبيق بتوكن ينتهي، وهوية التطبيق من الخادم | `/app/v1` |
| M1 | مشروع Flutter وحزمة `kit_mobile` مشتركة للمشاريع القادمة: الشبكة، الدخول، الهوية، الإشعارات، اللغتان | `mobile/`، `packages/kit_mobile` |
| M2 | العميل: الخدمات، الحجز، الدفع، حجوزاتي، باقاتي، نقاطي، التقييم | `features/customer` |
| M3 | الموظف (نفس التطبيق بدور مختلف): يومي، تفاصيل الحجز، حضر أو لم يحضر | `features/staff` |
| M4 | إشعارات: تأكيد، تذكير، فترة أُتيحت، عرض | `kit_mobile/push` |
| M5 | سكربت بناء العلامة من ملف واحد | `tool/brand.dart` |

**تعريف الانتهاء:**
- [ ] `kit_mobile` بلا اعتماد على كود الحجز، وتُنسخ لمشروع آخر كما هي.
- [ ] علامتان مختلفتان تُبنيان بلا تعديل يدوي.
- [ ] الحجز من التطبيق يظهر في التقويم فوراً.
- [ ] لا سعر ولا توفر يُحسب في التطبيق.
- [ ] RTL والإنجليزية وشاشة 360px، واختبارات ودجت.

**كيف يُختبر:** ابنِ بعلامة صالون وبعلامة ملعب، احجز من كلٍّ، وافتح حساب موظف وتابع يومه.
