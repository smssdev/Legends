# Sprint 05: التذكيرات والعملاء والباقات

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** العميل لا ينسى موعده، ويعود مرة بعد مرة بباقة أو اشتراك.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | التذكيرات: قبل الموعد بمدد يحددها المالك، وأزرار تأكيد وإلغاء في واتساب، وWebhook | `App\Reminders` |
| B2 | قائمة الانتظار: تبليغ المنتظرين عند إلغاء فترة | `Waitlist` |
| B3 | ملف العميل: حجوزاته، إنفاقه، ملاحظات (لون الصبغة، المقاس)، وعلامات | `App\Customers` |
| B4 | الباقات: 10 جلسات بسعر، رصيد جلسات يُخصم بالحجز، وصلاحية | `Package` |
| B5 | الاشتراكات: شهري بعدد حجوزات أو ساعات (ملعب كل خميس)، وتجديد | `Membership` |
| B6 | الولاء: نقاط بكل حجز، وبطاقات هدايا برمز | `Loyalty`، `GiftCard` |
| B7 | التقييم بعد الموعد برابط، وعرضه في الصفحة العامة بعد المراجعة | `Reviews` |
| B8 | حملات: عيد ميلاد، لم يحجز منذ مدة، عرض ساعات فارغة اليوم | `Campaigns` |
| W1 | إعدادات التذكير والقوالب، وسجل الرسائل | `pages/settings/Reminders` |
| W2 | شاشات العملاء والباقات والاشتراكات | `pages/customers` |
| W3 | شراء باقة أو بطاقة هدية من الصفحة العامة | `book/` |

**تعريف الانتهاء:**
- [ ] رصيد الجلسات مجموع حركاته، والحجز الملغى يعيد الجلسة حسب السياسة.
- [ ] التذكير لا يتكرر ولا يُرسل لحجز ملغى (اختبار بالساعة المحرّكة).
- [ ] بطاقة الهدية تُصرف مرة واحدة بقيمتها، وجزئياً يبقى رصيدها.
- [ ] اشتراك منتهٍ لا يحجز، وتجديده يفتح الحجز.
- [ ] بلا مفاتيح واتساب تعمل الرسائل بالبريد وتظهر في السجل.

**كيف يُختبر:** اشترِ باقة 5 جلسات، احجز منها اثنتين، ألغِ واحدة، وحرّك الساعة لتصل التذكيرات.
