# Sprint 03: صفحة الحجز العامة والدفع

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** العميل يفتح رابط النشاط ويحجز ويدفع العربون في أقل من دقيقة، بلا تنزيل ولا حساب.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | API عام: الخدمات، الموارد، الأيام المتاحة، الفترات، السعر | `PublicController` |
| B2 | هوية العميل بالجوال وOTP عند التأكيد فقط، وحماية من الإغراق | `GuestIdentity` |
| B3 | سياسة الدفع لكل خدمة: بلا دفع، عربون (نسبة أو مبلغ)، أو كامل | `PaymentPolicy` |
| B4 | سياسة الإلغاء: مجاني حتى X ساعة، ثم خصم العربون أو جزء منه، واسترجاع تلقائي | `CancellationPolicy` |
| B5 | الكوبونات وأسعار العروض | `Coupon` |
| B6 | صفحة «حجزي» برابط موقّع: تفاصيل، تأجيل، إلغاء، إضافة للتقويم (ICS)، موقع النشاط | `MyBookingController` |
| B7 | تأكيد فوري بواتساب أو SMS مع الرابط | `BookingConfirmed` |
| W1 | صفحة الحجز: خدمة، ثم موظف (أو أي أحد)، ثم يوم وساعة، ثم بياناتك والدفع. جوال أولاً | `book/` |
| W2 | صفحة النشاط العامة: صور، خدمات، ساعات، خريطة، تقييمات | `book/pages/Profile` |
| W3 | ودجت يُضمَّن في أي موقع، وزر «احجز» لإنستغرام (رابط قصير وQR) | `embed/` |

**تعريف الانتهاء:**
- [ ] حجز ملعب بعربون من جوال حقيقي في أقل من 60 ثانية.
- [ ] فشل الدفع أو إغلاق الصفحة يحرر الفترة بعد المهلة.
- [ ] الإلغاء قبل المهلة يعيد العربون كاملاً، وبعدها حسب السياسة (Unit للحدود).
- [ ] الصفحة أقل من 150KB وتفتح في ثانيتين على 3G.
- [ ] الرابط الموقّع لا يُخمَّن، ولا يكشف حجز غير صاحبه.
- [ ] axe بلا أخطاء، واللمس 44px.

**كيف يُختبر:** احجز من الجوال بالبطاقة التجريبية، أجّل، ثم ألغِ قبل المهلة وبعدها وراجع الاسترجاع.
