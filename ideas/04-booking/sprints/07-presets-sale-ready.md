# Sprint 07: قوالب الأنشطة والتجهيز للبيع

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** المشتري يختار نشاطه عند التركيب فيجد النظام بلغته ومصطلحاته، ونحن جاهزون للبيع.

| الرمز | المهمة | الملفات |
|---|---|---|
| S1 | القوالب: صالون، ملعب، قاعة، وعام. كل قالب يضبط نمط الفترات، والمصطلحات (موظف، ملعب، قاعة)، والشاشات الظاهرة، وبيانات نموذجية | `App\Presets` |
| S2 | معالج البدء: النشاط، ساعات العمل، أول خدمات، الدفع، ورابط الحجز جاهز للمشاركة | `pages/onboarding` |
| S3 | خادم التراخيص (يُبنى هنا لكل المشاريع): إصدار، ربط بالدومين، تعطيل، قناة التحديثات | مستودع `license-server` |
| S4 | المثبّت والتحديث والتراجع مجرَّبة على سيرفر نظيف | `deploy/` |
| S5 | ثلاثة مواقع تجريبية (صالون، ملعب، قاعة) تُعاد كل ساعة | `DemoSeeder` |
| S6 | ثلاث صفحات هبوط، والأسعار، وفيديو لكل نشاط | `site/` |
| S7 | دليل المستخدم والتركيب ونشر التطبيق | `docs/` |
| S8 | فحص الأمان واختبار الحمل (حجز جماعي عند فتح أسبوع جديد) | `tests/` |
| S9 | عقد الترخيص وسياسة الخصوصية وشروط الدعم (مسودات) | `docs/legal` |
| S10 | مراجعة `kit/` و`kit_mobile`: توثيقها ورقم إصدارها لتُنسخ للمشروع التالي | `kit/README` |

**تعريف الانتهاء:**
- [ ] من التركيب إلى رابط حجز يعمل في أقل من 15 دقيقة.
- [ ] كل قالب بلا مصطلح من قالب آخر في أي شاشة.
- [ ] نشاط حقيقي واحد (ملعب أو صالون) يعمل عليه أسبوعين، وملاحظاته مغلقة.
- [ ] خادم التراخيص يصدر ويعطّل، والنسخة تستجيب.
- [ ] المواقع التجريبية وصفحات الهبوط على الدومين.

**كيف يُختبر:** ركّب ثلاث نسخ بثلاثة قوالب، واحجز من كلٍّ، ثم سلّم نسخة لنشاط حقيقي.
