# Sprint 05: المخزون والوصفات والمشتريات

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل |

**الهدف:** المالك يعرف كلفة كل صنف وربحه، وما في المخزن، وما نقص أو هُدر.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | المكونات: وحدة شراء ووحدة استعمال ومعامل التحويل، وحد أدنى، ومخزن لكل فرع | `App\Stock\Ingredient` |
| B2 | الوصفة: مكونات كل صنف وإضافة بكمياتها، ووصفات نصف مصنّعة (صلصة تدخل في أصناف) | `Recipe` |
| B3 | حركات المخزون: شراء، بيع (خصم تلقائي من الوصفة)، هدر، تحويل بين فروع، تسوية جرد. الرصيد مجموع الحركات | `StockMovement` |
| B4 | الكلفة: متوسط مرجّح، وكلفة الصنف ونسبة كلفة الطعام | `Costing` |
| B5 | الموردون وأوامر الشراء واستلام البضاعة وفاتورة المورد ومديونيته | `Supplier`، `Purchase` |
| B6 | الجرد: ورقة عدّ، وفرق الفعلي عن النظري بالقيمة | `StockCount` |
| B7 | تنبيه الحد الأدنى، واقتراح طلبية من معدل الاستهلاك | `Reorder` |
| B8 | إيقاف الصنف تلقائياً عند نفاد مكوّن أساسي (اختياري) | `AutoOutOfStock` |
| W1 | شاشات المكونات والوصفات مع الكلفة الحية | `pages/stock` |
| W2 | المشتريات والاستلام، والهدر، والتحويل | `pages/purchases` |
| W3 | الجرد من الجوال، وتقرير الفروقات | `pages/stockcount` |

**تعريف الانتهاء:**
- [ ] بيع 10 برجر يخصم الخبز واللحم والصلصة بكمياتها، والمرتجع يعيدها.
- [ ] رصيد أي مكوّن يساوي مجموع حركاته (اختبار)، والكميات أرقام صحيحة بأصغر وحدة.
- [ ] طلبات أُخذت بلا إنترنت تخصم المخزون عند المزامنة بتوقيتها الأصلي.
- [ ] تغيير سعر الشراء يغيّر كلفة الأصناف المرتبطة عبر الوصفات النصف مصنّعة.
- [ ] Unit للتحويل بين الوحدات والمتوسط المرجّح.

**كيف يُختبر:** عرّف وصفة خمسة أصناف، اشترِ بضاعة، بع يوماً كاملاً بالبذرة، اجرد بفروق مقصودة، وراجع التقرير.
