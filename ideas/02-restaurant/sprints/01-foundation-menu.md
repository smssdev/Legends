# Sprint 01: الأساس والفروع والمنيو

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** مالك يدخل ويبني منيو مطعمه كاملاً بصوره وإضافاته وأسعاره لكل فرع.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | مستودع جديد ونسخ `kit/` (الحسابات، الأدوار، الهوية، اللغتان، الترخيص، التدقيق) | `backend/`، `web/` |
| B2 | الفروع: العملة، الضريبة (شاملة أو مضافة)، رسم الخدمة، ساعات العمل | `App\Branches` |
| B3 | المنيو: فئات وأصناف باسمين عربي وإنجليزي، صورة، سعر، باركود، ترتيب، إتاحة بالوقت (فطور، غداء) | `App\Menu` |
| B4 | الإضافات: مجموعات (إجباري أو اختياري، حد أدنى وأعلى) وخيارات بسعر، والأحجام | `ModifierGroup` |
| B5 | الوجبات المركبة (Combo) بسعر واحد | `Combo` |
| B6 | سعر وإتاحة لكل فرع، و«نفد اليوم» بضغطة | `BranchItem` |
| B7 | استيراد المنيو من Excel، ونسخ منيو فرع إلى آخر | `MenuImport` |
| W1 | الإطار والدخول واختيار الفرع | `web/src/layouts` |
| W2 | محرر المنيو: سحب للترتيب، ورفع صور مع ضغطها | `pages/menu` |
| D1 | مسودات الكاشير وشاشة المطبخ والمنيو العام قبل أي واجهة لها | `docs/design` |

**تعريف الانتهاء:**
- [ ] صنف بحجمين ومجموعة إضافات إجبارية ومجموعة اختيارية يُحفظ ويُعرض صحيحاً.
- [ ] تغيير سعر في فرع لا يمس الفروع الأخرى.
- [ ] استيراد 200 صنف من Excel مع تقرير بالصفوف الخاطئة.
- [ ] Unit لحساب سعر الصنف مع إضافاته والضريبة ورسم الخدمة (أرقام صحيحة).

**كيف يُختبر:** أدخل منيو كافيه حقيقي (30 صنفاً) من الصفر وقِس الوقت، ثم انسخه لفرع ثانٍ وغيّر سعرين.
