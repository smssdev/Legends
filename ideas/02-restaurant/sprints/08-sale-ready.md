# Sprint 08: التجهيز للبيع

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** مطعم يشتري ويبدأ البيع في يوم واحد، وموزع الأجهزة يركّبه وحده.

| الرمز | المهمة | الملفات |
|---|---|---|
| S1 | ربط خادم التراخيص: ترخيص لكل فرع وعدد أجهزة | `kit/License` |
| S2 | المثبّت والتحديث مجرَّبان، ومثبّت جسر الطباعة لويندوز وأندرويد | `deploy/`، `bridge/installer` |
| S3 | معالج البدء: نوع النشاط، منيو نموذجي جاهز (كافيه، برجر، مشويات)، الطابعة، أول وردية | `pages/onboarding` |
| S4 | الموقع التجريبي: كاشير ومطبخ ومنيو QR ببيانات وهمية | `DemoSeeder` |
| S5 | قائمة الأجهزة المدعومة المجرَّبة، ودليل توصيلها بالصور | `docs/hardware.md` |
| S6 | صفحة الهبوط والأسعار والفيديو، وصفحة الموزعين | `site/` |
| S7 | دليل الكاشير والمدير والمالك، وفيديوهات قصيرة لكل مهمة | `docs/` |
| S8 | فحص الأمان واختبار الحمل (5 كاشيرات، 2000 طلب في اليوم) | `tests/` |
| S9 | اختبار الصمود: يوم كامل بانقطاعات عشوائية للشبكة والطابعة | `tests/Chaos` |
| S10 | عقد الترخيص وشروط الدعم واتفاقية الموزع (مسودات) | `docs/legal` |

**تعريف الانتهاء:**
- [ ] من التركيب إلى أول فاتورة مطبوعة في أقل من ساعة بالدليل وحده.
- [ ] يوم الصمود ينتهي بلا طلب مفقود ولا مكرر، وZ مطابق.
- [ ] مطعم حقيقي واحد يعمل عليه أسبوعين، وملاحظاته مغلقة.
- [ ] الموقع التجريبي وصفحة الهبوط على الدومين.

**كيف يُختبر:** ركّب عند كافيه صديق، ودعه يعمل وردية كاملة وأنت تراقب فقط.
