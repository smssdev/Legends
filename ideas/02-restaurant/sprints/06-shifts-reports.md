# Sprint 06: الورديات والخزنة والتقارير

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** كل وردية تُقفل بخزنة مطابقة، والمالك يتابع فروعه من جواله.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | الوردية: فتح برصيد افتتاحي، وإقفال بعدّ النقد، والفرق زيادة أو عجز | `App\Shifts` |
| B2 | حركات الخزنة: إيداع وسحب ومصروف نثري بسبب وصلاحية | `CashMovement` |
| B3 | تقرير X (أثناء الوردية) وZ (الإقفال): المبيعات بالطريقة والنوع، والخصومات والمرتجعات والإلغاءات | `ShiftReport` |
| B4 | حضور الموظفين بالـ PIN وساعاتهم | `Attendance` |
| B5 | التقارير: المبيعات بالساعة واليوم والصنف والفئة والكاشير والفرع، الأكثر والأقل مبيعاً، الربح بعد الكلفة، الضريبة | `App\Reports` |
| B6 | تقرير المخاطر: خصومات وإلغاءات كل موظف، وفتح الدرج بلا بيع | `RiskReport` |
| B7 | ملخص يومي للمالك بواتساب أو بريد عند آخر إقفال | `DailyDigest` |
| W1 | فتح وإقفال الوردية في الكاشير وطباعة Z | `pos/src/pages/Shift` |
| W2 | لوحة المالك: اليوم حياً لكل فرع، ومقارنة بالأمس والأسبوع | `pages/dashboard` |
| W3 | شاشات التقارير بفلاتر وتصدير Excel وPDF | `pages/reports` |

**تعريف الانتهاء:**
- [ ] تقرير Z يساوي مجموع طلبات الوردية ومدفوعاتها بالقرش (اختبار).
- [ ] لا بيع بلا وردية مفتوحة، ولا إقفال وفيها طاولة مفتوحة إلا بتحويلها.
- [ ] إقفال وردية بلا إنترنت يُزامن لاحقاً صحيحاً.
- [ ] اللوحة تفتح في أقل من ثانيتين على سنة مبيعات (500 ألف طلب مولّدة).
- [ ] المالك يرى كل الفروع، ومدير الفرع فرعه فقط.

**كيف يُختبر:** افتح وردية، بع، اسحب مصروفاً، أقفل بعجز مقصود، وراجع Z وتقرير المخاطر.
