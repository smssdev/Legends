# Sprint 06: التلعيب

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** الطالب يعود كل يوم لأنه يريد، لا لأنه مُلزَم.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | النقاط (XP): قواعد قابلة للضبط لكل حدث (درس، تمرين، مراجعة، حضور حصة)، وسجل حركات. تكافئ الجهد والإتقان لا السرعة | `App\Game\Xp`، `config/gamification.php` |
| B2 | المستويات من مجموع النقاط بمنحنى | `Levels` |
| B3 | السلاسل: أيام متتالية بهدف يومي يختاره الطالب، و«تجميد» يحمي السلسلة مرة | `Streaks` |
| B4 | الشارات: بشروط يعرّفها المشرف (إتقان وحدة، 7 أيام، مساعدة زميل)، بثلاثة مستويات | `Badges` |
| B5 | لوحات الترتيب: أسبوعية، داخل الفصل، بمجموعات متقاربة المستوى، ويمكن إخفاؤها | `Leagues` |
| B6 | تحديات الفصل: هدف جماعي بمدة (الفصل كله يتقن الوحدة) | `ClassChallenge` |
| B7 | مكافآت يحددها المعلم تُصرف بالنقاط (امتياز في الفصل)، بلا مال | `Rewards` |
| B8 | منع التلاعب: لا نقاط لتكرار نفس السهل، وحد يومي | `XpGuard` |
| B9 | مفاتيح: تشغيل وإيقاف كل عنصر لكل مؤسسة ومرحلة (الكبار قد لا يريدونه) | `GameSettings` |
| W1 | شريط التقدم والسلسلة في رئيسية الطالب، واحتفال قصير عند الإنجاز | `components/game` |
| W2 | صفحة الإنجازات واللوحة والتحديات | `pages/student/Achievements` |
| W3 | إعدادات التلعيب ومحرر الشارات | `pages/academic/Gamification` |

**تعريف الانتهاء:**
- [ ] مجموع نقاط الطالب يساوي حركاته، والحدث الواحد لا يُكافأ مرتين.
- [ ] السلسلة تُحسب بمنطقة الطالب الزمنية، والتجميد يعمل مرة (اختبار بالساعة المحرّكة).
- [ ] حل نفس التمرين السهل عشر مرات لا يعطي نقاطاً بعد الحد.
- [ ] إيقاف اللوحات يخفيها من الواجهة والـ API.
- [ ] الحركات تحترم «تقليل الحركة» في إعدادات الجهاز.
- [ ] Unit لقواعد النقاط والمستويات والسلاسل.

**كيف يُختبر:** حلّ بطالب ثلاثة أيام متتالية بتحريك الساعة، فوّت يوماً بالتجميد، وتابع الشارات واللوحة.
