# Sprint 01: المؤسسة والفصول والجدول

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 6 أيام عمل |
| **يعتمد على** | نواة المشروع 5 (الدورات، الفيديو، الاختبارات، الدفع) |

**الهدف:** مدرسة أو أكاديمية تعرّف سنتها وصفوفها وفصولها ومعلميها وطلابها وجدول حصصها.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | مستودع من نواة المشروع 5، ومزايا تُفتح بالترخيص (`features` في المفتاح) | `kit/License`، `App\Features` |
| B2 | المؤسسة: سنوات وفصول دراسية، مراحل وصفوف ومواد | `App\Org` |
| B3 | الفصل (الشعبة): طلابه، ومعلم كل مادة، ودورة لكل مادة تُربط بمنهجها | `App\Classes` |
| B4 | الجدول الأسبوعي: حصص بوقت ومعلم وفصل، ومنع تعارض المعلم والفصل | `Timetable` |
| B5 | الأدوار الخمسة، وولي الأمر مربوط بأبنائه، وموافقته المسجَّلة للقاصر | `Guardians`، `Consent` |
| B6 | استيراد الطلاب والمعلمين والفصول من Excel، وترقية الطلاب لسنة جديدة | `App\Import`، `Promotion` |
| B7 | دخول موحّد اختياري (Google وMicrosoft للمدارس) | `kit/Auth/Sso` |
| B8 | وضع المؤسسات المتعددة (باقة المنصة): عزل البيانات بمعرّف المؤسسة في كل استعلام | `Tenancy` |
| W1 | الإطار بأدواره: رئيسية المعلم (حصص اليوم)، رئيسية الطالب (يومي وما عليّ) | `web/src/layouts` |
| W2 | إدارة السنة والفصول والجدول (شبكة بالسحب) | `pages/admin` |
| D1 | مسودات: غرفة الفصل المباشر، رئيسية الطالب، لوحة المعلم، لوحة ولي الأمر | `docs/design` |

**تعريف الانتهاء:**
- [ ] حصة تتعارض مع حصة أخرى للمعلم أو الفصل تُرفض.
- [ ] مؤسستان على نسخة واحدة: لا استعلام يُرجع بيانات الأخرى (اختبار آلي على كل نموذج).
- [ ] استيراد 1000 طالب مع أولياء أمورهم بتقرير أخطاء.
- [ ] ميزة غير مرخّصة لا تظهر ومساراتها ترفض.
- [ ] المعلم يرى فصوله فقط.

**كيف يُختبر:** أنشئ مدرسة بثلاثة صفوف وستة فصول، استورد طلابها، وابنِ جدول أسبوع.
