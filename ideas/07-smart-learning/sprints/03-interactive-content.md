# Sprint 03: المحتوى التفاعلي

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل |

**الهدف:** المعلم يبني درساً يشارك فيه الطالب كل دقيقة، لا فيديو يُشاهَد فقط.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | النشاط: نوع ومحتوى JSON بمخطط لكل نوع، ومحاولات ونتيجتها | `App\Activities` |
| B2 | الفيديو التفاعلي: أسئلة عند دقائق محددة توقف الفيديو، وتفرّع حسب الإجابة | `InteractiveVideo` |
| B3 | أنواع الأنشطة: بطاقات تعليمية، سحب وإفلات، توصيل، ترتيب، ملء فراغ، تظليل على صورة، خط زمني، سؤال بالرسم | `ActivityTypes` |
| B4 | الدرس المصغّر: تتابع شرائح (نص، صورة، فيديو قصير، نشاط) بهدف واحد ومدة 3 إلى 7 دقائق | `MicroLesson` |
| B5 | التصحيح في الخادم لكل نوع، وتلميحات متدرجة، وشرح بعد الإجابة | `ActivityGrader` |
| B6 | تشغيل محتوى H5P المرفوع (حزم جاهزة) داخل إطار معزول، وتسجيل نتيجته | `H5pPlayer` |
| B7 | مكتبة محتوى للمؤسسة: مشاركة الأنشطة بين المعلمين، ووسوم، وبحث | `Library` |
| B8 | كل تفاعل يُسجَّل حدثاً (يغذّي التكيّف والتحليلات وxAPI) | `LearningEvent` |
| W1 | محرر الأنشطة لكل نوع بمعاينة فورية | `pages/teacher/ActivityEditor` |
| W2 | محرر الفيديو التفاعلي: خط زمني تُسقط عليه الأسئلة | `pages/teacher/VideoEditor` |
| W3 | مشغل الدرس المصغّر والأنشطة للطالب (لمس أولاً، ويعمل بلوحة المفاتيح) | `components/activities` |

**تعريف الانتهاء:**
- [ ] كل نوع نشاط: يُنشأ، يُحل، يُصحَّح في الخادم، والإجابة الصحيحة لا تصل قبل الحل.
- [ ] الفيديو التفاعلي يتوقف عند السؤال ولا يُتجاوز إن جعله المعلم إلزامياً.
- [ ] الأنشطة تعمل بالعربية RTL وباللمس على 360px وبقارئ الشاشة للأنواع الممكنة (axe).
- [ ] حزمة H5P لا تصل لبيانات الصفحة الأم (عزل).
- [ ] مخطط JSON لكل نوع مُتحقَّق منه عند الحفظ، وUnit لكل مصحّح.

**كيف يُختبر:** ابنِ درساً مصغراً في الكسور: فيديو دقيقتين بسؤالين، ثم سحب وإفلات، ثم بطاقات، وحلّه من جوال.
