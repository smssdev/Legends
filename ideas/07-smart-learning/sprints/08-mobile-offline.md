# Sprint 08: التطبيق والعمل بلا إنترنت

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 8 أيام عمل |

**الهدف:** تطبيق باسم المؤسسة للطالب والمعلم وولي الأمر: يحضر منه الحصة، ويتعلم ويراجع ولو بلا إنترنت.

| الرمز | المهمة | الملفات |
|---|---|---|
| M1 | مشروع Flutter فوق تطبيق المشروع 5 و`kit_mobile`، بثلاثة أدوار وبناء العلامة | `mobile/` |
| M2 | الطالب: يومي، الدروس، الأنشطة التفاعلية (نفس المخططات)، التمرين المتكيّف، مراجعة اليوم | `features/learn` |
| M3 | الفصل المباشر في التطبيق: فيديو وصوت ومحادثة ورفع يد واستطلاع، والسبورة عرضاً (والكتابة على التابلت) | `features/live` (LiveKit Flutter SDK) |
| M4 | بلا إنترنت: تنزيل وحدة كاملة (دروس مصغرة وأنشطة وبطاقات مراجعة)، وحلّها، وطابور أحداث يُزامن | `core/offline` |
| M5 | المعلم الذكي في التطبيق (يحتاج اتصالاً، ويقول ذلك بوضوح) | `features/tutor` |
| M6 | التلعيب: السلسلة والنقاط والشارات، وتذكير الهدف اليومي بإشعار | `features/game` |
| M7 | المعلم: حصص اليوم، بدء الحصة، الحضور، الرد على الرسائل، علامات الإنذار | `features/teacher` |
| M8 | ولي الأمر: أبناؤه، الملخص، الإشعارات، الرسائل | `features/guardian` |
| B1 | مزامنة الأحداث: دفعات بمعرّفات فريدة تُقبل مرة واحدة، وتُطبَّق على الإتقان بتوقيتها الأصلي | `SyncController` |
| B2 | تصحيح الأنشطة المحلولة بلا إنترنت: يُعاد في الخادم عند المزامنة (الخادم هو المرجع) | `OfflineGrading` |

**تعريف الانتهاء:**
- [ ] وحدة منزّلة تُحل كاملة في وضع الطيران، وعند العودة يصل التقدم والنقاط مرة واحدة.
- [ ] نتيجة التطبيق المؤقتة تُستبدل بنتيجة الخادم إن اختلفت.
- [ ] حصة مباشرة من جوال متوسط على 4G مستقرة نصف ساعة.
- [ ] الإجابات الصحيحة للاختبارات المقيَّمة لا تُنزَّل للجهاز (الأنشطة التدريبية فقط تعمل بلا إنترنت).
- [ ] RTL والإنجليزية، وتابلت وجوال.
- [ ] علامتان تُبنيان بلا تعديل يدوي.

**كيف يُختبر:** نزّل وحدة، حلّها في وضع الطيران، ارجع وتابع المزامنة، ثم احضر حصة مباشرة من الجوال.
