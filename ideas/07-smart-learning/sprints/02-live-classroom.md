# Sprint 02: الفصل المباشر

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 10 أيام عمل |

**الهدف:** المعلم يفتح حصته من الجدول بضغطة: فيديو وسبورة ومشاركة شاشة وغرف جانبية، والحضور يُسجَّل وحده، والتسجيل يُحفظ في الدورة.

| الرمز | المهمة | الملفات |
|---|---|---|
| I1 | LiveKit وخادم TURN وEgress في Docker Compose، ومواصفات السيرفر المطلوبة | `deploy/livekit` |
| B1 | الجلسة: تُنشأ من الجدول أو فورياً، وتوكن دخول بصلاحيات الدور (معلم، طالب، مراقب) | `App\Live\Session` |
| B2 | أدوات الضبط: كتم الكل، منح الكلام، رفع اليد، قفل المحادثة، إخراج، غرفة انتظار | `Moderation` |
| B3 | الغرف الجانبية: توزيع عشوائي أو يدوي، مؤقت، تنقل المعلم بينها، نداء للعودة | `Breakouts` |
| B4 | الحضور: دخول وخروج كل طالب ومدة حضوره، ومحسوب حاضراً بقاعدة (نسبة من الحصة) | `LiveAttendance` |
| B5 | التسجيل: تسجيل مركّب، تحويله إلى HLS محمي (خط المشروع 5)، وإضافته درساً في الدورة | `Recording` |
| B6 | استطلاع وسؤال سريع أثناء الحصة، ونتيجته حية، وتُحفظ | `LivePoll` |
| B7 | السبورة: حالة مشتركة حية، صفحات، حفظ وتصدير PDF، وإذن الكتابة للطلاب | `Whiteboard` |
| W1 | غرفة الفصل: شبكة الفيديو، المتحدث، مشاركة الشاشة، المحادثة، القائمة، رفع اليد | `live/Room` |
| W2 | السبورة: قلم وأشكال ونص عربي ومعادلات وصور وPDF كخلفية | `live/Board` |
| W3 | فحص الجهاز قبل الدخول (كاميرا، ميكروفون، شبكة)، وتكيّف الجودة مع الشبكة، ووضع صوت فقط | `live/Precheck` |
| W4 | ملخص الحصة للمعلم: الحضور، المشاركة، نتائج الاستطلاعات | `pages/teacher/SessionReport` |

**تعريف الانتهاء:**
- [ ] حصة بـ 40 طالباً ومعلم لساعة مستقرة على السيرفر بالمواصفات المكتوبة (اختبار حمل بعملاء آليين).
- [ ] طالب لا يدخل حصة فصل ليس فيه، ولا يفتح ميكروفونه بلا إذن حين يمنعه المعلم (الصلاحية في التوكن لا في الواجهة).
- [ ] انقطاع شبكة الطالب يعيده تلقائياً بلا إعادة تحميل.
- [ ] التسجيل يظهر في الدورة خلال مدة معقولة بعد الحصة، محمياً كباقي الفيديو.
- [ ] السبورة متزامنة لكل الحاضرين، والعربية والمعادلات سليمة.
- [ ] الغرف الجانبية: توزيع، ومؤقت، وعودة الجميع.

**كيف يُختبر:** حصة حقيقية بخمسة أجهزة (منها جوال بشبكة ضعيفة): سبورة، مشاركة شاشة، غرفتان جانبيتان، استطلاع، ثم مشاهدة التسجيل.

**تنبيه:** تُقرأ وثائق LiveKit الحالية قبل البناء (الإصدارات والواجهات تتغير).
