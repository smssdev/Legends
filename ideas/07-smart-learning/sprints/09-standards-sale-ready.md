# Sprint 09: المعايير والتجهيز للبيع

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل |

**الهدف:** المنصة تتكلم لغة أنظمة التعليم الأخرى، وجاهزة لتُركَّب عند مدرسة وتُباع.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | xAPI: تحويل أحداث التعلم إلى عبارات، ومخزن داخلي، وتصدير أو إرسال لمخزن خارجي | `App\Standards\Xapi` |
| B2 | استيراد SCORM 1.2 و2004: تشغيل الحزمة في إطار معزول وتسجيل الإتمام والدرجة | `ScormPlayer` |
| B3 | LTI 1.3: المنصة أداة تُفتح من نظام آخر، ومنصة تفتح أدوات خارجية | `Lti` |
| B4 | ربط نظام شؤون الطلاب: استيراد دوري CSV أو OneRoster للطلاب والفصول | `Roster` |
| B5 | API عام موثّق بمفاتيح وWebhooks (تسجيل، إتمام، درجة) | `PublicApi` |
| S1 | المثبّت الكامل: التطبيق، LiveKit وTURN، التحويل، pgvector، ودليل المواصفات لكل حجم (200، 1000، 5000 طالب) | `deploy/` |
| S2 | ربط خادم التراخيص بالمزايا والحد الأقصى للطلاب النشطين | `kit/License` |
| S3 | الموقع التجريبي: مدرسة وهمية بأدوارها، وحصة مباشرة تجريبية مجدولة، ومعلم ذكي بحد استعمال | `DemoSeeder` |
| S4 | اختبار الحمل: 10 حصص مباشرة معاً × 30 طالباً، و2000 طالب نشط | `tests/Load` |
| S5 | فحص الأمان والخصوصية: العزل بين المؤسسات، بيانات القاصرين، حمولة AI | `tests/Security` |
| S6 | الوصول: axe على كل الشاشات، ولوحة المفاتيح، وقارئ الشاشة للمسارات الأساسية | `e2e/` |
| S7 | الوثائق: التركيب، دليل كل دور، دليل المشرف الأكاديمي لبناء خريطة المهارات، ودليل التدريب | `docs/` |
| S8 | صفحة الهبوط، وعرض تقديمي للمدارس، وفيديو، وعقد الترخيص واتفاقية معالجة البيانات (مسودات) | `site/`، `docs/legal` |

**تعريف الانتهاء:**
- [ ] حزمة SCORM نموذجية تعمل وتسجّل الإتمام، وربط LTI يمر مع منصة مرجعية (مثل Moodle تجريبي).
- [ ] عبارات xAPI صالحة حسب المواصفة (فاحص آلي).
- [ ] اختبار الحمل يمر على المواصفات المكتوبة.
- [ ] لا تسريب بين المؤسسات في أي مسار.
- [ ] أكاديمية حقيقية واحدة تعمل عليها شهراً (حصص حية ومتكيّف وAI)، وملاحظاتها مغلقة.
- [ ] الموقع التجريبي وصفحة الهبوط على الدومين.

**كيف يُختبر:** ركّب عند أكاديمية صغيرة، درّب معلميها بالدليل، وتابع أول أسبوعين.

**تنبيه:** مواصفات LTI وxAPI وSCORM تُقرأ من مصادرها الرسمية قبل البناء.
