# منصة تعلم ذكية بأحدث التقنيات التعليمية

## الفكرة

منصة تعليم أونلاين للمدارس والأكاديميات تجمع ما في التعليم الحديث: فصل مباشر بسبورة وغرف جانبية، ومحتوى تفاعلي، وتعلم يتكيّف مع مستوى كل طالب، ومعلم مساعد بالذكاء الاصطناعي، وتلعيب، وتحليلات تنذر مبكراً بالطالب المتعثر.

**علاقتها بالمشروع 5:** تُبنى فوق نواة منصة الدورات (الدورات والفيديو والاختبارات والدفع)، وتضيف ما في هذا الملف. فالمشروع 5 يُنفَّذ قبلها.

## المشتري

- المدارس الخاصة والدولية (تعليم مدمج وعن بعد).
- أكاديميات اللغات والبرمجة والتحفيظ والدروس الحية.
- مراكز التدريب المهني والشركات (تدريب الموظفين).
- منصات تعليم ناشئة تريد أساساً جاهزاً بعلامتها.

## التقنيات التعليمية التي تضمها

| التقنية | ما تعنيه في المنصة |
|---|---|
| الفصل الافتراضي المباشر | فيديو وصوت، سبورة مشتركة، مشاركة شاشة، غرف جانبية، رفع اليد، استطلاعات، تسجيل |
| المحتوى التفاعلي | فيديو بأسئلة داخله، بطاقات، سحب وإفلات، محاكاة بسيطة، ومتوافق مع H5P |
| التعلم المتكيّف | خريطة مهارات، وتقدير إتقان كل مهارة، ومسار يختار التالي لكل طالب |
| التكرار المتباعد | مراجعات مجدولة لما تعلّمه حتى لا يُنسى |
| التعلم المصغّر | دروس 3 إلى 7 دقائق بهدف واحد |
| المعلم الذكي (AI) | يشرح ويسأل ويلمّح بلا إعطاء الحل، من محتوى الدورة نفسها |
| مساعد المعلم (AI) | يولّد أسئلة وخطط دروس، ويقترح تصحيح المقالي للمراجعة |
| التلعيب | نقاط وشارات وسلاسل أيام ومستويات وتحديات فصل |
| تحليلات التعلم | لوحات للمعلم والإدارة وولي الأمر، وإنذار مبكر |
| المعايير | xAPI وSCORM (استيراد) وLTI (ربط بأنظمة أخرى) |

## ما يميزنا

- عربي أولاً: الواجهة، والسبورة، والمعادلات، والمعلم الذكي بالعربية.
- كل شيء في منتج واحد يملكه المشتري (بدل Zoom ومعه LMS ومعه أداة اختبارات).
- الفصل المباشر مفتوح المصدر على سيرفره (LiveKit)، بلا اشتراك لكل مستخدم.
- الذكاء الاصطناعي بمفتاح المشتري ومزوّد يختاره، ويعمل النظام كله بدونه.

## النطاق

**v1:** المؤسسة والفصول والمناهج، الفصل المباشر، المحتوى التفاعلي، التكيّف والتكرار المتباعد، المعلم الذكي ومساعد المعلم، التلعيب، التحليلات وولي الأمر، التطبيق، المعايير.

**بعد v1:** مراقبة الامتحانات بالكاميرا، الواقع المعزز، سوق محتوى بين المدارس، الترجمة الحية للحصص.

| المشرف الأكاديمي | المناهج وخريطة المهارات ومتابعة المعلمين |
| المعلم | حصصه ومحتواه وطلابه وتقييمهم |

## نموذج البيانات (مختصر)

فوق جداول المشروع 5: `orgs`، `terms`، `classes`، `class_members`، `timetable`، `live_sessions`، `live_attendance`، `recordings`، `whiteboards`، `activities`، `activity_attempts`، `skills`، `skill_edges`، `item_skills`، `mastery`، `review_queue`، `ai_threads`، `ai_messages`، `ai_usage`، `xp_moves`، `badges`، `streaks`، `xapi_statements`، `risk_flags`، `guardians`.

## التقنية

- نواة المشروع 5 والأساس المشترك.
- **الفصل المباشر:** LiveKit (مفتوح المصدر، WebRTC SFU) على سيرفر المشتري مع خادم TURN، وتسجيل عبر LiveKit Egress.
- **السبورة:** tldraw أو Excalidraw (يُفحص ترخيص كلٍّ للاستعمال التجاري قبل الاختيار) مع مزامنة حية.
- **التكيّف:** نموذج إتقان بسيط قابل للتفسير (تقدير بايزي لكل مهارة) بأرقام صحيحة، لا صندوق أسود.
- **الذكاء الاصطناعي:** واجهة `AiProvider` بمزوّدات قابلة للتبديل، واسترجاع من محتوى الدورة (pgvector)، وحدود استعمال لكل طالب، وسجل كامل. **الكلفة على المشتري بمفتاحه.**
- **xAPI:** مخزن عبارات داخلي بسيط (LRS).

## التسويق

- عرض حي لإدارة المدرسة (حصة تجريبية كاملة في 15 دقيقة).
- المعارض التعليمية، وموردو الأجهزة والسبورات الذكية للمدارس كشركاء.
- تجربة فصل دراسي مجاني لمدرسة مرجعية في كل بلد.
- محتوى: «كيف تعرف الطالب المتعثر قبل الامتحان».

## المخاطر

| الخطر | التعامل معه |
|---|---|
| الحجم كبير | يُبنى بعد المشروع 5 وفوقه، وكل سبرنت يُباع إضافة مستقلة إن لزم |
| جودة الفصل المباشر تعتمد على سيرفر وشبكة المشتري | مواصفات مكتوبة، واختبار حمل، وخيار LiveKit Cloud المدفوع بمفتاحه |
| أخطاء الذكاء الاصطناعي مع الطلاب | يجيب من محتوى الدورة مع ذكر مصدره، ويقول «لا أعرف»، والمعلم يرى كل المحادثات، وزر تبليغ |
| خصوصية القاصرين | موافقة ولي الأمر، ولا إرسال بيانات شخصية للمزوّد (تُحذف الأسماء)، وإيقاف AI لكل مؤسسة أو صف |
| دورة بيع طويلة للمدارس | الأكاديميات أولاً (قرارها أسرع) |
| تصحيح AI للمقالي | اقتراح للمعلم فقط، لا درجة نهائية آلية |
