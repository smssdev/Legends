# نظام العقارات وإدارة الأملاك

## الفكرة

نظام لمكتب عقاري أو مالك عمارات: العقارات والوحدات، والمستأجرون والعقود، واستحقاقات الإيجار وتحصيلها وسنداتها، والصيانة، وحساب كل مالك وعمولة المكتب، وبوابة للمستأجر والمالك.

## المشتري

- مكاتب إدارة الأملاك (تدير عقارات ملاك مقابل نسبة).
- ملاك العمارات والمجمعات والمحلات.
- شركات تأجير السكن الطلابي وسكن العمال.
- خارج النطاق (v1): التسويق العقاري والبيع وبوابات الإعلانات.

## ما يميزنا

- حساب المالك وعمولة المكتب آلياً (ما يُعمل اليوم في Excel).
- تذكير الإيجار بواتساب ورابط دفع.
- عربي، وبالتقويمين الهجري والميلادي في العقود.
- نسخة يملكها المكتب ببياناته.

## النطاق

**v1:** العقارات والوحدات، الملاك، المستأجرون، العقود وتجديدها وإنهاؤها، الاستحقاقات والتحصيل والسندات، التأمين، الصيانة والمصروفات، حسابات الملاك والتحويلات، التقارير، البوابة والتطبيق.

**بعد v1:** الربط بالمنصات الحكومية للعقود (مثل إيجار في السعودية، إن أُتيح ربط)، عرض الوحدات الشاغرة للعموم وطلبات المعاينة، قراءة العدادات والفواتير، المحاسبة الكاملة.

## الأدوار

| الدور | ما يفعله |
|---|---|
| مدير المكتب | كل شيء |
| موظف التأجير | الوحدات والعقود والمستأجرون |
| المحصّل | الاستحقاقات والسندات |
| المحاسب | المصروفات وحسابات الملاك والتقارير |
| فني الصيانة | طلباته |
| المالك | عقاراته وكشف حسابه (قراءة) |
| المستأجر | عقده ودفعاته وطلبات الصيانة |

## نموذج البيانات (مختصر)

`owners`، `properties`، `units`، `unit_features`، `tenants`، `contracts`، `contract_terms`، `dues`، `receipts`، `receipt_allocations`، `deposits`، `maintenance_requests`، `work_orders`، `vendors`، `expenses`، `owner_ledger`، `owner_payouts`، `documents`، `reminders`.

## التقنية

الأساس المشترك، ومعه: مولّد استحقاقات نقي (من شروط العقد إلى جدول دفعات)، ودفتر قيود للملاك، وقوالب عقود وسندات PDF، وتحويل التاريخ الهجري.

## التسعير والبيع (تقديري)

| الباقة | السعر | تشمل |
|---|---|---|
| مالك | 400$ | حتى 100 وحدة، بلا حسابات ملاك متعددين |
| مكتب | 900$ | وحدات وملاك بلا حد، والبوابة |
| مع التطبيق | 1400$ | تطبيق المستأجر والمالك بعلامة المكتب |
| تجديد الدعم | 25% سنوياً | |

## التسويق

- زيارات مباشرة للمكاتب العقارية (متجمعة في شوارع معروفة).
- عرض «انقل Excel مكتبك في يوم»: استيراد مجاني لأول العملاء.
- إعلانات لينكدإن وفيسبوك لمديري الأملاك في الخليج.
- المحاسبون القانونيون الذين يخدمون المكاتب كمسوّقين.

## المخاطر

| الخطر | التعامل معه |
|---|---|
| أنظمة الإيجار تختلف بالبلد (ضريبة، توثيق إلزامي، زيادات) | شروط العقد قابلة للضبط، ووحدة لكل بلد عند الحاجة، ومراجعة قبل كل بلد |
| تعقيد التحصيل الجزئي والمتأخرات | دفتر قيود واضح وتخصيص السند على الاستحقاقات بقاعدة ثابتة |
| نقل بيانات فوضوية من Excel | مستورد بتقرير أخطاء، وخدمة نقل مدفوعة |
