# Sprint 01: الأساس والملاك والعقارات والوحدات

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** المكتب يسجّل ملاكه وعقاراتهم ووحداتها، ويرى الشاغر والمؤجر في نظرة.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | مستودع جديد ونسخ `kit/` | `backend/`، `web/` |
| B2 | الملاك: بياناتهم، حساب التحويل، نسبة أو مبلغ عمولة المكتب، وملكية مشتركة بنسب | `App\Owners` |
| B3 | العقار: نوعه (عمارة، مجمع، فيلا، محلات، أرض)، موقعه على الخريطة، صكه ووثائقه | `App\Properties` |
| B4 | الوحدة: رقمها، دورها، نوعها، مساحتها، غرفها، مرافقها، الإيجار المطلوب، وحالتها (شاغرة، مؤجرة، محجوزة، صيانة) | `Unit` |
| B5 | إنشاء وحدات بالجملة (عمارة 5 أدوار × 4 شقق) | `UnitGenerator` |
| B6 | الوثائق: صور ومخططات وعقود ملكية بتاريخ انتهاء وتنبيه | `Documents` |
| B7 | استيراد العقارات والوحدات من Excel | `App\Import` |
| W1 | الإطار والدخول | `web/src/layouts` |
| W2 | شاشات الملاك والعقارات، وشبكة الوحدات بألوان الحالة | `pages/properties` |
| W3 | خريطة العقارات | `pages/map` |
| D1 | مسودات: شبكة الوحدات، العقد، التحصيل، كشف المالك | `docs/design` |

**تعريف الانتهاء:**
- [ ] عمارة بـ 20 وحدة تُنشأ في أقل من دقيقة.
- [ ] نسب الملكية المشتركة مجموعها 100% وإلا يُرفض الحفظ.
- [ ] موظف مقيّد بعقارات معينة لا يرى غيرها.
- [ ] وثيقة قاربت الانتهاء تظهر في التنبيهات (اختبار بالساعة المحرّكة).

**كيف يُختبر:** سجّل مالكين وثلاث عمارات، وولّد وحداتها، واستورد عقاراً من Excel.
