# Sprint 05: حسابات الملاك والتقارير

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** كشف حساب كل مالك يخرج بضغطة: ما حُصّل له، وما صُرف عنه، وعمولة المكتب، وصافيه.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | دفتر المالك: قيد لكل تحصيل ومصروف وعمولة وتحويل، لا يُعدَّل | `App\Owners\Ledger` |
| B2 | عمولة المكتب: نسبة من المحصَّل (لا المستحق)، أو مبلغ ثابت، أو رسوم تأجير لمرة واحدة عند كل عقد | `ManagementFee` |
| B3 | الملكية المشتركة: توزيع الصافي بنسب الشركاء | `CoOwnership` |
| B4 | التحويل للمالك: كشف الفترة، اعتماد، تسجيل التحويل، وإشعار | `Payout` |
| B5 | كشف الحساب PDF وExcel بتفصيل كل وحدة | `OwnerStatement` |
| B6 | تقارير: الإشغال والشواغر ومدتها، الإيراد المتوقع مقابل المحصَّل، المتأخرات، العقود المنتهية قريباً، ربحية كل عقار، أداء المحصّلين | `App\Reports` |
| B7 | لوحة المدير: مؤشرات اليوم والشهر | `Dashboard` |
| B8 | تقرير شهري تلقائي لكل مالك بالبريد أو واتساب | `OwnerDigest` |
| W1 | لوحة المدير | `pages/dashboard` |
| W2 | حسابات الملاك والتحويلات | `pages/owners/Accounts` |
| W3 | التقارير بفلاتر وتصدير | `pages/reports` |

**تعريف الانتهاء:**
- [ ] صافي المالك يساوي المحصَّل ناقص المصروفات والعمولة، ومجموع الدفتر يطابق السندات والمصروفات (اختبار بعد سنة مولّدة).
- [ ] إلغاء سند بعد تحويله للمالك يظهر قيداً سالباً في الكشف التالي.
- [ ] الشركاء: مجموع أنصبتهم يساوي الصافي بالقرش، والباقي من التقريب لشريك محدد مكتوب.
- [ ] تحويل معتمد لا يُعدَّل.
- [ ] التقارير سريعة على 5000 وحدة.

**كيف يُختبر:** ولّد سنة لمكتب بـ 300 وحدة، أخرج كشف مالك وطابقه يدوياً بعيّنة، واعتمد تحويلاً.
