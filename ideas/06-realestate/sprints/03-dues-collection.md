# Sprint 03: الاستحقاقات والتحصيل والسندات

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 6 أيام عمل |

**الهدف:** المحصّل يعرف كل صباح من عليه وكم، ويحصّل بسند، والمتأخر يُذكَّر وحده.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | الاستحقاق: حالاته (قادم، مستحق، متأخر، مدفوع جزئياً، مدفوع، ملغى)، وتُحدَّث يومياً | `App\Collection\Due` |
| B2 | سند القبض: نقدي، تحويل، شيك (بتاريخ استحقاق وحالة: تحت التحصيل، صُرف، ارتد)، أونلاين. ترقيم متسلسل | `Receipt` |
| B3 | التخصيص: السند يوزَّع على الاستحقاقات الأقدم أولاً، والزائد رصيد مقدّم | `Allocation` |
| B4 | غرامة التأخير: مبلغ أو نسبة بقاعدة يضبطها المكتب (اختيارية) | `LateFee` |
| B5 | التأمين: استلامه كأمانة منفصلة عن الإيراد، والخصم منه، وردّه | `Deposit` |
| B6 | التذكير: قبل الاستحقاق ويومه وبعده بواتساب أو SMS مع رابط دفع | `App\Reminders` |
| B7 | الدفع أونلاين من الرابط، والسند يصدر تلقائياً | `PayLink` |
| B8 | إلغاء السند بصلاحية: قيد عكسي لا حذف، والشيك المرتد يعيد الاستحقاق | `ReceiptReversal` |
| B9 | كشف حساب المستأجر، وخطاب مطالبة وإنذار PDF | `TenantStatement` |
| W1 | شاشة التحصيل: المستحق اليوم والمتأخر، بفلاتر العقار والمحصّل، وتحصيل سريع | `pages/collection` |
| W2 | السند وطباعته (A5 وحراري)، وإرساله بواتساب | `pages/receipts` |
| W3 | متابعة الشيكات، وأعمار الديون (30، 60، 90 يوماً) | `pages/collection/Aging` |

**تعريف الانتهاء:**
- [ ] رصيد كل مستأجر يساوي استحقاقاته ناقص سنداته (اختبار بعد ألف حركة مولّدة).
- [ ] دفع جزئي ثم باقٍ ثم زيادة: التخصيص صحيح في الحالات الثلاث (Unit).
- [ ] التأمين لا يدخل في إيراد المالك.
- [ ] شيك ارتد يعيد الاستحقاق متأخراً من تاريخه الأصلي.
- [ ] التذكير لا يُرسل لمن دفع، ولا يتكرر.
- [ ] الدفع أونلاين المكرر يصدر سنداً واحداً.

**كيف يُختبر:** حرّك الساعة شهرين على عشرة عقود، حصّل بعضها كاملاً وجزئياً وبشيك، ورُدَّ شيكاً، وراجع أعمار الديون.
