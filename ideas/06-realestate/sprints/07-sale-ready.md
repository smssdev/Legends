# Sprint 07: التجهيز للبيع

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** مكتب عقاري ينقل ملفاته من Excel ويعمل على النظام في يومين.

| الرمز | المهمة | الملفات |
|---|---|---|
| S1 | المستورد الكامل: ملاك، عقارات، وحدات، مستأجرون، عقود سارية بأرصدتها الافتتاحية، بقوالب Excel وتقرير أخطاء وتجربة قبل الاعتماد | `App\Import` |
| S2 | الأرصدة الافتتاحية: متأخرات المستأجرين وأرصدة الملاك عند تاريخ البدء | `OpeningBalances` |
| S3 | معالج البدء: بيانات المكتب، العمولة الافتراضية، قوالب العقد والسند، التذكيرات | `pages/onboarding` |
| S4 | ربط خادم التراخيص، والمثبّت والتحديث | `kit/License`، `deploy/` |
| S5 | الموقع التجريبي بمكتب وهمي (300 وحدة) وحسابات لكل دور | `DemoSeeder` |
| S6 | فحص الأمان واختبار الحمل (10 آلاف وحدة، تشغيل الاستحقاقات اليومي) | `tests/` |
| S7 | الوثائق: دليل كل دور، دليل النقل من Excel، التركيب | `docs/` |
| S8 | صفحة الهبوط والأسعار والفيديو، وعرض خدمة النقل | `site/` |
| S9 | عقد الترخيص وسياسة الخصوصية (مسودات) | `docs/legal` |

**تعريف الانتهاء:**
- [ ] ملف Excel حقيقي من مكتب (بأخطائه) يُستورد بعد تصحيح ما يذكره التقرير، والأرصدة تطابق ما عند المكتب.
- [ ] الاستيراد التجريبي لا يكتب شيئاً، والاعتماد يكتب كله أو لا شيء.
- [ ] مكتب حقيقي واحد يعمل عليه شهراً (دورة تحصيل كاملة وكشف مالك)، وملاحظاته مغلقة.
- [ ] الموقع التجريبي وصفحة الهبوط على الدومين.

**كيف يُختبر:** خذ ملفات مكتب حقيقي (بإذنه)، استوردها، وطابق كشف مالكين مع ما عنده.
