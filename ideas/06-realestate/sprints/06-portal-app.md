# Sprint 06: بوابة وتطبيق المستأجر والمالك

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** المستأجر يدفع ويبلّغ من جواله، والمالك يتابع أملاكه بلا اتصال بالمكتب.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | API البوابة: دخول بالجوال وOTP، ودور يحدد ما يظهر | `/portal/v1` |
| B2 | المستأجر: عقده، دفعاته القادمة والسابقة، الدفع أونلاين، سنداته PDF، طلب صيانة ومتابعته، طلب تجديد أو إخلاء | `TenantPortal` |
| B3 | المالك: عقاراته ووحداته وحالتها، كشف حسابه، تحويلاته، موافقات الصيانة، وثائقه | `OwnerPortal` |
| B4 | الإشعارات: استحقاق قادم، سند صدر، حالة الصيانة، تحويل تم | `kit/Notify` |
| W1 | البوابة ويب (PWA) للطرفين | `portal/` |
| M1 | تطبيق Flutter واحد بالدورين مع `kit_mobile` وبناء العلامة | `mobile/` |
| M2 | شاشات المستأجر: الرئيسية (المستحق الآن)، الدفع، السندات، الصيانة بالكاميرا | `features/tenant` |
| M3 | شاشات المالك: ملخص، العقارات، الكشف، الموافقات | `features/owner` |

**تعريف الانتهاء:**
- [ ] المستأجر لا يرى إلا عقده، والمالك لا يرى إلا عقاراته، ولا يرى أحدهما بيانات الآخر الشخصية (اختبار على كل مسار).
- [ ] الدفع من التطبيق يصدر السند ويظهر عند المحصّل فوراً.
- [ ] من له دوران (مالك ومستأجر) يبدّل بينهما.
- [ ] RTL والإنجليزية وشاشة 360px.
- [ ] علامتان مختلفتان تُبنيان بلا تعديل يدوي.

**كيف يُختبر:** ادخل مستأجراً وادفع استحقاقاً وبلّغ عن عطل، ثم ادخل مالكاً ووافق على الصيانة وراجع الكشف.
