# Sprint 02: المستأجرون والعقود

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 6 أيام عمل |

**الهدف:** عقد إيجار يُكتب في دقائق بكل شروطه، ويُطبع، ويولّد جدول دفعاته، ويُجدَّد أو يُنهى بقواعد واضحة.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | المستأجر: فرد أو شركة، الهوية، الجوال، الكفيل، وثائق، وقائمة سوداء | `App\Tenants` |
| B2 | العقد: الوحدة، المدة، الإيجار، دورية الدفع (شهري، ربع، نصف، سنوي)، يوم الاستحقاق، التأمين، الخدمات والرسوم الإضافية، الضريبة | `App\Contracts\Contract` |
| B3 | مولّد الاستحقاقات النقي: من الشروط إلى جدول دفعات، بهجري أو ميلادي، وفترة سماح، وزيادة سنوية | `DueSchedule` |
| B4 | حالات العقد: مسودة، ساري، منتهٍ، مُنهى مبكراً، مجدد، ومنع عقدين ساريين لوحدة بتحديث شرطي | `ContractState` |
| B5 | التجديد: بنفس الشروط أو بزيادة، وتنبيه قبل الانتهاء بمدد | `Renewal` |
| B6 | الإنهاء المبكر: تسوية (ما عليه، ما له، خصومات التأمين)، ومحضر استلام الوحدة بصور | `Termination`، `Handover` |
| B7 | قوالب العقد PDF بمتغيرات يعدّلها المكتب، وتوقيع بالرسم على الشاشة | `ContractTemplate` |
| B8 | حجز وحدة بعربون قبل العقد | `Reservation` |
| W1 | معالج العقد بخطوات، ومعاينة جدول الدفعات قبل الحفظ | `pages/contracts/Wizard` |
| W2 | صفحة العقد: الشروط، الدفعات، الوثائق، السجل | `pages/contracts/Show` |
| W3 | قائمة «تنتهي قريباً» وتجديد بضغطة | `pages/contracts/Expiring` |

**تعريف الانتهاء:**
- [ ] Unit للمولّد: كل دورية، عقد يبدأ منتصف الشهر، سنة كبيسة، هجري، زيادة سنوية، ومجموع الدفعات يساوي قيمة العقد بالقرش.
- [ ] عقدان لنفس الوحدة في فترة متداخلة: الثاني يُرفض (اختبار تزامن).
- [ ] العقد العربي PDF سليم، والتوقيع محفوظ معه.
- [ ] الإنهاء المبكر يلغي الاستحقاقات القادمة ويُبقي ما مضى، والتسوية تُظهر الصافي.
- [ ] الوحدة تتغير حالتها تلقائياً مع العقد.

**كيف يُختبر:** اكتب عقداً سنوياً ربع سنوي بتأمين، اطبعه، جدّده بزيادة 5%، ثم أنهِ عقداً آخر مبكراً وراجع التسوية.
