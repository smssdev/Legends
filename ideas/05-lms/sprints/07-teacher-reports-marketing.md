# Sprint 07: لوحة المدرس والتقارير والتسويق

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** المدرس يرى دخله وطلابه ومستواهم، ويملك أدوات تجلب له طلاباً.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | المالية: المبيعات بالمنتج والطريقة واليوم، الأكواد المباعة والمستعملة، الاشتراكات السارية والمنتهية | `App\Reports\Sales` |
| B2 | التعلم: مشاهدة كل درس (أين يتوقف الطلاب)، نسب الإتمام، درجات كل اختبار، الطلاب المتأخرون | `App\Reports\Learning` |
| B3 | ملف الطالب الكامل: مشترياته، مشاهداته، درجاته، أجهزته، إشارات المشاركة | `StudentProfile` |
| B4 | مدرسون متعددون (باقة الأكاديمية): كل مدرس دوراته وتقاريره، ونسبة للأكاديمية | `MultiTeacher` |
| B5 | المسوّقون: رابط وكود لكل مسوّق، وعمولة، وكشف حساب | `Affiliates` |
| B6 | صفحات تسويق: صفحة هبوط لكل دورة قابلة للتعديل، وSEO، وبيكسل فيسبوك وتيك توك بمفاتيح المشتري | `Marketing` |
| B7 | حملات: عربة متروكة، اشتراك سينتهي، دورة جديدة | `Campaigns` |
| B8 | لوحة الشرف والترتيب (اختياري) | `Leaderboard` |
| W1 | لوحة المدرس: اليوم والشهر، وتنبيهات (أسئلة بلا رد، واجبات بلا تصحيح) | `pages/teacher/Dashboard` |
| W2 | التقارير بفلاتر وتصدير | `pages/teacher/Reports` |
| W3 | المسوّقون والحملات ومحرر صفحة الدورة | `pages/teacher/Marketing` |

**تعريف الانتهاء:**
- [ ] أرقام المالية تطابق مجموع الحركات بالقرش.
- [ ] مدرس في أكاديمية لا يرى طلاب ولا دخل مدرس آخر (اختبار على كل مسار).
- [ ] عمولة المسوّق تُحسب مرة لكل بيع، وتُلغى عند الاسترجاع.
- [ ] منحنى المشاهدة يُظهر الدقيقة التي يغادر عندها الطلاب.
- [ ] التقارير سريعة على 20 ألف طالب (بيانات مولّدة).

**كيف يُختبر:** ولّد بيانات فصل دراسي، راجع اللوحة، أنشئ مسوّقاً، واشترِ من رابطه.
