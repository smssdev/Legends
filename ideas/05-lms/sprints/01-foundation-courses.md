# Sprint 01: الأساس والدورات والمنهج

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** المدرس يبني دورته: أبواب ودروس ومرفقات، بترتيبها وشروط فتحها.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | مستودع جديد ونسخ `kit/` | `backend/`، `web/` |
| B2 | التصنيفات: مرحلة، صف، مادة (شجرة يعرّفها المشتري) | `App\Catalog\Category` |
| B3 | الدورة: عنوان، وصف، غلاف، فيديو تعريفي، مدرس، حالة (مسودة، منشورة، مؤرشفة) | `App\Courses\Course` |
| B4 | المنهج: أبواب ودروس مرتبة، وأنواع الدرس (فيديو، ملف، نص، اختبار، واجب، رابط) | `Section`، `Lesson` |
| B5 | قواعد الفتح: بالترتيب، بتاريخ (جدولة أسبوعية)، بعد اجتياز اختبار، ودرس مجاني للمعاينة | `UnlockRule` |
| B6 | المرفقات: PDF ومذكرات بتنزيل مسموح أو عرض فقط بعلامة مائية | `Attachment` |
| B7 | نسخ دورة كاملة (لسنة جديدة أو مجموعة أخرى) | `CourseClone` |
| B8 | المجموعات: طلاب السنتر، أونلاين، مجموعة السبت | `Group` |
| W1 | الإطار: لوحة المدرس وواجهة الطالب بهوية واحدة | `web/src/layouts` |
| W2 | محرر المنهج: سحب للترتيب، وإضافة درس في نافذة | `pages/teacher/Builder` |
| W3 | صفحة الدورة العامة وصفحة المتجر | `pages/public` |
| D1 | مسودات: المتجر، صفحة الدورة، المشغل، لوحة المدرس | `docs/design` |

**تعريف الانتهاء:**
- [ ] دورة بثلاثة أبواب و20 درساً تُبنى وتُرتَّب بالسحب.
- [ ] درس مجدول لا يفتح قبل تاريخه، ودرس مشروط لا يفتح قبل اجتياز سابقه (Unit).
- [ ] نسخ الدورة ينسخ كل شيء إلا الطلاب وتقدمهم.
- [ ] الزائر يرى الدرس المجاني فقط، والباقي مقفل من الخادم لا من الواجهة.

**كيف يُختبر:** ابنِ دورة فيزياء بجدولة أسبوعية، وافتحها زائراً وطالباً غير مسجل.
