# Sprint 03: التسجيل والدفع والأكواد والاشتراكات

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 6 أيام عمل |

**الهدف:** الطالب يشتري بأي طريقة يعرفها: بطاقة، محفظة، أو كود اشتراه من السنتر.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | حساب الطالب: الجوال، رقم ولي الأمر، الصف، والتحقق بـ OTP | `App\Students` |
| B2 | ما يُباع: دورة كاملة، باب، درس واحد (حصة)، أو اشتراك شهري في مادة أو في كل شيء | `App\Sales\Product` |
| B3 | التسجيل: صلاحية وصول بمدة، وتمديد، وإيقاف، ومنح مجاني من المدرس | `Enrollment` |
| B4 | الدفع أونلاين عبر `kit/Payments`، ومحافظ الجوال والدفع عند منافذ (حسب البلد) | `Checkout` |
| B5 | الأكواد: توليد دفعات بقيمة (رصيد محفظة) أو لمنتج محدد، وتصدير للطباعة، واستعمال مرة واحدة | `App\Codes` |
| B6 | محفظة الطالب: شحن بكود أو بطاقة، وشراء منها. الرصيد مجموع الحركات | `Wallet` |
| B7 | الاشتراكات: تجديد يدوي أو تلقائي، وفترة سماح، وانتهاء يقفل المحتوى | `Subscription` |
| B8 | الكوبونات والخصومات وسعر خاص لمجموعة | `Coupon` |
| B9 | حماية الأكواد: حد محاولات، وقفل مؤقت، وسجل من ولّد ومن استعمل | `CodeGuard` |
| W1 | صفحة الشراء والسلة وشحن المحفظة | `pages/student/Checkout` |
| W2 | إدارة الأكواد: الدفعات وحالتها والبحث عن كود | `pages/teacher/Codes` |
| W3 | إدارة الطلاب والتسجيلات والمنح | `pages/teacher/Students` |

**تعريف الانتهاء:**
- [ ] كود يُدخله طالبان في لحظة واحدة: واحد ينجح (اختبار تزامن).
- [ ] خمس محاولات خاطئة تقفل الإدخال مؤقتاً.
- [ ] الدفع المكرر بنفس `idempotency_key` يسجّل مرة.
- [ ] انتهاء الاشتراك يقفل الدروس من الخادم، وتجديده يعيدها بتقدمها.
- [ ] الأكواد تُخزَّن مجزّأة (hash)، ولا تُعرض كاملة بعد التصدير.

**كيف يُختبر:** ولّد 100 كود، اشحن بواحد، اشترِ حصة من المحفظة، ثم اشترك شهرياً بالبطاقة التجريبية وحرّك الساعة شهراً.
