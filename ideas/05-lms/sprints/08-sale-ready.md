# Sprint 08: التجهيز للبيع

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** مدرس يشتري ويرفع أول دورة في يوم، وتتحمل منصته ليلة الامتحان.

| الرمز | المهمة | الملفات |
|---|---|---|
| S1 | المثبّت مع خدمة التحويل (FFmpeg) وتخزين محلي أو S3، ودليل ربط CDN | `deploy/` |
| S2 | حاسبة كلفة: عدد الطلاب وساعات الفيديو تعطي مساحة وحركة السيرفر المطلوبة | `site/calculator` |
| S3 | ربط خادم التراخيص، والتحديث والتراجع | `kit/License` |
| S4 | معالج البدء: الهوية، أول دورة، أول فيديو، طريقة الدفع، أول دفعة أكواد | `pages/onboarding` |
| S5 | الموقع التجريبي بحساب مدرس وطالب، وتطبيق تجريبي | `DemoSeeder` |
| S6 | اختبار الذروة: 3000 مشاهد معاً (الفيديو من CDN أو ملفات ثابتة) و500 في اختبار واحد | `tests/Load` |
| S7 | فحص الأمان: الوصول للفيديو والمفاتيح والإجابات، والصلاحيات | `tests/Security` |
| S8 | استيراد الطلاب من Excel، ونقل المحتوى من منصة سابقة (روابط الفيديو) | `App\Import` |
| S9 | الوثائق: التركيب، دليل المدرس، دليل الدعم، نشر التطبيق، وصفحة «حدود الحماية» | `docs/` |
| S10 | صفحة الهبوط والأسعار والفيديو، وعقد الترخيص (مسودة) | `site/`، `docs/legal` |

**تعريف الانتهاء:**
- [ ] من التركيب إلى طالب يشاهد أول درس مدفوع في أقل من ساعتين.
- [ ] اختبار الذروة يمر على سيرفر بالمواصفات المكتوبة في الوثائق.
- [ ] لا طريق للفيديو أو الإجابات بلا صلاحية.
- [ ] مدرس حقيقي واحد يعمل عليها شهراً بطلابه، وملاحظاته مغلقة.

**كيف يُختبر:** سلّم نسخة لمدرس حقيقي بمجموعة صغيرة، وتابع أول أسبوع.
