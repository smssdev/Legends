# Sprint 02: الفيديو المحمي

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل |

**الهدف:** المدرس يرفع الفيديو فيصير بثاً متكيفاً مشفّراً، لا يُنزَّل برابط ولا يُشاهَد بلا صلاحية.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | الرفع المتقطع القابل للاستكمال (ملفات بالجيجابايت) مباشرة إلى التخزين | `App\Video\Upload` (tus أو S3 multipart) |
| B2 | التحويل في الطابور: FFmpeg إلى HLS بجودات (360، 480، 720، 1080)، وصورة مصغرة، ومدة | `TranscodeJob` |
| B3 | التشفير: AES-128 لكل فيديو، والمفتاح لا يُخزَّن بجانب الملفات | `VideoKey` |
| B4 | جلسة المشاهدة: رمز قصير العمر مربوط بالطالب والجهاز والدرس، ومنه تُوقَّع قائمة التشغيل ورابط المفتاح | `WatchSession` |
| B5 | الأجهزة: حد لكل طالب (مثلاً 2)، تسجيل الجهاز، وطلب تغيير بموافقة الدعم | `Device` |
| B6 | المشاهدة المتزامنة: جلسة واحدة نشطة للحساب | `ConcurrentGuard` |
| B7 | حد مرات المشاهدة لكل درس (اختياري) وعدّ بالوقت المشاهَد فعلاً | `WatchLimit` |
| B8 | كشف المشاركة: حساب من مدن أو أجهزة كثيرة يُعلَّم للمراجعة | `SharingSignals` |
| B9 | مصادر بديلة: رابط يوتيوب غير مدرج أو Vimeo أو Bunny لمن يريد (مع توضيح أن حمايتها أقل أو عند مزوّدها) | `VideoSource` |
| W1 | المشغل: hls.js، الجودة والسرعة، استكمال من آخر نقطة، اختصارات | `components/Player` |
| W2 | العلامة المائية: اسم الطالب ورقمه يتحركان عشوائياً فوق الفيديو، ومراقبة حذفها من الصفحة | `components/Watermark` |
| W3 | شاشة الرفع وتقدم التحويل، وإدارة أجهزة الطلاب | `pages/teacher/Videos` |

**تعريف الانتهاء:**
- [ ] رابط القائمة أو المفتاح المنسوخ لا يعمل من متصفح آخر ولا بعد دقائق.
- [ ] فيديو ساعة يُحوَّل ويُشاهَد، وانقطاع الرفع يُستكمل من حيث وقف.
- [ ] طالب بجهاز ثالث يُرفض برسالة واضحة.
- [ ] فتح الحساب من جهازين معاً يوقف الأول.
- [ ] المفتاح لا يظهر في أي استجابة لغير صاحب جلسة سارية (اختبار).
- [ ] الوثائق تقول بصدق ما تمنعه الحماية وما لا تمنعه.

**كيف يُختبر:** ارفع فيديو، شاهده، ثم حاول تنزيله بأداة تنزيل شائعة وبنسخ الروابط من أدوات المطور.
