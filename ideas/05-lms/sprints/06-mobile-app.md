# Sprint 06: التطبيق والمشاهدة بلا إنترنت

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل |

**الهدف:** تطبيق باسم المدرس: الطالب يشاهد فيه بأمان، وينزّل الدرس ليشاهده بلا إنترنت داخل التطبيق فقط.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | API التطبيق، وتسجيل الجهاز بمعرّف ثابت، وترخيص التنزيل (مدة صلاحية وعدد) | `/app/v1`، `OfflineLicense` |
| M1 | مشروع Flutter مع `kit_mobile`، وبناء العلامة | `mobile/` |
| M2 | المتجر، الدورة، الشراء (كود، محفظة، بوابة) | `features/store` |
| M3 | المشغل: HLS مشفّر، جودة وسرعة، استكمال، وعلامة مائية متحركة | `features/player` |
| M4 | منع تصوير الشاشة وتسجيلها (`FLAG_SECURE` على أندرويد، وكشف التسجيل على iOS وإيقاف الفيديو) | `core/secure` |
| M5 | التنزيل: المقاطع مشفّرة في تخزين التطبيق، والمفتاح في المخزن الآمن، وصلاحية تنتهي وتُجدَّد عند الاتصال | `features/downloads` |
| M6 | رفض الأجهزة المكسورة الحماية والمحاكيات (اختياري للمشتري) | `core/integrity` |
| M7 | الاختبارات والواجبات (رفع بالكاميرا) والأسئلة والإشعارات | `features/learn` |
| M8 | مزامنة التقدم المسجَّل بلا إنترنت عند العودة | `core/sync` |

**تعريف الانتهاء:**
- [ ] تصوير الشاشة يعطي أسود على أندرويد، والتسجيل يوقف الفيديو على iOS.
- [ ] الملفات المنزّلة لا تُشغَّل خارج التطبيق ولا على جهاز آخر.
- [ ] درس منزّل انتهت صلاحيته لا يعمل حتى يتصل ويجدد.
- [ ] تقدم مشاهدة بلا إنترنت يصل للخادم عند العودة.
- [ ] الشراء داخل التطبيق يتبع سياسات المتاجر (تُقرأ السياسة الحالية قبل البناء: المحتوى الرقمي على iOS قد يُلزم بنظام شراء Apple).

**كيف يُختبر:** نزّل درساً، افصل الإنترنت وشاهده، انسخ ملفاته لجهاز آخر وحاول تشغيلها، وصوّر الشاشة.

**تنبيه:** سياسة Apple للمحتوى الرقمي قد تفرض عمولة أو تمنع الشراء داخل التطبيق: يُوثَّق للمشتري، والبديل الشراء من الويب.
