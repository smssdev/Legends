# Sprint 05: تجربة الطالب والتقدم والشهادات

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** الطالب يدخل فيعرف أين وصل وما عليه، ويسأل فيُجاب، وينهي فيأخذ شهادته.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | التقدم: نسبة مشاهدة كل درس من الوقت الفعلي، وإتمام الدرس بقاعدة (90% أو اجتياز) | `App\Progress` |
| B2 | «أكمل من حيث توقفت» و«المطلوب منك هذا الأسبوع» | `StudentHome` |
| B3 | أسئلة الدرس: الطالب يسأل عند دقيقة معينة، والمدرس أو المساعد يجيب نصاً أو صوتاً أو صورة | `App\QnA` |
| B4 | ملاحظات الطالب الخاصة على الدرس بتوقيتها | `Notes` |
| B5 | الإعلانات من المدرس لدورة أو مجموعة، مع إشعار | `Announcements` |
| B6 | الشهادة: قالب يصممه المشتري، PDF باسم الطالب ورمز تحقق وصفحة تحقق عامة | `Certificates` |
| B7 | تقرير ولي الأمر: أسبوعي بواتساب أو رابط (المشاهدة، الدرجات، الغياب) | `ParentReport` |
| B8 | حضور السنتر: مسح QR الطالب، وربط الحضور بفتح الحصة أونلاين لمن غاب | `CenterAttendance` |
| W1 | رئيسية الطالب، وصفحة الدرس (المشغل، المرفقات، الأسئلة، الملاحظات، قائمة الدروس) | `pages/student` |
| W2 | صندوق الأسئلة للمدرس والمساعدين | `pages/teacher/Inbox` |
| W3 | مصمم الشهادة، وصفحة التحقق | `pages/teacher/Certificates` |
| W4 | بطاقة الطالب بـ QR، وشاشة مسح الحضور بكاميرا الجوال | `pages/center` |

**تعريف الانتهاء:**
- [ ] ترك الفيديو مفتوحاً بلا مشاهدة (تبويب مخفي) لا يحسب تقدماً كاملاً.
- [ ] الاستكمال يعمل بين الويب والتطبيق.
- [ ] الشهادة العربية PDF سليمة، ورمزها يتحقق في الصفحة العامة.
- [ ] تقرير ولي الأمر لا يحوي رابطاً يدخل حساب الطالب.
- [ ] المساعد يجيب الأسئلة ولا يرى المالية.

**كيف يُختبر:** أكمل دورة قصيرة بحساب طالب، اسأل عند دقيقة، أجب من حساب مساعد، وحمّل الشهادة وتحقق منها.
