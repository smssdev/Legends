# منصة دورات بعلامة المشتري (LMS)

## الفكرة

منصة يبيع منها المدرس أو الأكاديمية دوراته المسجلة باسمه: فيديو محمي من التنزيل والمشاركة، واختبارات وواجبات، واشتراكات وأكواد شحن، وتطبيق بمشاهدة بلا إنترنت.

**علاقتها بالمشروع 7 (التعلم الذكي):** هذه منصة **بيع المحتوى المسجل** (أبسط وأرخص). والمشروع 7 يُبنى فوق نواتها ويضيف الفصل المباشر والتكيّف والذكاء الاصطناعي، ويُباع للمدارس والأكاديميات الأكبر.

## المشتري

- مدرسو الثانوية والجامعة (سوق كبير في مصر والخليج والعراق).
- مراكز التدريب والأكاديميات الصغيرة.
- مدربون وصنّاع محتوى يبيعون دوراتهم.
- خارج النطاق: الجامعات والمدارس النظامية (المشروع 7).

## ما يميزنا

- حماية الفيديو: هم المدرس الأول. بث مشفّر، وعلامة مائية متحركة برقم الطالب، وحد أجهزة، ومنع التصوير في التطبيق.
- أكواد الشحن والسنتر: الدفع الأكثر استعمالاً عند المدرسين (كروت تُباع نقداً).
- حضور السنتر وربطه بالمشاهدة أونلاين.
- المدرس يملك منصته وطلابه، لا عمولة لمنصة وسيطة.

## النطاق

**v1:** الدورات والمنهج، الفيديو المحمي، التسجيل والدفع وأكواد الشحن والاشتراكات، الاختبارات والواجبات، مشغل الطالب والتقدم والشهادات، التطبيق، لوحة المدرس والتقارير، ولي الأمر (تقرير)، الكوبونات والمسوّقون.

**بعد v1:** البث المباشر (يأتي من المشروع 7)، المنتدى، متجر الكتب والمذكرات، مدرسون متعددون بعمولة (Marketplace).

## الأدوار

| الدور | ما يفعله |
|---|---|
| المالك (المدرس) | كل شيء |
| مساعد | المحتوى، تصحيح الواجبات، الرد على الأسئلة |
| دعم | الطلاب والأكواد والأجهزة |
| الطالب | يشاهد ويحل ويسأل |
| ولي الأمر | تقرير ابنه برابط أو رسالة |

## نموذج البيانات (مختصر)

`courses`، `sections`، `lessons`، `videos`، `video_renditions`، `attachments`، `enrollments`، `plans`، `subscriptions`، `codes`، `code_batches`، `orders`، `payments`، `wallet_moves`، `quizzes`، `questions`، `attempts`، `answers`، `assignments`، `submissions`، `progress`، `watch_sessions`، `devices`، `certificates`، `affiliates`.

## التقنية

الأساس المشترك، ومعه: FFmpeg لتحويل الفيديو إلى HLS بجودات متعددة وتشفير AES-128 بمفاتيح قصيرة العمر، وتخزين متوافق مع S3 (على سيرفر المشتري أو تخزينه السحابي)، وCDN اختياري. و**DRM الحقيقي (Widevine وFairPlay) خدمات مدفوعة،** فتُترك خياراً يربطه المشتري بمزوّده.

## التسعير والبيع (تقديري)

| الباقة | السعر | تشمل |
|---|---|---|
| مدرس | 500$ | النسخة والويب |
| أكاديمية | 1200$ | مدرسون متعددون، والتطبيق بعلامته |
| مستضافة عندنا | شهري بحسب التخزين والمشاهدة | لمن لا يريد سيرفراً |
| تجديد الدعم | 25% سنوياً | |

## التسويق

- المدرسون يقلدون بعضهم: أول مدرس معروف في كل مادة يجلب غيره. نسخة مخفضة لأول 5 مقابل ذكر اسمنا.
- مجموعات المدرسين، وشركات تصوير الدروس والمونتاج كمسوّقين بعمولة.
- فيديو مقارنة: «منصتك أم منصة تأخذ نسبة من كل طالب».

## المخاطر

| الخطر | التعامل معه |
|---|---|
| لا حماية كاملة للفيديو (تصوير الشاشة بكاميرا) | نقول ذلك بصدق، ونردع بالعلامة المائية باسم الطالب وكشف المشاركة وإيقاف الحساب |
| كلفة البث والتخزين عند كثرة الطلاب | على المشتري (سيرفره أو تخزينه)، وحاسبة كلفة في الوثائق |
| ضغط الذروة قبل الامتحانات | الفيديو ملفات ثابتة خلف CDN، والخادم للصلاحيات فقط |
| سرقة الأكواد | كود لمرة واحدة، وحد محاولات، وسجل لكل دفعة ومن باعها |
