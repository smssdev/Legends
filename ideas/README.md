## ترتيب التنفيذ المقترح

1. **الحجوزات (4):** الأصغر، وفيه يُبنى الأساس المشترك كله ويُجرَّب البيع.
2. **العيادات (1):** يعيد استعمال محرك المواعيد من (4).
3. **العقارات (6):** نطاق محدد ومشترٍ يدفع.
4. **منصة الدورات (5)،** ثم **التعلم الذكي (7)** فوقها (نواة واحدة).
5. **المطاعم (2).**
6. **التوصيل (3):** الأكبر، وأعلى سعر للنسخة.

لا يبدأ مشروع إلا بطلب صاحب المشروع، ومشروع واحد في كل مرة حتى يصير جاهزاً للبيع.

## الأساس المشترك (Kit)

يُبنى مرة في أول مشروع داخل حزمة `kit/`، وكل مشروع بعده ينسخها في Sprint 01.

**التقنية:** Laravel 12 وPHP 8.4، PostgreSQL، Redis (كاش وطابور)، Vue 3 وTypeScript وTailwind، Flutter للتطبيقات، Docker Compose للتركيب، Reverb للبث الحي حيث يلزم. كلها مجانية ومفتوحة.

| الوحدة | ما تفعله |
|---|---|
| الحسابات والأدوار | دخول بالبريد أو الجوال (OTP)، أدوار وصلاحيات بالوحدة، سجل دخول، خطوتان اختيارياً |
| الهوية (White-label) | الاسم والشعار والألوان والخطوط والدومين من لوحة الإعدادات، بلا تعديل كود |
| اللغتان | عربي وإنجليزي، RTL كامل، وتاريخ هجري وميلادي، وعملة وضريبة لكل بلد |
| الدفع | واجهة واحدة `PaymentGateway` ومزوّدات: Paymob، Moyasar، Tap، Stripe، ونقدي. كل عملية بـ `idempotency_key` وسجل لا يُعدَّل |
| الإشعارات | بريد، وواتساب (Cloud API بحساب المشتري)، وSMS بمزوّد قابل للتبديل، وFCM، وقوالب يعدّلها المشتري |
| الترخيص | مفتاح لكل نسخة مربوط بالدومين، موقّع Ed25519، يُفحص عند التركيب ومرة يومياً مع مهلة سماح 14 يوماً بلا إنترنت. خادم التراخيص عندنا (تطبيق Laravel صغير) |
| المثبّت والتحديث | معالج تركيب في المتصفح (قاعدة، مدير، ترخيص)، و`docker compose up` بديلاً، وأمر تحديث يأخذ نسخة احتياطية أولاً |
| السلامة | سجل تدقيق لكل تعديل، نسخ احتياطي يومي مشفّر، ترويسات أمان، حدّ معدل، تصدير البيانات |
| العرض التجريبي | وضع Demo ببيانات وهمية يُعاد كل ساعة، لصفحة البيع |

**قواعد ثابتة لكل المشاريع:**

- المال أرقام صحيحة (بأصغر وحدة)، والرصيد مجموع الحركات.
- كل قاعدة عمل في الـ API، والواجهات ترسم فقط.
- اختبار Feature لكل مسار وUnit لكل منطق نقي.
- الترحيلات تضيف فقط بعد أول نسخة مباعة.
- العقد في `docs/api/openapi.yaml` يُحدَّث مع كل مسار.
- لا شاشة قبل تصميمها، والجوال أولاً، واللمس 44px.

## نموذج البيع المشترك

- **نسخة مرخّصة** على سيرفر المشتري (دومين واحد)، وتحديثات ودعم سنة، ثم تجديد سنوي اختياري (20 إلى 30% من السعر).
- **تركيب وتخصيص مدفوعان** (خدمة إضافية).
- **نسخة مستضافة عندنا** باشتراك شهري لمن لا يريد سيرفراً (تُضاف بعد أول 10 مبيعات).
- **«جاهز للبيع» يعني:** موقع تجريبي حي، وصفحة هبوط بالسعر، وفيديو دقيقتين، ودليل تركيب، ودليل مستخدم، ومثبّت مجرَّب على سيرفر نظيف، وخادم تراخيص يعمل.

## ينتظر قرار صاحب المشروع

1. بأي مشروع نبدأ (المقترح: الحجوزات).
2. اسم تجاري ودومين لكل منتج، أو علامة واحدة تجمعها.
3. البلد الأول للبيع (يحدد بوابة الدفع والضريبة والفاتورة الإلكترونية).
4. البيع المباشر وحده، أم أسواق السكربتات أيضاً (CodeCanyon يفرض شروطه وعمولته).
