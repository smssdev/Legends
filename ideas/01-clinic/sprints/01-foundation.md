# Sprint 01: الأساس والترخيص والفروع والأطباء

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** مستودع يعمل بالأساس المشترك، ومدير يدخل ويعرّف عيادته وفروعها وأطباءها ومواعيد عملهم.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | مستودع جديد بـ Laravel وVue وDocker Compose، ونسخ `kit/` (الحسابات، الأدوار، الهوية، اللغتان، سجل التدقيق) | `backend/`، `web/`، `deploy/` |
| B2 | الترخيص: فحص المفتاح عند التركيب ويومياً، ومهلة السماح | `kit/License` |
| B3 | الفروع: الاسم، العنوان، المنطقة الزمنية، أيام العمل والإجازات | `App\Clinic\Branch` |
| B4 | الأطباء: التخصص، مدة الكشف، سعر الكشف والاستشارة، وجدول أسبوعي لكل فرع مع استثناءات | `App\Clinic\Doctor`، `Schedule` |
| B5 | الأدوار الخمسة وصلاحياتها، وبذرة بيانات تجريبية | `database/seeders` |
| W1 | الإطار: رصيف جانبي وشريط علوي، ودخول، وتبديل اللغة والفرع | `web/src/layouts` |
| W2 | شاشات الإعدادات: الهوية، الفروع، الأطباء وجداولهم | `web/src/pages/settings` |
| D1 | مسودات الشاشات الرئيسية ونظام الألوان (`tokens.json`) قبل الواجهة | `docs/design` |

**تعريف الانتهاء:**
- [ ] `docker compose up` على جهاز نظيف يفتح معالج التركيب ثم لوحة المدير.
- [ ] تغيير الشعار واللون والاسم من الإعدادات يظهر فوراً بلا بناء.
- [ ] مفتاح خاطئ أو دومين مختلف يرفض التركيب برسالة عربية واضحة.
- [ ] جدول طبيب بفترتين في اليوم وإجازة يُحفظ ويُعرض صحيحاً.
- [ ] اختبار Feature لكل مسار، وUnit لحساب فترات الجدول.

**كيف يُختبر:** ركّب النسخة، أنشئ فرعين وثلاثة أطباء، ادخل بحساب استقبال وتأكد أنه لا يرى الإعدادات المالية.
