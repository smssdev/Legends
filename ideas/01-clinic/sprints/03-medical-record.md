# Sprint 03: الكشف والملف الطبي والوصفة

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل |

**الهدف:** الطبيب يكتب الكشف كاملاً في شاشة واحدة، ويطبع وصفة باسم العيادة، وكل تاريخ المريض أمامه.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | الزيارة: الشكوى، الفحص، العلامات الحيوية، التشخيص (نص حر وICD-10 اختيارياً)، الخطة، موعد المتابعة | `App\Medical\Visit` |
| B2 | قوالب الكشف لكل تخصص: حقول يعرّفها الطبيب (نص، رقم، اختيار) | `VisitTemplate` |
| B3 | الوصفة: أدوية من قائمة تُستورد (CSV) مع الجرعة والتكرار والمدة، ووصفات مفضلة للطبيب | `Prescription`، `Drug` |
| B4 | تنبيه الحساسية والتعارض مع أدوية المريض الحالية (من قائمة يدخلها المدير، لا قاعدة طبية جاهزة) | `PrescriptionCheck` |
| B5 | مخطط الأسنان: حالة كل سن وكل سطح، وخطة علاج ببنود مسعّرة وحالة كل بند | `ToothRecord`، `TreatmentPlan` |
| B6 | المرفقات: صور وأشعة وتحاليل، مشفّرة في التخزين، وصور قبل وبعد | `Attachment` |
| B7 | طلبات التحاليل والأشعة والتقارير الطبية والإجازات المرضية PDF بقوالب | `Documents` |
| B8 | سجل وصول: من فتح ملف أي مريض ومتى | `audit_log` |
| W1 | شاشة الكشف: يسار التاريخ (زيارات سابقة)، ووسط الكشف الحالي، ويمين الوصفة | `pages/visit` |
| W2 | مخطط الأسنان التفاعلي (SVG): بالغ وطفل | `components/ToothChart` |
| W3 | الخط الزمني للمريض، ومعرض المرفقات مع مقارنة صورتين | `pages/patients/Timeline` |

**تعريف الانتهاء:**
- [ ] الطبيب لا يرى إلا مرضاه إن فعّل المدير ذلك، والاستقبال لا يرى الكشف أبداً.
- [ ] وصفة بدواء في قائمة حساسية المريض تنبّه قبل الحفظ.
- [ ] الوصفة والتقرير PDF بالعربية سليمين (خط مضمّن، RTL) وبشعار العيادة.
- [ ] الزيارة المغلقة لا تُعدَّل: تُضاف ملحقات بتوقيت واسم.
- [ ] المرفقات لا تُفتح برابط مباشر بلا صلاحية.

**كيف يُختبر:** اكشف على مريض أسنان: حشو سنّين وخطة علاج بثلاثة بنود، اطبع الوصفة، ثم افتح الملف بحساب الاستقبال وتأكد من الحجب.
