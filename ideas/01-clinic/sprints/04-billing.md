# Sprint 04: الخدمات والفواتير والأقساط

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 6 أيام عمل |

**الهدف:** كل زيارة تنتهي بفاتورة صحيحة، والعيادة تعرف من دفع ومن عليه وكم نصيب كل طبيب.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | قائمة الخدمات: فئات، وسعر لكل خدمة، وسعر خاص لكل طبيب أو فرع | `App\Billing\Service` |
| B2 | الفاتورة: بنود من الزيارة وخطة العلاج تلقائياً، خصم بنسبة أو مبلغ بصلاحية، ضريبة حسب البلد، ترقيم متسلسل لكل فرع | `Invoice`، `InvoiceItem` |
| B3 | الدفع: نقدي وبطاقة وتحويل وأونلاين، ودفع جزئي، وسجل حركات لا يُعدَّل، والاسترجاع حركة عكسية | `Payment`، `Ledger` |
| B4 | الأقساط: خطة بتواريخ ومبالغ، وتنبيه المتأخر | `Installment` |
| B5 | رصيد المريض: مقدّم ومديونية وكشف حساب | `PatientAccount` |
| B6 | نسبة الطبيب: نسبة أو مبلغ لكل خدمة، وتقرير مستحقاته بالفترة | `DoctorShare` |
| B7 | إقفال اليوم: المحصّل لكل طريقة ولكل موظف، والفرق عن الخزنة | `DayClose` |
| W1 | شاشة الفاتورة والتحصيل عند الاستقبال، وطباعة إيصال حراري وA4 | `pages/billing` |
| W2 | كشف حساب المريض وخطة الأقساط | `pages/patients/Account` |
| W3 | إقفال اليوم ومستحقات الأطباء | `pages/finance` |

**تعريف الانتهاء:**
- [ ] رصيد أي مريض يساوي مجموع حركاته دائماً (اختبار).
- [ ] دفع يتكرر بنفس `idempotency_key` يُسجَّل مرة واحدة.
- [ ] فاتورة مدفوعة لا تُحذف: تُلغى بفاتورة دائنة بصلاحية المدير.
- [ ] كل المبالغ أرقام صحيحة بأصغر وحدة، ولا float في أي حساب.
- [ ] Unit للضريبة والخصم والتقريب ونسبة الطبيب.

**كيف يُختبر:** أنهِ زيارة بخدمتين، ادفع نصفها نقداً، قسّط الباقي على شهرين، ثم أقفل اليوم وطابق الخزنة.
