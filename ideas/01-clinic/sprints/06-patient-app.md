# Sprint 06: تطبيق المريض

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 6 أيام عمل |

**الهدف:** تطبيق أندرويد وiOS باسم العيادة وشعارها، يحجز منه المريض ويرى وصفاته وفواتيره.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | API التطبيق: دخول بالجوال وOTP وتوكن ينتهي، وملف المريض وأفراد أسرته | `routes/api.php` (`/app/v1`) |
| B2 | إشعارات FCM: تذكير، تغيير موعد، دورك اقترب | `kit/Notify/Push` |
| B3 | ملف هوية للتطبيق يُقرأ من الخادم (اسم، ألوان، شعار) | `GET /app/v1/brand` |
| M1 | مشروع Flutter: بنية الميزات، Riverpod، Dio، تخزين آمن للتوكن، لغتان | `mobile/` |
| M2 | الشاشات: الرئيسية، الأطباء، الحجز، مواعيدي، وصفاتي (PDF)، فواتيري والدفع، ملفي | `mobile/lib/features` |
| M3 | متابعة الدور حياً يوم الموعد | `features/queue` |
| M4 | سكربت بناء بعلامة المشتري: الاسم والأيقونة والمعرّف والألوان من ملف واحد | `mobile/tool/brand.dart` |

**تعريف الانتهاء:**
- [ ] `dart run tool/brand.dart clinic.json` ينتج APK باسم وأيقونة مختلفين بلا تعديل يدوي.
- [ ] الحجز والإلغاء والدفع من التطبيق تظهر فوراً في لوحة الاستقبال.
- [ ] المريض لا يصل إلا لملفه وملفات أسرته (اختبار صلاحيات على كل مسار).
- [ ] التطبيق يعمل بالعربية RTL وبالإنجليزية، وعلى شاشة 360px.
- [ ] اختبارات ودجت للشاشات الأساسية.

**كيف يُختبر:** ابنِ التطبيق بهويتين مختلفتين، احجز من الجوال، وتابع الدور في يوم الموعد.

**ملاحظة:** النشر على المتاجر بحساب المشتري، ونكتب له دليل الخطوات. حساب Apple مدفوع (على المشتري).
