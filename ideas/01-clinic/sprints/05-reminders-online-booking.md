# Sprint 05: التذكيرات والحجز أونلاين

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** المريض يحجز وحده من رابط العيادة، ويصله تذكير يؤكد به أو يلغي، فيقل الغياب.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | قواعد التذكير: قبل الموعد بيوم وبساعتين (يحددها المدير)، وقنوات بالترتيب: واتساب ثم SMS ثم بريد | `App\Reminders` |
| B2 | واتساب Cloud API: قوالب معتمدة، وأزرار «أؤكد» و«ألغي»، وWebhook يحدّث حالة الموعد | `kit/Notify/WhatsApp` |
| B3 | رسائل أخرى: تأكيد الحجز، موعد المتابعة، قسط مستحق، تهنئة ميلاد، استدعاء من لم يزر منذ مدة | `Campaigns` |
| B4 | الحجز العام: الأطباء والفترات الحرة، وتحقق الجوال بـ OTP، وحد حجوزات للرقم، وعربون أونلاين اختيارياً | `PublicBookingController` |
| B5 | قائمة الاحتياط: من ينتظر فترة أقرب يُبلَّغ عند إلغاء غيره | `Waitlist` |
| B6 | سجل الرسائل وحالتها وكلفتها التقريبية | `message_log` |
| W1 | صفحة الحجز العامة بهوية العيادة (`/book`)، وصفحة «موعدي» برابط موقّع | `web/src/public` |
| W2 | إعدادات التذكير والقوالب مع معاينة | `pages/settings/Reminders` |
| W3 | ودجت حجز يُضمَّن في موقع العيادة (iframe وسكربت) | `web/embed` |

**تعريف الانتهاء:**
- [ ] ضغطة «ألغي» في واتساب تحرر الفترة وتبلّغ أول منتظر.
- [ ] التذكير لا يُرسل مرتين لنفس الموعد، ولا خارج ساعات يحددها المدير.
- [ ] الحجز العام لا يكشف اسم أي مريض آخر ولا يسمح بإغراق الجدول.
- [ ] بلا مفاتيح واتساب يعمل كل شيء بالبريد، وتظهر الرسائل في السجل.
- [ ] اختبارات الوقت بساعة قابلة للتحريك.

**كيف يُختبر:** احجز من الصفحة العامة برقمك، حرّك الساعة إلى ما قبل الموعد بيوم، وتابع الرسالة وأثر زرّيها.
