# Sprint 07: التقارير والصلاحيات والمصروفات

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 5 أيام عمل |

**الهدف:** المدير يرى عيادته بالأرقام في شاشة واحدة، ويتحكم في من يرى ماذا.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | المصروفات: فئات، ومورّد، ومرفق الإيصال، ومصروف متكرر | `App\Finance\Expense` |
| B2 | مخزون بسيط للمستهلكات: كمية وحد أدنى وتنبيه، وصرف يدوي | `Stock` |
| B3 | التقارير: الإيراد (يوم، طبيب، خدمة، فرع)، المديونيات، الغياب، مرضى جدد وعائدون، إشغال الجدول، الربح بعد المصروفات | `App\Reports` |
| B4 | تصدير Excel وPDF لكل تقرير، وتقرير أسبوعي بالبريد للمدير | `ReportExport` |
| B5 | محرر الأدوار: صلاحية لكل وحدة (عرض، إضافة، تعديل، حذف، مالي) وأدوار مخصصة | `kit/Roles` |
| B6 | سجل التدقيق: بحث بالمستخدم والوحدة والتاريخ | `audit_log` |
| B7 | نسخ احتياطي يومي مشفّر مع رفع اختياري لتخزين المشتري (S3 متوافق)، واستعادة مجرَّبة | `kit/Backup` |
| W1 | لوحة المدير: بطاقات اليوم ورسوم الشهر | `pages/dashboard` |
| W2 | شاشات التقارير بفلاتر، والمصروفات، والمخزون | `pages/reports` |
| W3 | محرر الأدوار وسجل التدقيق | `pages/settings/Roles` |

**تعريف الانتهاء:**
- [ ] كل رقم في اللوحة يطابق مجموع صفوف تقريره المفصل (اختبار).
- [ ] دور مخصص «محاسب بلا حذف» يعمل على كل المسارات لا في الواجهة فقط.
- [ ] استعادة نسخة احتياطية على سيرفر نظيف تعيد كل شيء.
- [ ] التقارير تفتح في أقل من ثانيتين على 50 ألف موعد (بيانات مولّدة).

**كيف يُختبر:** ولّد سنة بيانات بالبذرة، وقارن تقرير الإيراد بمجموع الفواتير، ثم استعد نسخة احتياطية.
