# منصة توصيل بعلامة المشتري (White-label)

## الفكرة

منصة توصيل كاملة يشتريها رائد أعمال ويطلقها في مدينته باسمه: تطبيق العميل، وتطبيق المندوب، وتطبيق ولوحة التاجر، ولوحة الإدارة. متاجر متعددة (مطاعم، بقالة، صيدليات، أي شيء).

## المشتري

- رواد أعمال يريدون «تطبيق توصيل المدينة» في مدن لا تغطيها التطبيقات الكبرى.
- شركات توصيل قائمة تعمل بالهاتف وواتساب.
- سلاسل محلات تريد تطبيق توصيلها.
- شركات برمجة تعيد البيع بعلامتها (ترخيص موسّع).

## ما يميزنا

- الكود كاملاً مع النسخة، وبناء التطبيقات الثلاثة بعلامة المشتري بأمر واحد.
- خرائط بلا كلفة إلزامية: OpenStreetMap افتراضياً، وGoogle Maps اختيارياً بمفتاح المشتري.
- محاسبة العمولات والمحافظ والتسويات جاهزة (أصعب ما في هذه المنصات).
- عربي أولاً.

## النطاق

**v1:** المتاجر والكتالوج، السلة والطلب والدفع، تطبيق العميل، لوحة وتطبيق التاجر، المناديب والإسناد والتتبع الحي، تطبيق المندوب، العمولات والمحافظ والتسويات، العروض والتقييمات، بناء العلامة.

**بعد v1:** طلب أي شيء (مشوار)، الاشتراكات، الطلبات المجدولة، مدن متعددة بإدارات فرعية، الإعلانات المدفوعة للمتاجر.

## الأدوار

| الدور | ما يفعله |
|---|---|
| مالك المنصة | كل شيء: المتاجر والمناديب والعمولات والتسويات |
| موظف العمليات | متابعة الطلبات الحية وحل مشاكلها |
| التاجر | متجره وأصنافه وطلباته وكشف حسابه |
| المندوب | استلام وتوصيل الطلبات ومحفظته |
| العميل | يتصفح ويطلب ويتابع ويقيّم |

## نموذج البيانات (مختصر)

`zones`، `stores`، `store_hours`، `categories`، `products`، `option_groups`، `options`، `customers`، `addresses`، `carts`، `orders`، `order_items`، `order_events`، `payments`، `drivers`، `driver_locations`، `assignments`، `wallets`، `wallet_moves`، `commissions`، `settlements`، `coupons`، `reviews`، `tickets`.

## التقنية

الأساس المشترك، ومعه: PostGIS للمناطق والمسافات، وReverb للتتبع الحي، وFlutter لثلاثة تطبيقات من مستودع واحد (حزمة مشتركة)، وخرائط `flutter_map` (OSM) مع OSRM مستضاف ذاتياً للمسافة والمسار.

## التسعير والبيع (تقديري)

| الباقة | السعر | تشمل |
|---|---|---|
| قياسية | 2000$ | النسخة والكود، دومين واحد، وبناء التطبيقات بعلامته |
| مع الإطلاق | 3500$ | التركيب، ونشر التطبيقات على المتاجر، وتدريب |
| موسّعة (إعادة بيع) | 8000$ | حق بيعها لعملائه بعلامته |
| تجديد الدعم | 20% سنوياً | |

## التسويق

- موقع تجريبي وتطبيقات تجريبية على المتاجر تُنزَّل وتُجرَّب.
- إعلانات موجهة لـ«مشروع تطبيق توصيل» في الخليج ومصر والعراق وليبيا واليمن والسودان.
- يوتيوب: «كيف تبدأ تطبيق توصيل في مدينتك» (المحتوى يبيع).
- شركات البرمجة الصغيرة كشركاء إعادة بيع.

## المخاطر

| الخطر | التعامل معه |
|---|---|
| الحجم: ثلاثة تطبيقات ولوحتان | يُبنى آخراً بعد أن ينضج الأساس، وحزمة Flutter مشتركة |
| مشتري الكود قد يعيد بيعه | ترخيص قانوني واضح، ومفتاح مربوط بالدومين، والتحديثات والدعم لحامل المفتاح فقط |
| التتبع يستنزف البطارية والخادم | إرسال الموقع بفاصل يتكيف مع الحركة، وتخزين آخر موقع في Redis |
| حسابات Apple وGoogle للمشتري | دليل خطوة بخطوة، وخدمة النشر مدفوعة |
| نجاح المشتري يعتمد على تشغيله لا على البرنامج | دليل تشغيل (كيف تجلب المتاجر والمناديب) مع النسخة |
