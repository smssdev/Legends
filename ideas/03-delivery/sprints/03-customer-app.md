# Sprint 03: تطبيق العميل

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 9 أيام عمل |

**الهدف:** العميل ينزّل التطبيق، يحدد موقعه، يطلب من متجر، ويتابع طلبه حتى الباب.

| الرمز | المهمة | الملفات |
|---|---|---|
| M1 | مستودع Flutter بثلاثة تطبيقات وحزمة مشتركة (الشبكة، النماذج، الهوية، المكونات، الخرائط) | `apps/customer`، `packages/core`، `packages/ui` |
| M2 | نظام التصميم: ألوان وخطوط وأشكال من ملف هوية واحد | `packages/ui/theme` |
| M3 | الدخول بالجوال وOTP، وتحديد الموقع بالـ GPS أو على الخريطة | `features/auth`، `features/location` |
| M4 | الرئيسية: أنواع المتاجر، بنرات، الأقرب، الأعلى تقييماً، بحث | `features/home` |
| M5 | صفحة المتجر: الفئات والمنتجات، ونافذة الخيارات، وحالة المتجر | `features/store` |
| M6 | السلة والتأكيد: العنوان، طريقة الدفع، الكوبون، ملاحظة، والتفصيل | `features/checkout` |
| M7 | الدفع بالبطاقة عبر صفحة البوابة (WebView أو SDK حسب المزوّد) | `features/payment` |
| M8 | متابعة الطلب: شريط الحالات، وخريطة المندوب حياً، والاتصال به | `features/tracking` |
| M9 | طلباتي، إعادة الطلب، العناوين، المحفظة، الملف، اللغة | `features/account` |
| M10 | إشعارات FCM لكل حالة، وروابط عميقة لصفحة الطلب | `packages/core/push` |
| W1 | نسخة ويب للعميل (PWA) من نفس الـ API: تصفح وطلب ومتابعة | `web/customer` |

**تعريف الانتهاء:**
- [ ] طلب كامل من أول فتح للتطبيق في أقل من دقيقتين.
- [ ] التطبيق لا يحسب سعراً: كل رقم من الخادم.
- [ ] انقطاع الشبكة يظهر حالة واضحة ويعيد المحاولة بلا تكرار الطلب.
- [ ] RTL والإنجليزية، وشاشة 360px، ووضع ليلي.
- [ ] اختبارات ودجت للشاشات الأساسية، واختبار تكامل لدورة الطلب على خادم تجريبي.

**كيف يُختبر:** على جوالين: اطلب من متجر، وغيّر الحالات من اختبار خلفي، وتابع الإشعارات والشريط.
