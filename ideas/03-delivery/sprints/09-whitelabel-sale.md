# Sprint 09: بناء العلامة والتجهيز للبيع

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل |

**الهدف:** مشترٍ يملأ ملف علامته فيخرج له خادم وثلاثة تطبيقات باسمه جاهزة للمتاجر.

| الرمز | المهمة | الملفات |
|---|---|---|
| S1 | ملف العلامة الواحد: الاسم، المعرّفات، الأيقونات، الألوان، الخطوط، الدومين، مفاتيح الخرائط والإشعارات | `brand/brand.yaml` |
| S2 | أمر البناء: يولّد الأيقونات وشاشات البدء ويضبط المعرّفات ويبني APK وAAB للتطبيقات الثلاثة، ومشروع iOS جاهزاً للأرشفة | `tool/brand_build.dart` |
| S3 | إعدادات المنصة من اللوحة بلا كود: العملة، الضريبة، اللغات، بوابة الدفع، نصوص الشروط | `admin/pages/settings` |
| S4 | المثبّت (Docker Compose مع PostGIS وOSRM وRedis وReverb)، وتحميل خريطة البلد لـ OSRM بأمر | `deploy/` |
| S5 | ربط خادم التراخيص، وسياسة التحديث لحامل الترخيص | `kit/License` |
| S6 | الموقع التجريبي ولوحاته، وتطبيقات تجريبية منشورة، ومحاكي مناديب يحرّك العرض | `DemoSeeder`، `tool/sim` |
| S7 | الوثائق: التركيب، بناء العلامة، النشر على Google Play وApp Store، إعداد Firebase والبوابة | `docs/` |
| S8 | دليل التشغيل للمشتري: جلب المتاجر والمناديب، التسعير، أول 100 طلب | `docs/playbook.md` |
| S9 | فحص أمان كامل (صلاحيات الأطراف الخمسة على كل مسار)، واختبار حمل (1000 طلب في الساعة) | `tests/` |
| S10 | صفحة الهبوط والأسعار والفيديو، وعقد الترخيص القياسي والموسّع (مسودتان) | `site/`، `docs/legal` |

**تعريف الانتهاء:**
- [ ] علامتان مختلفتان تُبنيان من نفس المستودع بلا تعديل يدوي في أي ملف.
- [ ] تركيب كامل على سيرفر نظيف من الدليل في أقل من ساعتين.
- [ ] لا مسار يسرّب بيانات طرف لطرف آخر.
- [ ] تجربة حية: 10 طلبات حقيقية في مدينة مع متجرين ومندوبين.
- [ ] الموقع والتطبيقات التجريبية متاحة للعموم.

**كيف يُختبر:** أعطِ حمزة ملف علامة جديداً وسيرفراً فارغاً، ودعه يصل إلى أول طلب بالدليل وحده.
