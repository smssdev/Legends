# Sprint 06: تطبيق المندوب

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل |

**الهدف:** المندوب يتصل، يأتيه العرض، يقبل، يوصل، ويرى ما كسبه.

| الرمز | المهمة | الملفات |
|---|---|---|
| M1 | التسجيل ورفع الوثائق، وحالة المراجعة | `apps/driver/features/onboarding` |
| M2 | زر «متصل»، وخدمة موقع في الخلفية بفاصل يتكيف مع الحركة والبطارية | `features/presence`، `core/location` |
| M3 | عرض الطلب: شاشة كاملة بصوت وعدّاد، المتجر والمسافة والأجر، قبول أو رفض | `features/offer` |
| M4 | مراحل التوصيل: إلى المتجر، استلمت، إلى العميل، سلّمت، مع فتح الملاحة في تطبيق الخرائط | `features/delivery` |
| M5 | إثبات التسليم (رمز أو صورة)، وتحصيل النقد وتأكيده | `features/proof` |
| M6 | الاتصال بالعميل والمتجر، وزر مشكلة (العميل لا يرد، العنوان خطأ) | `features/support` |
| M7 | الأرباح: اليوم والأسبوع، والمحفظة، والنقد الذي عليه | `features/earnings` |
| M8 | سجل الطلبات والتقييمات | `features/history` |
| B1 | مسارات المشاكل: إعادة محاولة، إرجاع للمتجر، تدخل العمليات | `DeliveryIssue` |

**تعريف الانتهاء:**
- [ ] العرض يظهر ويرنّ والتطبيق في الخلفية والشاشة مقفلة (أندرويد).
- [ ] التتبع يستمر ساعتين في الخلفية بلا قتل من النظام على ثلاثة أجهزة مختلفة، واستهلاك بطارية مقبول (يُقاس ويُكتب).
- [ ] فقدان الشبكة في منتصف التوصيل: الحالات تُحفظ وتُرسل عند العودة بترتيبها.
- [ ] المندوب لا يرى رقم العميل بعد انتهاء الطلب.
- [ ] الأرباح المعروضة تطابق محفظته في الخادم.

**كيف يُختبر:** توصيلة حقيقية في الشارع بثلاثة جوالات (عميل، تاجر، مندوب): تُضاف للتجارب المؤجلة إن لم تتيسر، ولا توقف العمل.
