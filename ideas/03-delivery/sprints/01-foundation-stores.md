# Sprint 01: الأساس والمناطق والمتاجر والكتالوج

| | |
|---|---|
| **الحالة** | ⏳ قادم |
| **المدة** | 7 أيام عمل |

**الهدف:** مالك المنصة يرسم مناطق مدينته ويضيف المتاجر، وكل متجر له كتالوجه وساعاته.

| الرمز | المهمة | الملفات |
|---|---|---|
| B1 | مستودع جديد ونسخ `kit/`، وPostgreSQL مع PostGIS | `backend/`، `deploy/` |
| B2 | المناطق: مضلعات على الخريطة، ورسوم توصيل (ثابتة أو بالمسافة)، وحد أدنى للطلب | `App\Geo\Zone` |
| B3 | أنواع المتاجر (مطعم، بقالة، صيدلية…) وتصنيفاتها | `StoreType` |
| B4 | المتجر: الموقع، نطاق التوصيل، ساعات العمل والاستثناءات، وقت التحضير، نسبة العمولة، حالة (مفتوح، مشغول، مغلق) | `App\Stores` |
| B5 | الكتالوج: فئات ومنتجات بصور وأسعار وخيارات (مجموعات إجبارية واختيارية)، ومخزون اختياري | `App\Catalog` |
| B6 | طلب انضمام تاجر ومراجعته وتفعيله، وحسابات موظفي المتجر | `StoreOnboarding` |
| B7 | استيراد الكتالوج من Excel | `CatalogImport` |
| B8 | البحث: بالاسم والفئة، والمتاجر التي توصل لنقطة معيّنة مرتبة بالمسافة والتقييم | `StoreSearch` |
| W1 | لوحة الإدارة: الإطار، ورسم المناطق على الخريطة (Leaflet) | `admin/` |
| W2 | إدارة المتاجر وطلبات الانضمام | `admin/pages/stores` |
| D1 | مسودات التطبيقات الثلاثة واللوحتين ونظام الألوان القابل للتبديل | `docs/design` |

**تعريف الانتهاء:**
- [ ] نقطة داخل منطقة تُرجع متاجرها، وخارج كل المناطق تُرجع «لا نوصل هنا».
- [ ] متجر خارج ساعاته أو «مشغول» يظهر مغلقاً ولا يقبل طلباً.
- [ ] رسوم التوصيل بالمسافة أرقام صحيحة، وUnit للحساب وحدود المضلع.
- [ ] البحث عن متاجر نقطة يستعمل فهرساً مكانياً (أقل من 100ms على 5000 متجر).

**كيف يُختبر:** ارسم ثلاث مناطق، أضف 10 متاجر، واسأل الـ API من نقاط داخلها وخارجها.
