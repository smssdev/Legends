| الاسم | القيمة | الاستخدام |
|---|---|---|
| navy | `#0A1F42` | الخلفيات |

## الاسم والشعار (قرار صاحب المشروع، 2026-10-20)

- **الاسم:** الأساطير، وبالحروف اللاتينية Legends.
- **العملة المميزة:** الكوينز.
- **الشعار:** درع كحلي بإطار ذهبي، على حافته العليا تاج بثلاث لآلئ، وفي وسطه كرة يحملها إكليل غار. وتحته LEGENDS والأساطير.

## الملفات الحالية (`current/`)

كلها تُرسم من مصدر واحد، فلا تُعدَّل الصور يدوياً:
- `python3 tools/brand/logo.py` يرسم ملفات SVG.
- `node tools/brand/render.mjs` يصدّر منها كل الصور بخط Alexandria (يحتاج Playwright مع Chromium).

| الملف | الوصف |
|---|---|
| `logo.svg`، `logo-1024.png` / `logo-512.png` | الشعار الكامل: الدرع، وLEGENDS، والأساطير، على الكحلي |
| `emblem.svg` | الدرع وحده بخلفية شفافة، للشاشات الداكنة (الويب يستخدمه في `/brand/emblem.svg`) |
| `icon.svg`، `icon-512.png`، `icon-192.png` | أيقونة التطبيق: الدرع على الكحلي بهامش آمن (تصلح كـ maskable) |
| `apple-touch-icon.png` (180) | شاشة iOS الرئيسية |
| `favicon.svg`، `favicon.ico` (16/32/48)، `favicon-16/32/48.png` | أيقونة المتصفح: الدرع بلا إكليل ليبقى واضحاً صغيراً |
| `coin.svg`، `coin-512/128/48/24.png` | الكوينز: عملة ذهبية فيها الكرة والتاج، بخلفية شفافة |
| `og-invite.png` (1200×630) | صورة مشاركة واتساب/OG، الـ 45% اليمنى فارغة للنص |

- نص بطاقة الدعوة العربي (اسم الدوري والشعار) يُرسم بـ HTML، وليس داخل `og-invite.png`.
- **الاتجاهات القديمة:** `concepts/` فيها الاتجاهات الثلاثة الأولى للشعار، للأرشيف فقط.
