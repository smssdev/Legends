# Legends: الهوية البصرية

## الألوان (مقاسة من الأعمال النهائية)

| الاسم | القيمة | الاستخدام |
|---|---|---|
| navy | `#0A1F42` | الخلفيات |
| gold | `#F5B82E` | الشعار، العملة، العناصر البارزة |
| gold dark | `#C08A0C` | إطار العملة، الشعار فوق الذهبي |
| pitch green | `#1E9E4A` | ثانوي، لواجهة الملعب فقط (ليس جزءاً من الشعار) |
| ivory | `#F7F4EA` | الأسطح الفاتحة |

## الملفات الحالية (`current/`)

تُنسخ إلى `public/brand/` عند إنشاء المشروع.

| الملف | الوصف |
|---|---|
| `logo-1024.png` / `logo-512.png` | الكرة المتوجة + كلمة LEGENDS على الكحلي |
| `icon-512.png`, `icon-192.png` | أيقونة التطبيق، كحلي كامل (تصلح كـ maskable) |
| `apple-touch-icon.png` (180) | شاشة iOS الرئيسية |
| `favicon.ico` (16/32/48), `favicon-16/32/48.png` | أيقونة المتصفح |
| `coin-512/128/48/24.png` | أيقونة العملة، خلفية شفافة |
| `og-invite.png` (1200×630) | صورة مشاركة واتساب/OG، الـ 45% اليمنى فارغة للنص |

- نص بطاقة الدعوة العربي (اسم الدوري والشعار) يُرسم بـ HTML، وليس داخل `og-invite.png`.

## اتجاهات مقترحة للشعار (`concepts/`)

ثلاثة اتجاهات بديلة بـ SVG (تتكبر بلا فقدان جودة)، بنفس الألوان:

| الملف | الفكرة |
|---|---|
| `a-crest.svg` | **الدرع:** درع كحلي بإطار ذهبي، فيه كرة نجمتها في المنتصف، وثلاث نجوم فوقها (ألقاب) |
| `b-laurel.svg` | **الغار:** كرة بنجمة داخل إكليل غار مفتوح ونجمة في الأعلى (الأسطورة وقاعة المشاهير) |
| `c-monogram.svg` | **حرف L:** حرف L ذهبي بقوس ركنية الملعب في زاويته وكرة بنجمة، أيقونة مربعة جاهزة |

> القرار النهائي للشعار لم يُحسم بعد. انظر `docs/PLAN.md`، قسم النقاط المفتوحة.
